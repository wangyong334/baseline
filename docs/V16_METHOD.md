# V16：重叠上下文中的共享特征修正

> 本文记录 r1。2026-11-13 优化版本的结构、约束与损失见 `docs/V16_R2_METHOD.md`，使用 `configs/v16/r2/`。

实现基线：V14 `e91bddc`；V16 保留 V5 BIR、跨窗膜电位、峰值通信约束、分流并行 TBPTT。当前版本是待正式实验验证的模型，不声称首次滑窗、精确贝叶斯更新或已达到某会议录用标准。

## 1. 问题与研究假设

稀疏小目标的有效判别线索可能跨越切片边界。即时输出无法利用稍后到达的上下文；单纯增加特征强度又可能增强持续背景。跨窗膜电位携带历史，但不能替代尚未到达的观测，也不能保证保留任意历史细节。

用 100 ms 窗、50 ms 步长构造 AB、BC：同一待判片段 B 在两个上下文中被观察。在 C 到达后完成 B 的最终判决。这里的研究对象是“如何利用两份相关上下文修正同一片段”，不是把滑窗本身作为新发明。

两个方法分别回答：

1. **双上下文对照读取（方法一）**：哪些局部结构有别于普遍背景响应？
2. **条件残差修正（方法二）**：给定第二份特征，第一份特征还应补充什么、补充多少？

两份特征都来自完整混合窗口与状态历史。没有从深层混合特征中声称分离出“纯 B”，也不将两次预测作为独立似然相乘。

## 2. 时间与状态协议

设原始片段 A=[0,50)、B=[50,100)、C=[100,150) ms。

- 100 ms：V5 对 AB 产生 F1，保存共享特征；B 暂不最终输出。
- 150 ms：同一状态链对 BC 产生 F2，用 F1/F2 得到 F*，按 B 的原始事件 ID、坐标读取 F*，完成 B 的判决。
- 之后释放 F1，保留 F2 供下一对窗口复用。

递推状态的物理步长是 50 ms，输入覆盖长度为 100 ms。B 的输入确实出现两次，状态也可能包含更早历史，这是明确的滚动输入协议，不等价于原始 50 ms 非重叠 V5。修正特征 F* 不回写 SNN 状态。

首尾只有一次覆盖的事件由原 V5 读出完成。每个原始事件只有一个最终输出；真实空窗仍更新状态，录像结束不存在的未来窗不补零伪造观测。待判片段固定等下一窗，不做阈值选事件或提前锁定正例。

## 3. 方法一：双上下文对照读取

F_i 为末层发放前膜电位特征，形状 C×H×W，C=12。先做有效传感器区域的 4×4 均值池化：

U_i = Pool_valid(F_i)。

当前默认不增加降维投影；使用共享的 Q/K/V 线性投影、3 个头、每头 4 维。每个粗网格位置 u 只读取 5×5 邻域 N(u)，并设置一个可学习的空选择：

a_i(u,v) = Softmax_v(Q_i(u)^T K_i(v)/sqrt(d) + b_(v-u))。

Softmax 范围是有效邻居与空选择；无效 padding 被屏蔽。以有效邻域均值作为局部参考：

Vbar_i(u) = Mean_(v in N(u)) V_i(v)，

R_i(u) = Sum_(v in N(u)) a_i(u,v) [V_i(v) - Vbar_i(u)]。

代码采用等价形式 `sum(a*V) - sum(a)*Vbar`，减少显式中间张量。空选择贡献为零。

原理上的结构保证是：局部 V 为常数时 R=0；无效 padding 不会污染有效邻域；网络可以降低不可靠邻域的使用量。**这不意味着 R 就是目标、空选择是校准置信度，或者已精确去掉 B 的公共信息。**持续运动背景同样可能产生强对比。

每个新窗口只计算一次 U/R，之后缓存供相邻两次组合复用。两个视图共享参数，不运行跨事件检索。高分辨率 F1/F2 始终保留，避免小目标只能经过粗池化路径。

## 4. 方法二：条件残差修正

相关观察的正确出发点是条件补充信息，而非重复累加。二分类概率存在恒等式：

logit P(Y|A1,A2) = logit P(Y|A2)
  + log [p(A1|Y=1,A2) / p(A1|Y=0,A2)]。

这里只借此组织“第二视图基础 + 条件修正”；网络没有显式拟合上述密度，因此不称精确后验或 SPRT。

构造条件描述：

D = [U2, R2, U1-U2, R1-R2, U1*U2, R1*R2]。

差值表达变化，乘积提供相容性线索；两者都不等于概率意义上的独立性估计。使用 1×1 Conv(72→24) → SiLU → 1×1 Conv(24→24)，拆成 g_raw 和 r：

g = tanh(g_raw)，

F* = F2 + Up(g) * (F1-F2) + Up(r)。

Up 是有效区域归一化的双线性上采样，保留原数学前向，使用确定性一阶伴随反传以兼容旧 CUDA/PyTorch。

解释：F2 提供已有判断基础；有界、有符号的 g 控制第一视图细节的恢复或反向修正；r 对两份视图共同出现的错误也保留修正能力。g 不是概率，可发生外推；整体没有误报单调下降保证。

末层零初始化使完整模型起点严格为 F2。第一步主要学习末层，之后梯度进入前层与方法一。将 F* 按 B 的坐标读取，再拼接原极性 p 与**第二次出现时的窗口内时间 tau2**，送入原 V5 `14→32→1` MLP。不会把第一次 tau 与第二次特征混用。

## 5. 架构对应

```text
连续事件 → 100/50 ms 滚动表示 → V5 BIR U-Net → 每窗 F_i
                                      │             │
                                      └─状态 carry  ├─保留高分辨率特征
                                                    └─方法一：共享局部对照读取 → U_i,R_i
                                                                  │ 缓存一窗
                      前次 F1,U1,R1 ────────────────┐              │
                      当前 F2,U2,R2 ────────────────┴─方法二：条件修正 → F*
                                                                           │
                      同一 B 的原始 ID、坐标、p、tau2 ───────────────────────┤
                                                                           ↓
                                                           原 V5 MLP → B 最终分数
```

两模块是在共享网格上做上下文读取与修正；逐事件操作只保留输入计数/索引、最后一次批量 MLP，不引入事件间注意力或隐藏状态。

## 6. 损失、训练与六个独立实验

配对事件损失：L = 0.5 BCE(z*,y) + 0.25 BCE(z1,y) + 0.25 BCE(z2,y)。单覆盖事件权重为 1。加上原 V5 峰值通信预算损失，预算为每步 157700。每个原始事件在一轮中的监督权重总和为 1，避免重叠输入隐式改变样本权重。

pos_weight 仅由训练集拟合，上限 30；100 ms 表示的归一化统计也重新由训练集拟合。保留 4 streams、K=16、逐层并行 TBPTT、50 epoch、原学习率日程。原配置 `optimizer_step: per_sequence` 是单流入口字段；本分流入口与 V14 一致，每个 K 窗块进行一次优化器更新，运行记录明确记录实际更新数。

融合损失可反传到两视图的骨干特征及读出。跨 TBPTT 边界，前一特征与 U/R 保留数值但 detach，并 clone 单窗数据，避免旧计算图及整块存储滞留。各录像边界同时清零状态、释放缓存。

| 配置 | 方法一 | 方法二 | 种子 |
|---|---|---|---|
| full | 局部对照注意力 | 条件残差修正 | 37、38 |
| no_revision | 保留 | 普通拼接 MLP + 高分辨率均值跳连 | 37、38 |
| no_context | 有效邻域均值读取，无 QKV/空选择 | 保留 | 37、38 |

去掉方法二采用 `mean(F1,F2)+Up(MLP([U1,U2,R1,R2]))`，MLP 为48→36→12。它是容量接近的普通融合控制，不丢掉第一视图的高分辨率路径。去掉方法一仍保留两视图原特征和统一尺寸接口，验证的是结构化对照读取相对普通均值的增益。

三组分别从头训练，不以同权重开关代替消融。相同种子的骨干初值一致，模块单独初始化不改变骨干随机数序列。不同组的结果目录、配置、权重独立。

## 7. 计算、测量与解释边界

默认新增参数：full 2898、no_context 2352、no_revision 2754。每新窗口复用上次编码后，头部 dense MAC 估计分别为19.45M、13.38M、18.61M；不含骨干、池化、Softmax、插值和逐元素运算。不能将其直接换算成真实能耗。

主路径推理每事件调用一次原 MLP，即约480个线性 MAC/事件；复杂度仍有必要的 O(N) 输入与输出。共享网格计算取决于 H×W 和固定25邻域，不是事件数的二次方。训练包含三个读出监督，比主路径推理多；诊断 first/second/main 的测时不能当作最终模型速度。

固定待决时间：内段事件从发生到最终窗口关闭为50–100 ms，另外加运行与排队时间。缓存只有前一窗 F/U/R，与流长度无关；读取本地录像的实现会预载整段稀疏输入，profile中明确记录，不能冒充真实相机驱动端到端测试。

每项实验自动：训练逐epoch验证选最佳 → 同一权重正式val/test → 单主读出profile。输出IoU、ACC（目标事件召回，不是总体正确率）、Pd、Fa、阈值扫描、每录像统计、相对第二次读出的改好/改坏数量、通信、速度、峰值显存、可用时整卡实测能耗。能耗不包括CPU或整机，存在其他GPU进程时标记污染。

## 8. 主要失败条件与研究判断

- 共享5×5粗网格只能覆盖有限局部位移，快速目标和空间错配仍可能失败；它不是运动估计器。
- 局部对比也可能来自背景。应检验相同召回/Pd条件下是否降低Fa，而不能只看ACC升高。
- F1/F2可能高度冗余，最终模型可能退化到第二视图；此时应如实报告，不能凭结构宣称互补已成立。
- 上下文采样与状态共同影响结果，滑窗、carry和两个模块的作用不能混写。
- full与消融优势必须由独立重训结果支持；first/second/main同权重诊断只分析依赖关系。
- 固定有限延迟不是自适应序贯停止；不声称风险界、精确公共信息扣除或贝叶斯校准。

论文图和公式应展示真实实现，研究主线是“边界上下文不足 → 同片段滚动重访 → 对照读取与条件修正 → 独立消融与误报/延迟验证”。
