# V14：重叠观测下的轻量条件分数修正

本文是 2026-11-12 的实现与论文方法协议，不是已验证的性能结论。V14 保留 V5 的 BIR 流式 U-Net、跨窗状态、事件读出和通信预算训练，新增 100 ms 观测窗 / 50 ms 步长以及一个 34 参数的条件残差头。它不使用 V11–V13 的逐事件隐藏状态、邻域检索、反复注意力和可变轮数等待。V15 特征级方案不属于本协议。

## 1. 问题：有限观测下的判断，与相关的第二次观测

小目标在一个短窗里可能只有少量、断续的事件。流式骨干的膜电位能传递过去，但在第一次输出时不能利用尚未到来的观测。延迟一次步长，可以让同一批事件在包含新上下文的窗口中被重新读出。然而，两个窗口共享事件，单状态链还共享历史状态：第二个分数不能视为独立证据，直接相加可能重复放大共同信息。

本轮的具体问题是：**对同一事件的两次相关估计，能否用一个有结构约束、可端到端训练的轻量修正头，在有限等待下改善最终判断？** 这里不承诺复原完整的未来特征，也不把仅有两个标量说成包含所有上下文。

论文动机应通过验证集上的下列现象支撑：第一次读出存在漏检或误报；第二次读出能纠正其中一部分、也可能损坏一部分；收益随第一次置信程度变化。不能仅凭“事件稀疏”推定该机制一定有效。

## 2. 观测组织与状态：共享同一事件身份，不假设信息独立

令步长为 \(S=50\,\mathrm{ms}\)，不重叠基本块及观测窗为

\[
 B_k=\{e_i:kS\leq t_i<(k+1)S\},\qquad
 W_k=B_k\cup B_{k+1},\quad k=0,\ldots,K-2. \tag{1}
\]

8 s 录像有 160 个基本块、159 个完整的 100 ms 观测窗。严格冷启动：第一窗是 0–100 ms，不创建 -50–50 ms 的虚构观测。每个内部块 \(B_k\), \(1\leq k\leq K-2\)，在 \(W_{k-1}\) 和 \(W_k\) 各出现一次。利用原始事件索引配对，不进行事件匹配或空间邻居搜索。

设 \(X_k=R(W_k)\) 是事件计数表示，\(s_k\) 是整张特征图的 BIR 状态，计算为

\[
 (F_k,s_k)=G_\theta(X_k,s_{k-1};\Delta t=S),\qquad
 r_{i,k}=h_\theta\!\left[F_k(x_i,y_i),p_i,\tau_{i,k}\right]. \tag{2}
\]

\(h_\theta\) 沿用 V5 的批量事件 MLP，输出原始 logit；\(\tau_{i,k}\) 是该事件在当前 100 ms 观测窗内的相对时间。\(F_k\) 对应当前观测及状态所包含的历史，不是可直接剥离的纯 \(B_k\) 特征。

本轮选择的是**一条状态链**：\(AB\to BC\to CD\to\cdots\)，每 50 ms 更新一次膜电位；观测支持长度为 100 ms。它不是两条交错状态链。B 会影响相邻两次输入，还可能通过膜电位影响后续输出。因此这里不声称原始事件只输入骨干一次、不声称重复输入已被消除。训练和评估必须采用相同状态与时间常数语义；不能把观测长度 100 ms 当作相邻状态更新的 100 ms 间隔。

对于 \(e_i\in B_k\)，定义

\[
 r_{1,i}=r_{i,k-1},\qquad r_{2,i}=r_{i,k}. \tag{3}
\]

两者的事件身份与标签相同，但输入上下文、膜电位和窗内时间坐标均可能不同。分数变化不能全部归因为新增的 C。首块和末块只有一次完整窗覆盖，按唯一可得读出输出，并单独统计；不能静默丢弃它们来改善指标。

## 3. 原理：条件更新，而不是相乘两个“后验”

记 \(Y\in\{0,1\}\) 为同一事件的类别。对真正的条件概率，有恒等式

\[
 \operatorname{logit}P(Y=1\mid r_1,r_2)
 =\operatorname{logit}P(Y=1\mid r_1)
 +\log\frac{p(r_2\mid r_1,Y=1)}{p(r_2\mid r_1,Y=0)}. \tag{4}
\]

该式没有假设两分数独立：第二项已经以第一分数为条件。它解释了为什么第二次观测的作用应随第一次估计变化。它是**分数层条件更新的依据**，不是当前网络自动满足的概率保证。

V5 的输出经过加权 BCE 训练，并非已校准的概率对数几率。因此不能直接把 \(r_1\) 等同式 (4) 第一项，也不能把 \(r_2\) 等同条件似然比。理想的常数正类权重 BCE 极小解已会相对真实 log-odds 产生权重偏移；有限容量、采样和通信正则还会增加偏差。本文将 (4) 用作结构设计依据，不宣称精确 Bayesian posterior、SPRT 最优性或错误风险上界。

重叠的 B 所含信息没有被数学上“减干净”。我们改为直接学习联合分数的监督映射，避免把两个相关分数当独立似然相乘。是否学会可靠利用第二观测，需要专门消融验证。

## 4. 方法公式：随第一次估计变化的残差修正

以第一次分数为条件，生成修正强度和偏置：

\[
 u=\operatorname{ReLU}(w_1r_1+b_1),\qquad
 [a_{\rm raw},c]^\top=W_2u+b_2,\qquad
 a=\operatorname{softplus}(a_{\rm raw}). \tag{5}
\]

其中隐藏维度为 8，映射为 \(1\to8\to2\)。最终分数为

\[
 \boxed{r_f=r_1+a(r_1)(r_2-r_1)+c(r_1).} \tag{6}
\]

它有三项明确分工：\(r_1\) 保留初始判断；\(r_2-r_1\) 表示两次读出的差异；\(a,c\) 让这种差异及偏置的处理依赖第一次估计。\(c\) 可补偿分数尺度或类别权重造成的偏移，但也可能独自解释收益，所以必须设置只校准对照。

结构带来的真实约束是

\[
 \left.\frac{\partial r_f}{\partial r_2}\right|_{r_1}=a(r_1)>0. \tag{7}
\]

固定第一次分数时，更高的第二次分数不会降低最终分数。这个约束体现方向一致性，减少任意二元 MLP 的自由度；它不保证全局校准、判决单调改善或抗分布变化。

初始化 \(a=0.5,c=0\)，从两 logit 均值开始训练。参数量为 \((1\times8+8)+(8\times2+2)=34\)。几点必须保留在方法解释中：

- Softplus 只约束 \(a>0\)，没有约束 \(a\leq1\)。该模型允许外推，不是必然的凸加权平均。
- 若 \(r_2=r_1\)，则 \(r_f=r_1+c(r_1)\)。除非 \(c=0\)，并不满足严格的重复输入不变性。
- 分数相减不是对共同事件 B 的可逆信息分解；深度非线性网络不存在一般的“减 logit 即去重”结论。
- 对固定 \(r_1\)，修正是 \(r_2\) 的仿射函数。若同一个 \(r_1\) 下第二分数的可靠性具有复杂非单调关系，这个头会欠拟合；先用实验判断，不预先堆叠额外网络。

## 5. 模块架构与流式执行

```text
原始事件（保留原始索引）
          |
  100 ms 窗 / 50 ms 步长计数表示
          |
  V5 BIR U-Net  <---- 单链跨窗状态 s（每 50 ms 更新）
          |
  按当前窗事件坐标读取共享特征 + 极性 + 窗内时间
          |
       原 V5 读出 MLP
          |
     当前窗 logits
       /          \
已出现过的前半块     首次出现的后半块
  r2 + 索引          r1 + 索引暂存一个步长
       |                  |
       +---- 与缓存同 ID 配对 ----+
                     |
          条件分数修正头（34 参数）
                     |
             最终分数，只输出一次

修正头细节：
 r1 ---- Linear(1,8) -> ReLU -> Linear(8,2) --- a_raw -> Softplus --+
  |                                             \--- c --------+ |
  |                                                           | |
 r2 - r1 ---------------------------- multiply by a ------------+ |
  |                                                             |
 r1 --------------------------- residual add + c <---------------+
                                        |
                                       rf
```

这是有界次数的事件读出与一次融合，不为事件维护可学习隐藏状态，不按事件执行 Python 推理循环，也不反复复查。逐事件标签仍然需要 \(O(N)\) 输出；本轮解决的是无界复查和高常数邻域运算，不声称消除读取所有事件的成本。

对内部块 B，第一次分数在 100 ms 可用，最终分数在 150 ms 可用：相对第一次输出多等待 50 ms。B 内事件本身的最终观测等待为约 50–100 ms，再加处理耗时；不能只把模型前向耗时称为系统延迟。首块首次输出更晚的冷启动，以及末块无第二次完整观测的回退，都需计入全录像评估。

## 6. 训练目标与并行 TBPTT

采用训练集确定的正类权重 \(w\)，定义

\[
 \ell_w(r,y)=-wy\log\sigma(r)-(1-y)\log[1-\sigma(r)]. \tag{8}
\]

令 \(\mathcal A_c\) 为当前 TBPTT 片段 \(c\) 内实际发生的事件读出实例集合，元素 \((i,v)\) 表示事件 \(i\) 的第 \(v\) 次读出；\(\mathcal P_c\) 为本片段获得第二次读出、完成融合的事件集合。对于完整录像中覆盖两次的事件，令 \(\omega_i=0.25\)；首尾只覆盖一次的事件令 \(\omega_i=1\)。本片段按实际收集到的监督权重质量 \(m_c\) 归一：

\[
 \begin{aligned}
 m_c&=\sum_{(i,v)\in\mathcal A_c}\omega_i+0.5|\mathcal P_c|,\\
 \mathcal L_{{\rm cls},c}
 &=\frac{\displaystyle\sum_{(i,v)\in\mathcal A_c}\omega_i\ell_w(r_{v,i},y_i)
 +0.5\displaystyle\sum_{i\in\mathcal P_c}\ell_w(r_{f,i},y_i)}{m_c},\qquad m_c>0.
 \end{aligned} \tag{9}
\]

两个辅助损失维持单次读出的可用性，最终损失直接训练融合目标。若一个事件跨 TBPTT 边界，其首次读出的 0.25 权重计入前一片段，第二次读出的 0.25 和融合的 0.5 计入后一片段；不在后一片段重复计算首次辅助损失。完整录像中每个双覆盖事件的原始监督权重合计 \(0.25+0.25+0.5=1\)，单覆盖事件为 1，因此各片段 \(m_c\) 总和等于原始事件数 \(N\)。但优化器在每个片段使用 \(\mathcal L_{{\rm cls},c}\) 更新参数，各片段分母及参数版本可能不同，**这不等于将整条录像的损失一次性除以 \(N\) 后进行一次更新**。日志中的 `loss_per_event` 是原始损失和除以累计监督质量，用于汇总，不改变上述逐片段优化。\(m_c=0\) 时跳过分类项，若通信正则存在则仍可执行相应更新。实现应记录配对数、单覆盖数、跨片段配对数和输出覆盖率。

融合损失允许沿两条 logit 路径反传到同一骨干和读出头。BIR 的状态数值跨片段保留，TBPTT 边界切断计算图；若配对跨 TBPTT 边界，缓存的第一 logit 也必须在优化器更新前 detach，后侧及融合头仍可学习。这个边界限制要如实报告，不能声称任何两次读出的融合梯度都无截断。严禁跨 optimizer.step 保留旧参数版本的计算图再 backward。

训练采用原来的分流并行协议：4 条录像流、每条流 16 个连续更新为一个 TBPTT 段、每段更新一次、seed 37、50 epochs。16 次全局 50 ms 更新对应 800 ms 的时间跨度。不同录像之间彻底清空状态与待配对缓存；批内流换录像时不能继承其他录像的状态。训练、校准和评估的窗口、状态更新间隔和时间归一化必须一致。

最终执行协议统一使用 FP32，并关闭 CUDA matmul 与 cuDNN 的 TF32。训练仍使用 `layer` 分层批量计算、4 streams 和 K=16；**每个 epoch 的正式验证与 checkpoint 选择、最终 val/test 评估和 profile 均使用逐窗 `step` 执行**。CUDA 批量卷积与逐窗卷积的浮点归约顺序可能不同，微小误差可跨越 BIR 量化阈值并沿状态链传播。本地探针曾观察到默认 TF32 下两执行方式输出概率的最大绝对差约 0.005，关闭 TF32 后仍约 0.00087；这些只是该探针的观测值，不是全数据保证或误差上界。两种执行方式表达相同的数学递推和 TBPTT 训练设计，但不能声称 GPU 输出逐位相同。固定 `step` 选模和报告使正式指标对应实际部署路径，训练与该路径间的浮点差异仍属于已知实现限制。

保留历史 BIR 通信预算设置：\(B_{\rm comm}=157700\)、\(\eta=0.01\)、\(\alpha=0.05\)。若沿用原实现，正则与反馈为

\[
 \mathcal L=\mathcal L_{\rm cls}
 +\mu\,\mathbb E[(C/B_{\rm comm}-1)_+],\quad
 \mu\leftarrow\max\{0,\mu+\eta(\widehat P(C>B_{\rm comm})-\alpha)\}. \tag{10}
\]

\(C\) 是沿用 V5 口径的每次骨干更新通信计数，\(\mu\) 为非负反馈系数。超预算幅度损失和超预算频率反馈不是同一个约束目标的严格对偶推导，所以称为反馈调节的预算惩罚，不宣称严格概率约束保证。100 ms 输入 / 50 ms 更新下仍使用这个既有每次更新预算，其物理含义不等于每秒能量预算；必须同步报告每秒通信和读出开销。

## 7. 计算量、缓存与效率验证

令 \(N\) 为原始事件数，\(N_p\) 为内部配对事件数，\(N_\partial\) 为首尾单覆盖事件数。读出调用覆盖 \(2N_p+N_\partial\) 个事件实例，融合仅计算 \(N_p\) 次。附加小头每事件有 24 个线性层 MAC，外加偏置、ReLU、Softplus 和标量算术；这些非线性及内存访问不能在实测时间中忽略。

当前配置保留 5 个时间 bins、12 个输入通道，8 s 内骨干调用为 159 次，而 50 ms 非重叠基线是 160 次，密集卷积调用数近似相同。但每个 bin 的物理宽度由 10 ms 变为 20 ms，100 ms 聚合还改变活动密度及 BIR 状态动态。计数表示构造和事件 MLP 的工作量接近两倍，不能由 34 参数推出端到端几乎免费，也不能将相对 50 ms 基线的差异全部归因于融合头。

算法的待判缓存只需保存待第二次覆盖的一个 50 ms 块的索引和首次 logit，规模随该块事件数线性增长；加上本来就有的共享膜电位，不保存每事件隐藏向量或邻接图。**当前录像回放实现另外预载整条录像及展开后的事件索引/输入元数据到设备，因此整个进程的输入驻留内存并非仅一个 50 ms 块。** 这是批量回放的数据准备策略，不代表网络使用未来输入作提前判决；未来窗仍按时间顺序送入骨干。真正传感器在线驱动需要滚动输入缓冲，不能以当前实现宣称已完成该部署。训练还需 TBPTT 激活，不能用待判缓存大小估算训练显存。

效率报告必须包含相同录像、相同硬件、相同 precision 下的端到端时间、骨干时间、事件读出与融合时间、events/s、实时因子、峰值显存、每秒通信以及观测等待。计时需 GPU 同步、预热，并明确是否含磁盘 I/O、排序、整录像上传和表示构造。预载之后的逐窗计时不等于完整数据管线端到端时间。SOP/MAC 换算能耗和 GPU 板级实测能量分开命名；不能把理论操作量称为实际设备能耗。

## 8. 实验组织：从机制证据到最终精度

| 编号 | 对照 | 回答的问题 | 证据性质 |
|---|---|---|---|
| E0 | 50 ms V5 BIR carry + 原通信预算 | 历史主干基准，整体新方案是否值得等待 | 主对照需同划分、同训练预算的独立训练；旧结果只作历史参照 |
| E1 | 100/50 滑窗，首读出 / 次读出 / 两 logit 均值 | 新上下文与重复观测本身的作用 | 先做同一新权重读出诊断；不能冒充各方案独立训练的最优比较 |
| E2 | 本文条件头 | 有约束的条件修正能否超越均值 | 正式主模型，独立训练 |
| E3 | 只校准：\(r_1+c(r_1)\) | 收益是否只是单分数重新校准 | 同权重替换只属诊断；独立训练是主要因果对照 |
| E4 | 拼接 MLP：2→8→1，33 参数 | 贡献是否超出同容量的任意两分数映射 | 保持骨干、损失、预算、训练一致并独立训练 |
| E5 | 去掉辅助损失 / 固定融合系数 | 辅助监督与随首次置信度变化的条件化是否必要 | 有余力再做，不能因结果差而改用 test 调参 |
| E6 | 50 ms carry/reset 既有重训对照 | V5 状态在旧观测协议中的作用 | 已完成 seed 37；不证明新重叠协议下 carry 一定优于 reset |
| E7 | 更多种子 / 另一骨干或数据集 | 稳定性与可迁移性 | 未完成前不得写“广泛验证”或“通用插件” |

所有选择基于验证集，锁定模型、阈值及 checkpoint 后一次性报告测试集。四个主要指标保持项目定义：IoU、正事件召回（历史代码命名 ACC）、Pd、Fa；Fa 不是普通事件级 FPR，须按现有评估实现说明分母。无论输出晚多少，指标时间分组均按原始事件时间，不按输出时间移动标注。

至少报告：首读出错误被修正的数量、首读出正确被损坏的数量、按 \(r_1\) 分层的两类比例、\(a(r_1)\) 和 \(c(r_1)\) 曲线、首尾与内部事件分开指标、完整录像指标。置换后文会改变联合分布，只可作为压力诊断，不能单凭置换后的下降证明干净的未来因果贡献。

### 失败判据

1. 若条件头不优于同协议的均值或次读出，不能把条件融合写成已成立的主要贡献。
2. 若只校准对照获得同等收益，证据支持的是分数校准，不是未来上下文利用。
3. 若改善 IoU 伴随 Pd 或 Fa 明显恶化，必须报告权衡，不能只挑一项指标。
4. 若完整录像推理不能满足 20 次更新/s 的处理要求，不能宣称实时；高事件率压力测试另行报告吞吐拐点。
5. 若缺事件、重复输出、跨录像配对、训练测试状态不一致或 TBPTT 图跨优化器更新，结果作废而非解释为模型波动。
6. 若单链重叠导致重复驱动、饱和或漂移，先否定本协议的可用性；不能用条件头自动消除膜电位重复信息作为无证据解释。

## 9. 当前能写的贡献与重大局限

候选贡献是：在保留共享流式 SNN 计算的条件下，利用重叠观测明确同一事件的二次读出；以条件更新为依据，将轻量融合限制为随首分数变化且对次分数单调的残差结构；通过有界缓存和固定一次修正避免 V13 的事件邻域复查成本。这些是设计事实，性能和创新程度仍需与已有分数融合、校准及事件时序方法比较。

重大局限包括：两个标量丢失空间细节；共享 B 与状态造成的依赖未被精确分解；顺序结构依赖首次分数的质量；100 ms 表示可能使运动轨迹更模糊；单链重复驱动可能有害；Softplus 允许较大斜率，带来外推与数值风险；固定等待不能按难度节省延迟；单种子不能证明统计稳定；通信预算并非真实硬件能量保证。不能把普通重叠窗或两层 MLP 本身包装成新理论。
