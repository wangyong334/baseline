## 模型与这轮修复

主路径为：50 ms 事件窗 → 冻结 BIR 流式 SNN → 事件初始信念 → 出生决策 → 共享来源与相对关系缓存 → SDU 重审 → VoW 比较停止风险与继续代价 → 提交或等待下一窗。已提交查询停止计算，作为观测的源事件仍可供其他待判查询读取。

默认保留 `configs/bst_shared.json` 的宽度和证据预算。共享来源编码为 32 维，查询状态 16 维，两个证据头，每头关系维度 8。SDU 的旧证据权重和有符号值继续随新上下文变化；缓存只保留不会随查询状态变化的投影，不缓存动态结论。分数使用“初始分数 + 当前全部可见证据的总修正”，避免重复计入旧证据。图与公式见 [方法合同](BST_METHOD.md)、[五张架构图及说明](BST_FIGURES.md)。

本轮修复集中于会影响正式实验可信度的问题：

- 完整先验导出、数据覆盖、BIR 身份和训练/验证分区校验；不允许把短探针缓存当完整训练。
- 训练和策略拟合的种子显式保存，拒绝非法预算、非有限损失/梯度；大代价目标的 inverse-softplus 避免溢出。
- 最终评估拒绝空数据、重复策略和来源不完整的模型；缺失能耗保留 `null`，不伪装为零。
- 同一个版本冻结源代码、配置和 SHA256；两个种子独立输出；中断/失败不会覆盖旧结果，也不会显示 COMPLETE。

上一轮推理优化继续生效：批量邻域检索、追加式因果缓存、固定关系投影复用、查询槽位回收、减少同步及同输入投影融合。保留了重新审查旧证据的能力。三段同录像共 651,810 个事件、两种停止方式的 1,303,620 个输出对比中，类别、等待窗数、提交原因一致；后验最大绝对差为 4.7684e-7。

620,440 事件的 8 秒录像上，同机探针完整计算耗时由 9.600→5.489 秒（固定停止）、10.048→5.667 秒（学习停止）。这是 RTX 5060 Laptop、探针权重、同步串行测量；不代表服务器 4090 或正式训练模型的速度。完整证据见 `Res/inference_optimization_20261111/final/REPORT.md`。

本轮本地验证还包括：RTX 5060 Laptop 上四策略完整录像评估冒烟、学习停止路径两次重复输出一致性及 NVML 实际计数器采集；Python 3.8 / Torch 1.9.1 CPU 上训练、队列、指标和机制检查。真实 test_000 的完整 44,751 事件/160 窗先验导出后，一条独立抽样查询的四模式重审诊断成功；重复同前缀信念变化为零，最大贡献重建误差 4.78e-7。该权重仍是短训练探针，不据此推论正式精度收益。记录在 `Res/final_release_20261111/` 和 `Res/reconsideration_audit_20261111/query_smoke/`。

交付时测试：99 项 BST + 17 项 V11 + 10 项原 VoW，共 126 项通过；两个服务器 shell 语法检查通过。验证索引与代码 SHA256 见 `Res/final_release_20261111/VALIDATION.json`。Linux 实际调度与 4090 正式训练仍由用户上传后执行，本地测试不代替服务器运行结果。

## 正式评估实际执行什么

每个种子使用对应的已训练 BIR，完整导出 train/val/test 先验，训练 SDU，再在预留验证录像上拟合 VoW。这轮不重新训练 BIR。测试集不参与权重、阈值或策略选择。

`tools/bst/final_metrics.py` 在原始完整 test 录像上测量四条预先声明的路径：

| 路径 | 用途 |
|---|---|
| `bir` | 初始 BIR 输出，绕过 SDU；仍使用相同流式执行器包装 |
| `band_fixed` | 固定出生区间 + 固定截止等待 |
| `band_learned` | 固定出生区间 + 学习停止 |
| `learned_learned` | 学习出生 + 学习停止 |

固定区间类型以配置的 `band_kind=martingale` 为准，不冒充历史 V11 的所有版本。四条路径一起报告，不从测试结果中挑最佳路径充当预先确定的模型。

每段录像、每条路径先预热，再默认重复测量三次；保留逐事件输出并检查重复执行的分数、类别、等待窗数和提交原因。统计内容如下：

- IoU、ACC、Pd、Fa；沿用项目现有定义，ACC 需按事件目标召回口径解释。
- 等待分布、真实提交时的纠错/误伤，分别统计目标救回、目标误伤、误报消除与新增误报。
- 原始事件分布下的 Brier、NLL、15 个等宽概率箱的 ECE；内部 `sigmoid(z)` 与官方报告分数 `sigmoid(z+log_w)` 分开，不做测试集校准。
- 每段计算时间、逐窗时间、吞吐、实时因子、峰值 allocated 显存，以及源编码、SDU 更新、证据访问和缓存工作量。
- 独立额外前向的 Conv2d/Linear MAC 小计；不是全部 FLOPs，不包含转置卷积和全部非线性开销。
- NVML GPU 板卡焦耳、每百万事件焦耳、原始功率采样与测量方法。优先使用硬件总能耗计数器，缺失时用功率积分，均不可用则记缺失。

`tools/bst/audit_reconsideration.py` 额外从真实 test 录像中按固定随机规则抽取 8 个查询，不根据标签或效果挑例子。它导出旧来源随时间的权重、有符号值、归一化贡献，以及关闭重赋权、关闭重赋值、两者关闭的同权重对照，检查重复相同证据前缀的信念无漂移。结果写入 `reconsideration/audit.json` 与 `tokens.npz`。诊断强制打开查询并保留后续前缀，所以不能作为实际停止的速度或总体精度结果；零效应也会如实保留。

计时包括事件表征、BIR、邻域/缓存、SDU/VoW 和输出回 CPU；不包括磁盘加载、模型初始化、指标和写盘。逐窗 CUDA 同步，属于串行流式执行时间。证据等待是另一指标；实际部署延迟还含窗口结束前的等待、计算、排队和传输。

能耗是未扣空闲的 GPU 板卡能耗，包括显存，不能称为进程独占能耗、整机或神经形态硬件能耗。测量前后记录其他 GPU 计算进程；边界无其他进程不能证明整个区间绝对独占。近期 GPU 的功率查询可能为约 1 秒平均，短段的积分仅是估计。吞吐使用总事件数除以各录像耗时中位数之和，不平均不同密度录像的吞吐率。

## 论文判断

已核对本地拓扑/噪声两篇样板以及 HMNet、RVT、QueryDet 的原论文。借鉴的是分工、信息可用性和昂贵计算之前的门控，不照搬任务不匹配的模块。审查全文与来源见 `Res/final_release_20261111/PAPER_REVIEW.md`。

可检验的核心贡献是：共享计算下仍可重新解释旧证据的序贯读出，以及预测继续代价并真正停止查询的等待策略。缓存和 MLP/注意力本身不是独立创新。

仍需由正式实验回答三项关键风险：来源只有初始分数和极性的信息瓶颈；均值聚合对重复与独立支持的处理；VoW 是否退化为全部等待或简单置信度门控。当前是 SNN 骨干 + ANN 决策模块，学习校正不等于已经证明的精确对数似然比。不能把“主线保住了”写成“贝叶斯最优性或风险界已证明”。

两种子正式结果用于判断精度—等待—实际计算—能耗取舍。最终论文还需旧证据重审消融、同预算 V11/置信度对照和逐录像变化；同权重关模块是干预诊断，不等于重训消融。
