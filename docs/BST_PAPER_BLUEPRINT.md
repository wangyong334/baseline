# 从问题与原理到网络模块：论文组织与验证合同

> 本页保留论文样板审查和 R2 组织思路；当前 R3 结构及公式以 [R3 方法合同](BST_FINAL_R3_METHOD.md) 为准。出生年龄 0 的恒等约束和零值竞争需要分别重训消融，不能继续套用 R2 的年龄 0 精化描述。

2026-11-11。本文件说明本轮重设计应如何写清楚和验证；选定方向为 `configs/bst_window.json`：`normalization=window`、`window_gate=true`、`bounded_values=true`，宽度和邻域预算沿用共享模型。具体实现、配置与实验状态以方法文档和运行产物为准。下述实验表是预先声明的设计，不含尚未运行的性能数字。不能把公式正确、代码性质通过与检测效果有效混为同一结论。

## 1. 两篇样板真正值得借鉴的做法

已核对本地两份原文、方法架构和实验表：

- `References/CVPR论文撰稿/论文模板/2026 CVPR (拓扑结构思想).pdf`：方法第 3–5 页，模块/位置/损失迁移消融第 8 页；原文图 3–4、表 2–5。
- `References/CVPR论文撰稿/论文模板/Yuan_Seeing_Through_the_Noise_Improving_Infrared_Small_Target_Detection_and_CVPR_2026_paper.pdf`：方法第 3–4 页，组件、尺度、其他金字塔和开销第 6–8 页；原文图 3、表 2–4、表 6。中文批注与论文原文分开理解。

SpTopoNet 先给出一个反例：逐点分类损失不能充分区别事件轨迹的某些结构差异，再以拓扑约束处理该缺口。它没有把持久同调强塞进每次推理；昂贵计算留在训练损失，网络使用局部与全局关系模块体现结构假设。图 3 中的模块、损失和随后消融可以一一对应。表 4 迁移到 Ev-SpSegNet、3D-UNet、PointNet++ 的具体对象是 **EvTopoLoss**，不能误称整套 TLM/SCM 都做了同样的跨骨干验证。

NS-FPN 先区分单尺度噪声净化与跨尺度语义融合，再把 LFP 和 SFS 放进对应的数据流位置；分别验证两个组件、插入尺度、结构参数、参数量和 FLOPs。其两类任务使用 MSHNet 分割与 YOLOv8n-p2 检测。值得借鉴的是“模块职责、输入输出和实验问题对齐”，不是将小波、螺旋采样直接移植到事件序贯决策。

对本项目，论文的起点应是一个现有读出无法区分的情形：**同窗的大量重复响应，与后续时刻持续到来的支持，即使事件数或平均分数接近，也应具有不同的决策意义。** 这是待检验的建模假设，不是“不同时间窗必然独立”的事实。

## 2. 每个模块必须回答的问题

| 模块 | 具体缺陷 | 原理承担什么职责 | 网络中必需的结构 | 应出现的实验信号 |
|---|---|---|---|---|
| BIR 初始估计 | 弱事件碎片难以仅凭当前输入判定；稠密重复输出昂贵 | 有界动态状态与量化汇报，为当前可用信息形成初始估计 | 跨窗有界状态、窗口共享骨干、逐事件读出 | 状态/输出稳定，弱目标读出有效；消息减少与实际计算单独统计 |
| 共享证据 | 多个查询重复编码相同观测 | 查询无关的来源与查询相关的关系分解 | 一次来源编码、源 ID 缓存、查询相对几何、因果可见性掩码 | 同权重共享/复制计算输出一致，密集录像重复工作减少 |
| SDU 重审 | 初始压缩状态可能误解旧事件；固定旧值无法被新证据纠正 | 保留可再次读取的显式旧证据；以当前可见信息重估整组证据 | 新证据进入查询上下文；旧条目的权重和值都依赖该上下文 | 固定旧事件，仅改变新证据内容，旧贡献改变；关闭路径后效应消失 |
| 分组聚合 | 平坦求和放大重复，平坦均值淡化持续新支持 | 按观测时间块控制单块贡献，再合并不同块的信息 | 窗内归一化、跨窗非归一贡献、可解释的块可靠性/尺度约束 | 复制整窗支持不会仅靠数量无限放大；增加一致新窗在固定势条件下增加支持；反证可回退 |
| VoW 停止 | 固定等候浪费计算，置信度接近阈值不等于等待有收益 | 有限时域决策：比较停止损失与条件后续代价 | 明确停止风险；共享年龄条件 MLP 预测后续策略回报；显式行动成本和截止；实际移出队列 | 同置信度组内能区别纠错/误伤；相同等待或计算预算下更优；真实查询更新减少 |

MLP、残差、归一化和注意力在这里是实现原理所需映射与信息路径的工具。任何新增 GRU 或全局注意力都应回答它解决了上述哪一行的失败；仅使图更复杂不构成增益。

## 3. 公式必须限定正确的承诺

### 3.1 初始信念、证据势与重审

事件 \(i\) 在首次可判窗口结束时获得 \(p_{i,0}=\sigma(z_i)\)。后续可见信息形成总证据势 \(S_{i,d}(y)\)。一个有清晰优化意义的读出是：

\[
q_{i,d}=\arg\min_{q\in\Delta_2}
\mathrm{KL}(q\Vert p_{i,0})-\mathbb E_{Y\sim q}[S_{i,d}(Y)].
\tag{B1}
\]

其闭式解为 \(q_{i,d}(y)\propto p_{i,0}(y)\exp S_{i,d}(y)\)，因此：

\[
\operatorname{logit}q_{i,d}=z_i+S_{i,d}(1)-S_{i,d}(0).
\tag{B2}
\]

式 B1–B2 是给定势函数后精确的变分读出，不是势函数等于真实条件似然的证明。如果势由分类损失训练，应称为学习得到的近似概率或广义信念更新，并报告校准。

[Bissiri、Holmes、Walker（2016）](https://academic.oup.com/jrsssb/article/78/5/1103/7040623) 给出基于损失与 KL 的一般信念更新依据；它关于可加损失的顺序一致性结论，不能直接套到会随新上下文重写旧势的网络。我们的每次重审从同一个初始信念重新计算总势。若写成递推，必须使用差量：

\[
\ell_{i,d}=\ell_{i,d-1}+
\underbrace{(R_{i,d}-R_{i,d-1})}_{\text{新证据与旧证据重新解释的合计修正}},
\quad R_{i,d}=S_{i,d}(1)-S_{i,d}(0).
\tag{B3}
\]

直接用“旧分数 + 本次整组证据的总势”会重复计入旧观测。当前先验也可能已使用同一原始历史；不能将年龄 0 的精化称为获得了时间上的未来证据。它是对压缩初始估计的补充；年龄 1 之后才有后来到达的信息。

### 3.2 为什么必须在结构中体现分组

只把任意残差 \(R\) 写进 B1，并不能建立新机制，因为任何 logit 残差都可事后写成这种形式。需要由架构施加可证伪的约束。设 \(\mathcal N_{i,g}\) 是来源窗口 \(g\) 中保留的邻居，可用的结构合同为：

\[
\bar v_{i,g,h}^{(d)}=
\frac{\sum_{j\in\mathcal N_{i,g}}a_{ijh}^{(d)}v_{ijh}^{(d)}}
{\sum_{j\in\mathcal N_{i,g}}a_{ijh}^{(d)}},\qquad
R_{i,d}=\sum_{g,h}\rho_{i,g,h}^{(d)}\bar v_{i,g,h}^{(d)}.
\tag{B4}
\]

空块贡献严格为零。选定结构对有效条目使用 \(a=\max\{\sigma(\text{query-key interaction}),\epsilon\}\)，其中 \(\epsilon=\max(10^{-12},\operatorname{tiny}(\mathrm{dtype}))\)，无效条目权重为零。数值下界施加在每条有效亲和度上，再求和归一化；不能直接给组分母截断下界，否则极小亲和度时，复制整组将改变分子而分母仍被固定，破坏性质。仅对空组使用分母 1，不引入假证据。有符号值 \(v_h=s_h\tanh(\mathrm{raw}_h)\)，\(s_h>0\) 是学习的头尺度；\(\rho=\sigma(\mathrm{window\ head})\in(0,1)\) 是折扣，不是校准过的可靠概率。窗内归一化控制同一块的数量放大；跨窗非归一合并保留持续支持的路径。旧 \(a,v,\rho\) 仍需可随当前上下文改变，所以新反证可以降低旧支持。给定训练好的有限尺度，一个窗口的校正绝对值不超过各头尺度之和；这是结构界，不是真实错误概率界。

上下文摘要也先在窗内平均，再在非空窗口之间平均；VoW 的证据统计采用窗口层级。若仍将全体事件的平坦平均、原始数量或事件级有效样本数旁路输入状态，那么最后读出分组仍不能保证复制不变。可学习的 (s_h) 决定势的幅度，不把它偷换成无需选择尺度的结论。

“复制整窗不变”需要整个计算图都不使用会随复制变化的计数或平坦摘要，并且邻域选择未因此改变；不能只对最后一个均值层证明后宣称端到端不变。“新增支持单调”只在旧势、可靠性和上下文固定的受控条件下成立，完整重审允许新观测否定旧解释，故不要求全网络概率总是单调。

分窗不会让高度相关的观测自动独立；跨窗加和可能仍放大持续背景，须通过背景持续响应、时间重复和反证实验检查。单条事件复制与整组事件复制也不是同一性质，图注必须写清楚测试对象。

### 3.3 等待公式直接决定两条网络分支

与工作点一致的停止风险为：

\[
R_{\mathrm{stop}}(p)=\min\{c_{FN}p,c_{FP}(1-p)\}.
\tag{B5}
\]

继续分支输出条件后续代价，显式行动成本在网络外相加：

\[
Q_{\mathrm{wait}}(S_d)=c_{\mathrm{step}}+
f_\theta(S_d),\qquad
f_\theta(S_d)\approx\mathbb E[J_{d+1}^{\pi}\mid S_d].
\tag{B6}
\]

停止风险与继续代价比较决定实际执行路径；截止步强制提交。监督回报必须来自一个冻结、可部署的后续策略。不能逐样本根据未来真值挑最佳停止时刻后把它当作可部署目标。[FIRMBOUND（ICLR 2025）](https://proceedings.iclr.cc/paper_files/paper/2025/hash/54a1495b06c4ee2f07184afb9a37abda-Abstract-Conference.html) 是有限时域停止的重要先例，本模型并未采用其全部一致估计条件，不能继承其最优性结论。

## 4. 可证伪实验先于主表

| 问题 | 最小控制 | 通过说明什么 | 失败意味着什么 |
|---|---|---|---|
| 重复事件是否被当作新支持 | 相同上下文、完整复制同一窗口的来源集合；邻域固定 | 聚合结构的数量鲁棒性 | 计数/摘要/归一化旁路仍泄漏重复数量 |
| 持续支持是否被均值冲淡 | 固定势和可靠性，向不同合法窗口增加一致支持 | 结构保留跨窗积累能力 | 新模块仍退化成全局平均 |
| 是否真正重审旧证据 | 固定旧条目，改变新条目内容；比较 full/no-reweight/no-revalue | 旧贡献确有受控的重解释路径 | 机制只有文字描述，或上下文支路失效 |
| 反证能否改变结论 | 增加相反证据、持续背景和伪重复 | 可回退而非只增强目标 | 累积机制会放大错误历史 |
| 学习等待是否超越置信度 | 按初始置信度和标签分组；比较同预算策略 | 状态含额外的等待收益信息 | VoW 只是重新参数化阈值或全部等待 |
| 加速来自何处 | 同权重同输出，关闭缓存/投影融合分别计时 | 执行优化的独立贡献 | 速度由删证据、改截止或硬件波动造成 |

真实录像的单事件轨迹图应同时画初始分数、后验估计、阈值、总修正、旧来源贡献、停止风险和继续代价，并标实际提交时刻。提交后的轨迹只能作为离线反事实诊断，不能混入线上工作量。只展示好看的个例会偏置结论，应预先固定抽样规则并给分组汇总。

## 5. 消融与跨骨干的最小矩阵

主模块表：骨干 → 骨干+年龄 0 SDU（`band_arrival`，完成首次重审即提交）→ 骨干+固定截止 SDU → 骨干+SDU+学习停止 → 可选学习出生。年龄 0 对照隔离“已有观测上的网络精化”与“等待后续到达证据”的收益，不能只用骨干和最终网络的差值证明序贯等待有用。保持相同原始录像、划分、先验骨干与工作点。固定出生与学习出生分别呈现，不能让两条变化的路径互相替代。

SDU 表：原平坦均值、分组聚合、关闭重赋权、关闭重赋值、二者关闭。结构效果需要分别训练这些消融；同权重关开关仅回答已训练模型是否使用该路径。预算、表示维度、训练轮数等同步报告，避免容量差异解释了全部收益。

VoW 表：立即提交、固定等待、V11 区间/规则、仅置信度停止、学习等待。通过验证集选择约束工作点，再一次性测试；报告精度-等待及精度-实际工作量曲线，而非在测试集上给每种方法挑最佳点。

跨骨干接口至少包含逐事件初始分数、极性、坐标、时间和分数可用时刻，并声明加权训练分数的转换。每个骨干分别比较 `B`、`B+SDU-fixed`、`B+SDU+VoW`；每个骨干单独训练读出属于模块迁移，直接复用同一组权重才属于零样本权重迁移，两者必须区分。

BIR 和 LIF 若共享同一个 U-Net 拓扑，只能支持神经元或骨干变体的兼容性；要声称跨架构普适性，需再选择一个结构不同的因果骨干。离线完整片段网络若读取未来，不能不加说明地放入实时对比。对每个骨干都需保存来源 hash、训练种子、窗口定义、输入时间范围及验证选择规则。

跨骨干表的列建议为：骨干、读出、IoU、ACC、Pd、Fa、目标等待中位/P95、整段计算秒数、峰值显存、板卡 J/百万事件、参数量。每骨干报告绝对值和相对自身基线的变化；两种子逐一展示，统计不确定性以录像为单位，而非把相关事件当独立样本。

## 6. 论文图与方法段落的组织

总图只保留三条清楚的数据流：窗口共享骨干与初始估计、显式历史与分组重审、实际停止/等待。来源缓存与待判查询画成不同对象；共享计算不意味着共享事件标签。粗线表示可缓存张量，细线表示当前查询状态相关计算，虚线表示训练监督，避免把监督标签画进推理路径。

SDU 小图应画出两种池化轴：同窗内归一化、跨窗合并；并让“新上下文回到旧条目的权重和值分支”清楚可见。VoW 小图应有可计算的停止风险分支、非负继续代价 MLP、显式成本加法和比较器，输出箭头真实连接提交与下一窗。网络图不应隐藏哪个分支是 ANN、哪个是 SNN。

方法正文顺序建议：问题与信息边界 → 为什么已有聚合混淆重复和持续支持 → 分组重审结构及性质 → 变分读出与概率边界 → 等待决策和训练回报 → 复杂度与执行。每段先给一个设计需求，再给公式，再指向图中的对应算子，最后说明一个可以使主张失败的实验。

贡献应集中于解决问题的新分工和约束。广义信念更新、残差、注意力、共享编码、拟合停止各自已有先例，不能单独包装成首次提出。两篇模板的组织方式支持“明确问题与机制证据”，不支持仅凭公式或架构图宣称达到 CVPR 水平。
