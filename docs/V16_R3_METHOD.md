# V16 r3：BIR 与单一上下文修正模块

本轮只运行 seed37 完整模型。保留 V5 的 BIR、跨窗状态、通信约束、原事件读出和分流并行 TBPTT；在 V16 r2 的匹配骨干上微调。没有更改 0.9 推理阈值，也没有宣称能保证达到 90% IoU。

## 问题与论文组织

论文的两个组成部分是 **BIR 通信表达**和**有限等待的上下文判决修正**。不再把后者硬拆为两个创新模块。

1. 有限时间步下的脉冲通信表达受限：沿用 BIR 的有界分级状态与变化通信；通信预算损失仍参与训练。
2. 即时判决无法使用随后到达的观察：100 ms 观察窗每 50 ms 推进，同一中间片段获得两次上下文观察，最后一次覆盖时统一输出。跨窗膜电位已有历史记忆，因此不能把问题描述成“完全没有过去信息”。

重叠窗口是组织观察的机制，不作为首次提出的贡献。方法需要解决的是：两次相关观察怎样互补，而不把共同活动当成两份独立确认。

## 原理的准确边界

“条件上下文修正”是本模块的描述名称，不是已有标准滤波算法。数学起点是条件贝叶斯恒等式。对于二分类标签 Y 和相关观察 O1、O2：

\[
\operatorname{logit}P(Y=1\mid O_1,O_2)
=\operatorname{logit}P(Y=1\mid O_2)
+\log\frac{p(O_1\mid Y=1,O_2)}{p(O_1\mid Y=0,O_2)}.
\]

它不需要 O1、O2 条件独立，说明补充信息必须在已有观察的条件下解释。这里选择较新的 O2 为计算基准，O1 提供额外区分线索；在线依然按 O1 到达、缓存、O2 到达、联合输出的顺序执行。它不是基于停止边界的经典 SPRT。

**网络并未显式拟合上述条件密度。** 原读出使用加权分类损失，新目标又面向固定工作点，因此其 sigmoid 值不能直接当作校准后验概率。本文实现应称“受条件证据更新启发的判决修正”，不能写成精确贝叶斯滤波、卡尔曼滤波或已证明的错误率界。

范文设计逻辑的对应：观察实际缺陷 → 用条件信息组织问题 → 将约束写成可检验结构 → 在训练目标中体现误报与漏报代价 → 用同容量对照验证。没有套用范文的小波、频域、高斯滤波或拓扑方法。

## 一个模块的公式与结构

V5 原读出对同一个事件产生两组隐藏特征与分数 `(h1,z1)`、`(h2,z2)`。h 为原 MLP 的 32 维 ReLU 激活，无新增 U-Net、GRU 或事件邻域搜索。两次观察以原始事件索引精确配对。

为防止极少数大幅值通道主导修正，用不依赖训练统计的有界缩放：

\[
\psi(h)=h/\sqrt{1+\operatorname{mean}(h^2)},\quad
a_j=[\psi(h_j),\operatorname{softsign}(z_j)],\quad d=a_1-a_2.
\]

这是每事件内部的缩放，不混合样本或窗口，不从验证集拟合均值方差。通道 RMS 小于 1，不表示每个通道都小于 1。原 z2 的幅值通过残差主路保留。

\[
c=W_c a_2+b_c,
\quad u=\operatorname{SiLU}(c+W_d d)-\operatorname{SiLU}(c),
\quad\Delta=\kappa\tanh(w_o^T u),
\quad z_f=z_2+\Delta.
\]

默认 hidden=8、kappa=2。`Wd`、输出投影不设偏置，输出投影零初始化。

```text
两次共享 V5 BIR U-Net 读出，保留原始事件 ID
       h1,z1                       h2,z2
         │                           ├──────────── z2 主路 ─────┐
      有界缩放 a1                  有界缩放 a2                  │
         └────────── a1-a2 ── Wd ──────┐                       │
                               a2 ─ Wc+bc ─ c                  │
                                        │                     │
                         SiLU(c+Wd·d) − SiLU(c)                │
                                        │                     │
                                 Linear → tanh × κ ─────── 加法
                                                              │
                                                sigmoid、固定0.9输出
```

这是一条条件残差路径。r2 的“共识分数 + 残差修正”两条路径被删除，避免一个把分数拉向第一次、另一个再拉回第二次。

可以直接测试的结构性质：

- 初始化时 `zf == z2`，新增模块不会立即破坏已有读出。
- **当 h1=h2 且 z1=z2 时，任意训练权重下 Δ=0**。相同观察不会机械地增信。
- `|Δ|≤κ`，可正可负；能补回目标，也能降低背景分数。
- 两次观察的梯度都可以经过共享读出回传骨干；跨 TBPTT 边界只截断旧计算图，缓存值仍保留。

这些性质不等于完整分离了共同 B 信息。不同上下文下的同一 B 通常产生不同特征，其共同信息仍可能被错误学习；需用单次观察、打乱配对等对照检查。

## 损失函数：固定工作点与正样本保留

旧加权 BCE 对新增漏检的惩罚很大，会倾向多报目标。本地同模型、同容量实验已复现“召回增、误报增、IoU 降”。因此最终融合输出不用继续重复同一 WBCE30。

设 a=logit(0.9)，第二次分数停止梯度为 sg(z2)。

\[
\ell_f=\operatorname{BCEWithLogits}(z_f-a,y)
+\lambda_r y\,1[\operatorname{sg}(z_2)\ge a]
\left[\min(\operatorname{sg}(z_2),a+m)-z_f\right]_+^2.
\]

默认 lambda_r=5、m=1。第一项把训练分类边界与固定推理工作点对应；第二项只保护训练集中已被第二次观察正确检出的目标。它不保护背景的错误高分，也不要求继续追逐极端正分数。它是软约束，不保证测试召回不下降；参考随骨干更新，并非固定教师。

配对事件：

\[
\ell_{pair}=0.25\ell_{WBCE}(z_1,y)+0.25\ell_{WBCE}(z_2,y)+0.5\ell_f.
\]

仅覆盖一次的首尾事件保留原 WBCE，权重为1。每个原始事件监督权重合计1，避免重叠事件因为出现两次获得双倍权重。仍加入原通信预算项。权重总和相同不代表各项梯度代价相同。

没有在推理端变更阈值；但新损失会改变分数校准。这应如实报告，不能称作纯结构收益。单次/双次对照必须使用相同损失。

## 训练与选模

- 从已完成的 r2 seed37 匹配骨干加载；旧融合头丢弃，新模块为零修正初始化。
- 沿用 train99，val24，4 streams、TBPTT16、greedy whole-record、每chunk更新；原窗口表示与膜电位步长不变。
- 最多20轮，头学习率3e-4线性降至3e-5；骨干及原读出为其0.1倍。最少10轮后启用6轮验证 IoU patience。
- 新训练开始前完整验证初始化模型并保存为 epoch0 候选。后续只按全验证集累计 TP/FP/FN 的 micro IoU 选模型。
- 如果最佳仍是 epoch0，报告“未超过初始化”，不宣称新模块有效。
- 完成后自动验证、测试和测速。测试不参与本轮探针、损失选择、早停或阈值选择。
- 这是从已有模型微调的实验；论文训练总成本需同时报告初始化来源和微调成本，不能当作从头训练仅20轮。

## 计算和消融

默认修正头544参数、536线性MAC/配对事件，低于r2的833参数、1088MAC。MAC不包含SiLU、缩放、tanh、数据搬运和骨干。事件仍批量O(N)读出与修正，没有逐事件Python循环、每事件GRU或动态近邻检索。

缓存只保留下一次覆盖要用的半窗 `(h1,z1)` 与ID；其内存仍随半窗事件数增长，未宣称与事件率无关。对超高事件率需要单独压力测试。重叠表示和骨干自身的计算并没有消失。

`full`：两次观察的上述模块。
`no_context`：同544参数/536MAC，使用a2代替差分输入，完全不访问第一观察，验证增益是否只是单次校准。
`no_revision`、`second`：直接z2，无可训练修正头。

本轮仅运行full seed37。其余配置保留用于后续独立训练，不会自动放入池子。BIR本身消融应另行组织，不能把两个旧融合分支当作论文两个模块。

## 风险和判断标准

1. 两次观察可能都误判；32维读出也可能已经丢失区分线索。新模块不能恢复从未编码的信息。
2. 当第二次分数离阈值超过kappa，修正不能翻转结论；有界稳定性以部分可修复性为代价。
3. 骨干微调可能让原来的好特征退化；低学习率、原读出监督与epoch0验证候选只能降低风险，不能保证测试改进。
4. 目前冻结探针增益小，不支持宣称“解决所有背景误报”或“保证90%”。需要正式seed37结果；后续跨种子和独立消融才能支撑论文贡献。
5. 相同第二次读出和同容量单次修正是关键对照，不能只比较一个失效的旧完整模型。
