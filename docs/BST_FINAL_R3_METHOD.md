# R3：以出生信念为参考、允许拒绝证据的序贯重审

2026-11-11。实际入口：`configs/bst_final.json`。本文对应实现，不代表正式两种子训练已经完成。保留 `bst_shared.json`（平坦均值）和 `bst_window.json`（R2）作为可重训对照。发展线 CLAUDE.md 本轮不更新。

## 问题如何导出架构

逐事件任务仍需逐事件标签，但昂贵的来源编码、窗口索引和固定几何投影可以共享。待判查询保留自己的状态及来源列表；后续新观测到达后，允许重新解释旧来源，不能用一个不可逆均值代替它们。R2 已实现这个结构，同时区分同窗归一和跨窗累积。

R3 修复两个不同的问题，分别保留消融开关：

1. **相对权重不能表达整组不可信。** 如果所有亲和度同时乘上很小的数，普通归一化的输出完全不变。即使所有候选都不匹配，仍被强制分配全部质量。新增可学习的零值竞争分支，把绝对支持程度留在聚合结果里。
2. **读取历史不等于获得新观测。** BIR 初始分数已经依据过去及出生窗的信息产生；直接再加历史势可能在年龄 0 就大幅改判。新增出生参考势，输出只使用当前势相对出生势的变化。新证据仍可改变旧来源的解释，因此不是只累加新 token。

两者都来自算子的性质和信息可用性，不是根据某段录像调出的阈值。它们提供结构约束，不能保证训练后精度一定提高。

## 1. 初始信念与共享来源

每个事件在其 50 ms 窗口结束时获得 BIR 初始分数 \(z_i\)，内部初始信念为 \(p_i^{\rm init}=\sigma(z_i)\)。这不是事件到达瞬间的零延迟预测。官方报告分数的类别权重变换另行处理，不能与内部概率混用。

BIR 沿用原有流式 SNN，不重新训练。SDU 来源编码器读取 `[z_j, polarity_j]`，经 Linear → LayerNorm → SiLU → Linear → SiLU 得到 32 维共享特征。两头固定键/值投影及相对几何投影缓存；当前查询、动态亲和度和动态值不跨更新缓存。状态宽度 16、每头关系维度 8。

每个窗口最多保留 8 个近邻和 8 个证据候选，过去 10 窗、出生窗、最多未来 10 窗，共至多 336 个槽位。这是选中证据的预算，**不是保留所有原始事件**；候选之外的证据不可重审。查询构建使用当前已见各窗的平衡摘要与上次状态，归一化不跨查询、录像或未来时间。详细固定投影与查询公式见 R2 方法合同 W1–W2。

## 2. 零值竞争与窗级势

对已到达的来源窗 \(g\)，令 \(n_{ig}=|\mathcal N_{ig}|\)，两个头分别产生亲和度与有符号值：

\[
a_{ijh}^d=\sigma(A_h(e_j,r_{ij},q_i^d)),\qquad
v_{ijh}^d=s_h\tanh(V_h(e_j,r_{ij},q_i^d)),\quad s_h>0.
\]

\(A,V\) 的固定来源/关系部分可复用，查询部分随新上下文重算。学习两个正的 null 参数 \(\nu_h=\mathrm{softplus}(\eta_h)+\epsilon\)，null 的值严格为 0：

\[
w_{ijh}^d=\frac{a_{ijh}^d}{\sum_{k\in\mathcal N_{ig}}a_{ikh}^d+n_{ig}\nu_h},\qquad
S_{igh}^d=\sum_j w_{ijh}^d,\qquad
m_{igh}^d=\sum_j w_{ijh}^d v_{ijh}^d. \tag{R1}
\]

空窗贡献为 0。\(1-S\) 是归一化运算中的零分支质量，**不是已校准的不相关概率**。有效亲和度不施加正数下限，零支持不会被数值保护改成均匀支持。\(\epsilon\) 仅保证 null 分母正且数值稳定。

窗门控仍为 Linear(33,16) → SiLU → Linear(16,2) → Sigmoid，从查询、该窗上下文及相对窗龄得到折扣 \(\rho_{igh}^d\)。当前总势为：

\[
F_i^d=\sum_{g,h}\rho_{igh}^d m_{igh}^d. \tag{R2}
\]

这里不在窗口轴做 softmax，也不把已经包含 \(S\) 的 \(m\) 再乘一次 \(S\)。来源上下文用同一权重混合后按非空窗数平均，不能再除以接受质量，否则会抵消 null 的作用。上下文更新为初始锚点加一个受 \(\bar S_i=\mathrm{mean}_h\sum_g\rho_{igh}S_{igh}/|G_i|\) 控制的残差：

\[
c_i^d=c_i^{\rm init}+\bar S_i\tanh(\mathrm{MLP}([\bar e_i,F_{ih}^d,\log(1+M_i)])). \tag{R3}
\]

原始值、折扣、接受质量及其乘积分别导出，不能只画注意力热图就声称解释了网络。

**可直接检查的性质：** 对固定查询和固定已选来源，把同一窗内全部 token 复制相同次数，R1 的分子总量、分母两项同步放大，窗势不变；这不保证 top-k 选取前任意重复事件都不影响结果。固定有界值下，全组亲和度趋零时，该组势趋零。若整个当前前缀都拒绝，当前原始势为零、上下文残差归零。新来源先参与可见摘要，因此这些性质不等于“被拒绝来源在网络所有路径上都无影响”。

## 3. 出生参考的序贯创新

在出生时计算并保存 \(F_i^0\)。训练图中它保留梯度，推理中其数值保持不变。任意后续前缀读出：

\[
\Delta_i^d=F_i^d-F_i^0,\qquad
\ell_i^d=z_i+\Delta_i^d,\qquad p_i^d=\sigma(\ell_i^d). \tag{R4}
\]

因此正常首次出生时 \(\ell_i^0=z_i\)。年龄 0 的前缀 BCE 对势网络梯度抵消；模型从后续前缀学习有用变化。空出生前缀的参考为零，后续真正到达的证据仍可更新。没有新增选中来源时保持当前信念，避免重复调用同一前缀造成漂移。

R4 也可以写成 \(\ell_i^d=\ell_i^{d-1}+F_i^d-F_i^{d-1}\)。本实现直接替换总修正，不在每一步重复加上旧证据。旧 token、旧窗的权重、值及折扣都可以变化，出生贡献被扣除而不是丢弃旧 token。解释导出按来源给出“当前贡献减出生贡献”，总和重建实际输出。

**必须保留的边界：** 后期全部拒绝得到的是 \(\ell_i^d=z_i-F_i^0\)，不是必然回到 \(z_i\)；这表示撤回出生时的势。只有出生势也为零才回到初始信念。R3 明确放弃年龄 0 的历史再校准收益，以保持“后续观测驱动修正”的语义；`no_innovation` 消融用于检验这个取舍。

对于给定的 \(\Delta\)，以下变分目标有精确闭式解 R4：

\[
p_i^d=\arg\min_{p\in(0,1)}\mathrm{KL}(\mathrm{Ber}(p)\Vert\mathrm{Ber}(p_i^{\rm init}))-p\Delta_i^d. \tag{R5}
\]

一阶条件为 \(\mathrm{logit}(p)-z_i-\Delta_i^d=0\)，二阶导数正。这个恒等式解释先验锚定的形式；**它不证明学习势是真实条件似然比**。跨窗相关性、共享 BIR 历史和查询依赖仍在，不能据此宣称精确 Bayes 更新、独立增量或风险上界。若每窗势有界，则 \(|\Delta_i^d|\le(|G_i^d|+|G_i^0|)\sum_hs_h\)，这是幅度界而非分类错误界。

## 4. VoW：预测后续代价，再决定是否等待

当前停止风险由当前内部信念和预先声明的误报/漏检代价给出：

\[
R_{\rm stop}(p)=\min(C_{\rm FN}p,C_{\rm FP}(1-p)),\qquad
\mathrm{wait}\iff R_{\rm stop}(p_i^d)>c_{\rm wait}+Q_\psi(f_i^d). \tag{R6}
\]

\(Q_\psi\) 为非负输出 MLP，预测冻结后续策略的条件剩余代价。训练目标使用验证拟合分区的真实标签计算后续分类损失及等待成本，逐轮固定策略生成目标；不是把截止输出视为真值，也不是只预测分数会变化多少。训练/选择/策略拟合录像分离，测试集不参与选择。

出生头在昂贵 SDU 之前，根据因果局部上下文预测进入后的总代价，并与直接停止比较；保留固定入口对照。学习入口有机会覆盖固定区间之外的错误，但能力与校准仍需正式数据检验。已提交查询退出后续计算，源事件仍可供其他查询读取。固定每步成本不是物理焦耳；决策更早也不自动保证墙钟时间更短。

## 5. 训练计算与无损部分

本轮没有降低目标样本数量、邻居预算、训练轮数或损失权重来制造提速：

- 按来源窗合并 KD-tree 查询，结果回填原槽位，保留距离并列、去重、边界及自排除规则。
- 每个录像按原随机顺序准备有限大小的邻居 ID 缓存；默认预算 64 MiB，只限制常驻 ID 数组，不是整个进程 RAM 上限。临时相对几何按批构造。
- 保留原 SGD 批次及顺序；每次优化步重新计算学习特征，只复用静态几何。
- 每个前缀只处理已可见槽位；所有可见旧 token 仍参与重审。固定来源/关系投影仍在同一批内共享。
- 持续输出录像与查询进度、阶段耗时；JSON 和 epoch 权重用原子替换写入。没有新增中途恢复训练功能。

旧均值模型相同录像、相同权重的实测等价性与速度见 [R3 交付记录](BST_FINAL_R3_RELEASE.md)。新机制本身会改变输出，不能要求新模型与旧模型逐分数一致；无损验证针对计算实现，结构改动用重训消融验证。

## 6. 论文证据与尚未解决的问题

`experiment_matrix.py` 对新配置生成 10 个重训变体。`full / no_null_evidence / no_innovation / window_r2` 构成 2×2；另外六项是旧均值、关闭重权、关闭重值、两者都关闭、关闭窗门控、去掉有界值。旧均值同时移除多个结构，不能作为单独证明跨窗累积的受控消融。所有变体保留相同训练及证据预算；同权重关闭模块的解释诊断不替代重训消融。

正式五策略是 BIR、固定入口年龄 0 提交、固定入口固定截止、固定入口学习停止、学习入口学习停止。R3 的年龄 0 路径应与 BIR 同分数，用于验证零创新边界；它仍执行一次 SDU，所以不应同耗时。正式报告同时保留 IoU/Pd/Fa、救回与误伤、校准、等待时间、完整原始流推理时间及 GPU 板卡能耗。

能构成贡献的候选是**共享计算下保留旧证据重新解释，并以出生参考与零值竞争约束后续修正**，以及**用真实后续代价学习等待且在执行器中实际退出**。缓存工程、常见注意力/MLP、漂亮架构图本身不是独立贡献。

仍可能失败的原因包括：来源仅有初始分数和极性，不能恢复骨干已经丢失的全部语义；候选预算之外的证据不可恢复；学习势/停止风险未经充分校准；固定入口阻止高置信错误被重审；null 只提供拒绝能力，不保证学会拒绝；学习等待未必减少真实计算。需要正式两种子、相同预算的 V11/置信度对照以及其他骨干迁移实验，才能判断贡献强度；不能先保证达到 CVPR 发表标准。
