# V19：存在性证据树突（模块一的升级）

11-14 晚。V18 已定型（`docs/V18_METHOD.md` 第 0 节）；V19 只升级判决单元的树突（模块一），胞体、停止规则、判决脉冲、骨干都不动。代码是开关，默认值仍是 V18：`--dendrite existence --ring on --clutter on --content ring`（`model/sdu.py` 的 `association_prior`、`_existence`；`tools/v18/train_sdu.py`）。测试 `tests/test_sdu_v18.py` 的 `V19Tests`（44 项全过，py3.8 / torch 1.9.1 与本地 GPU 环境；V17 的 17 项也过）。本地真实数据小试：训练、评估、流式回放（单层与协同）都跑通，流式与离线 0 处不符。

## 2. 原理：整合概率数据关联的存在性似然比

一个待定事件的单元在每一窗检验两个假设各自的"源存在"：这一窗里，源要么漏检（概率 1 − P_D），要么窗里的某个事件就是它的检出。窗里同一个方框的事件得分相同，于是这一窗相对"只有杂波"的似然比是

- **E1（每个方框的得分）** score_hb = log g_h(r_b, k) + ℓ_hb − κ_h · log(1 + E_b)
  - log g_h(r, k) = b_h − (r − v_h k)² / (2 s_h(k)²) − log(s_h(k)·(v_h k + s_h(k)) / σ_h²)，s_h(k)² = σ_h² + (w_h k)²：**扩展的关联环**。方向未知、每窗约走 v_h px 的源，k 窗后在半径 v_h k 的环上，环随时间变宽；最后一项按环的面积 ≈ s·(R + s) 归一化（概率守恒，k = 0 时为 0）。v_h = w_h = 0 时就是 V18 的固定距离场。b_h 是读者 h 在它所属假设里的混合权重（对数）。
  - ℓ_hb：**内容似然比**，方框统计量（计数、先验分数和，按同 / 反极性；协同版另有两项判决脉冲数）的线性模型，系数按（窗偏移，环）共享，**同一环上的方框共用一套**（目标可以往任何方向走，没有偏好方向），被上下文平移（以过去为条件）。没有按位置的偏置：几何只由关联环表达。
  - E_b = ρ̂ · 面积_b：方框里**预期的杂波事件数**，ρ̂ = 单元整个方块（243 px）里"像背景的事件"（计数 − 先验分数和）/ 在画面内的像素数。减 κ_h log(1 + E_b) = 把方框的事件数除以 (1 + 预期杂波)^κ：**除法归一化**，看的是"超出杂波预期多少"。
- **E2（一窗的电流，每个假设一个）** λ_g = log( 漏检_g(c) + Σ_{h∈g} Σ_b n_b · exp(score_hb) ) = log 漏检_g（≤ 0，"该来的没来"的反证）+ softplus(log D_g − log 漏检_g)（≥ 0，检出的证据），g = 目标 / 背景。同一假设的两个读者（一近一远）是关联先验的两个混合成分，共用**一次**检出和一个漏检概率，所以每个假设每窗只贡献一个观测（前提 (ii)），不会因为读者多而重复计数。漏检_g(c) = sigmoid(m_g + u_g · c)。
- **E3（胞体）** U(k) = U(k − 1) + λ_目标 − λ_背景：目标假设兴奋、背景假设抑制；停止规则不变。
- 附带的可解释量：读者与方框的后验关联 β_hb = n_b exp(score_hb) / (漏检_g + D_g)（就是概率数据关联里的 β），"本窗检出了源"的概率 1 − β_0 = D_g / (漏检_g + D_g)，以及它在近 / 远读者之间的分配。
- 11-14 自查后的两处修正：（1）原来每个读者各算一个 log(漏检 + …) 再相加，等于同一窗算两次，改为每个假设一个混合；（2）环的归一化由 s² 改为 s·(R + s)。

与已有消融一致：去关联 −0.016、逐事件相加 −0.010（应"先求和再取对数"）、方框当观测 −0.008（候选量测按事件计）、单个有符号通道等得更久（两个假设分开算）、去伪观测 test 3/3 更低（漏检项必须有）。

## 3. 模块图（按 NS-FPN 图 3 的画法）

```
模块一  存在性证据树突（每个待定事件一个，每来一窗走一步）
 证据场（每窗一张积分图：计数、先验分数和，按极性）──► 中央凹采样：中心 + 4 个环，33 框
   ├─► ① 关联环  log g(r, k)：环半径 v·k、宽度 √(σ² + (w·k)²)          ← 窗偏移 k
   ├─► ② 内容似然  θ[k, 环] · x_b + 上下文平移                          ← 上下文 c
   └─► ③ 杂波归一化  −κ · log(1 + ρ̂ · 面积)，ρ̂ = 像背景的事件 / 像素
        ⊕ ─► + log n_b ─► Σ exp（各方框）─► ⊕ 漏检项 1 − P_D(c) ─► log ─► λ_h（目标 2 路 / 背景 2 路）
                                                                     └─► β_hb（后验关联）→ 上下文更新
模块二  序贯判决胞体（不变）：U ← U + Σ sign·λ → 收拢界 b_k → 发放（标签 + 判决脉冲给邻居的 ②）
```

画图要点：中央凹采样的小插图画成同心方环，叠一个随 k 外扩的关联环（类似 PACT 的多假设采样、NS-FPN 的螺旋采样插图）；①②③ 三路并排汇入 ⊕；漏检项画成 log-sum-exp 前面的一个"空槽"；E/I 两路用两种颜色。

## 4. 与 V18 比

| | V18（mean） | V19（existence） |
|---|---|---|
| 一窗的贡献 | 归属加权平均（有上限） | log(漏检 + Σ 事件数 × e^得分)：对数增长 |

## 5. 初始化与可解释输出

新参数取对称初值：两类假设的读者各一近一远、初始环速 ≈ 0.13 px/窗、κ = 1、漏检 0.5；内容系数和上下文平移为 0，所以训练开始时膜电位严格等于先验（测试 `test_starts_at_prior`）。训练后 `learned_constants` 给出每个头的环速、环宽增长、σ、κ、漏检概率。预期（待验证）：目标读者学到每窗 2–3 px 的外扩环、κ 接近 1；背景读者环速接近 0（背景源不动）。诊断：学到的关联环 vs 实测同源比例（窗偏移 × 层），后验关联 β 的纯度随窗数，漏检份额随杂波。

## 6. 实验与采用规则

- 开发（种子 0）：V19 单层 × 3 骨干；v5s37 上的消融：去关联环（`--ring off`）、去杂波归一化（`--clutter off`）、按框的内容系数（`--content box`）、V18 平均形式 + 关联环 + 杂波（`--dendrite mean --ring on --clutter on`）。
- 最终：V19 单层 3 骨干 × 3 种子（第一层），协同 3 × 3（第二层读第一层判决脉冲，`--stage1 run/v18/<骨干>/v19_s<种子> --spikes feature`）。
- 采用（按用户 11-14 的标准：精度过 0.9 后看原理与可解释性）：V19 协同 9 次 test 平均 ≥ 0.90，val 比 V18 定型低不超过 0.003，流式 0 处不符 → V19 取代 V18 作为论文模型；否则论文用 V18，V19 的诊断作分析。种子 0 三个骨干如果 test 平均 < 0.90 或 val 比同骨干 base 低 0.005 以上，就删掉还没开始的最终轮作业。

## 6b. 第二个数据集 EV-Flying ×4（11-14 晚，分支 V19）

- 分辨率 320 × 180：所有步骤设 `EVUAV_SENSOR=180,320`（训练写进配置，评估、分析、回放核对；数据目录有 `data_card.json` 时分辨率不对会直接拒绝）。它决定证据场的大小和官方 Fa（每像素虚警）。

- 训练轮数 2：按 EV-Flying 骨干配置的规则"总更新次数与 EV-UAV 相当"，EV-Flying 一轮约 1.7 万批，已超过 EV-UAV 8 轮的约 1.1 万批；2 轮是挑选最好一轮所需的最少轮数。V18 与 V19 用同样设置。

## 6c. 结果与最终配置（11-14 晚，结果包 `Res/v18_results_20261114_192238.tar.gz`）

种子 0，3 个骨干平均，与同骨干 V18 base_s0 比（val / test / 判决层 mJ per 8 s）：

| 版本 | val | test | 能耗 |
|---|---|---|---|
| V18 base | 0.9043 | 0.9068 | 0.326 |
| V19 环共用内容（`--content ring --ring on --clutter on`） | 0.9001 | 0.9081 | 0.242 |
| V19 按框内容（`--content box --ring on --clutter on`） | 0.9038 | 0.9069 | 0.386 |
| v5s37：平均形式 + 环 + 杂波 | 0.8924（base 0.8923） | 0.9183（0.9189） | 0.146 |
| v5s37：环共用内容去环 / 去杂波 | 0.8894 / 0.8894（V19 0.8896） | 0.9155 / 0.9174 | 0.162 / 0.138 |

协同 9 次：V19 环共用内容 val 0.9006 / test 0.9086，比 V18 定型（0.9039 / 0.9094）val 低 0.0033，按规则不采用。流式回放 600 条录像记录中 1 处不符（v5s38 v19c_s1 test_016，|dU| 2.6e-6，界上压线）。

- 存在性公式本身不损失精度（按框内容 −0.0005）；V19 低的 0.004 来自"环共用内容系数"。
- 学到的参数（两种内容形式一样）：环外扩速度 0.11–0.14、环宽增长 0.12–0.14 px/窗，停在初值 0.127；近读者 σ 26–37 px（V18 学成 5–13 px）；κ 0.84–1.22（初值 1）；漏检概率目标 0.39–0.45、背景 0.53–0.58。原因：存在性得分里位置先验与内容在同一个指数里相加，按（窗偏移，环 / 框）的内容系数能表达任何径向偏好，关联环不可辨识。第 5 节"目标读者学到每窗 2–3 px 的外扩环"的预期没有实现，论文不能主张学到的外扩。
- **最终 V19（11-14 晚定）**：存在性树突 + 按框内容 + 杂波归一化，去掉关联环（按框偏置完全覆盖它）：`--dendrite existence --content box --clutter on`。关联环、环共用内容保留为消融开关。代码默认值仍是 V18（卡 2 上的 V18 作业依赖默认值）。测试 `V19F` 配置：从先验出发、单窗公式、流式 = 离线、协同。
- 最终轮：第一层 `v19f` 3 骨干 × 3 种子，协同 `v19fc`（STAGE1 = `run/v18/<骨干>/v19f_s<种子>`）。采用规则同第 6 节：协同 9 次 test ≥ 0.90，val 比 V18 定型低不超过 0.003，流式不符只允许界上压线。

EV-Flying（V18 第一层，V5-EVF 种子 37 先验，2 轮）：判决层几乎没有作用。种子 0 test 0.7355（骨干 0.7353），val 全部等到截止也只从 0.8388 到 0.8395，进单元 82%；种子 1 第 2 轮训练发散（val 截止 0.7577），按 step0 选了第 0 轮，test 0.7134，等待反而变差。可纠正的骨干错误只有 5%（EV-UAV 约 48%）。原因（已有记录，CLAUDE.md 第 2.1 节与 11-01 目标统计）：(1) 标签由框导出且有漏标（10-16 定：不补标），虚警里有一部分其实是未标目标，精度上限被压低；(2) 目标快而短命：每窗位移 p50 / p95 4.7 / 25 px（EV-UAV 2.3 / 5.6），寿命中位 5 窗（EV-UAV 42），75% 的窗没有目标，等 10 窗时源早已离开方框，等待能积累的证据很少。在 EV-Flying 上不再跑新版本，论文作为补充数据集并解释为局限。

## 7. 不主张 / 风险

- 不主张精度提升；主张的是"每一项都由原理推出、有实测动机、学到的参数可解释"。
- log-sum-exp 介于"平均"和"相加"之间，而"相加"之前变差过，精度可能略降。
- 杂波密度用骨干先验区分"像背景的事件"，与骨干的错误相关（同 V18 的局限）。
