# V15：用后续新观测修正早期共享特征

本文件描述实现与待验证假设，不预先承诺精度提升或 CVPR 接收。V15 保留 V5 的 BIR、跨窗状态、通信约束和分流并行 TBPTT。它采用原生 50 ms 不重叠输入，每窗只运行一次骨干；相邻输入在延迟判决时共享上下文。它与 V14 的 100 ms 原始事件重叠窗口是两种实验协议。

## 1. 问题与切入点

流式 V5 在第 t 窗结束时已有历史，却还没有第 t+1 窗的观测。稀疏小目标可能需要后续局部活动才能消除当前的歧义。增加判决等待时间，可以获得这些观测；但是直接把下一窗的深层特征当作独立证据存在一个结构问题：下一窗的深层特征也含有旧膜电位。

以 BIR 的状态递推表示：

\[
M_{t+1}=\operatorname{clip}\{\lambda M_t+(1-\lambda)(I_{t+1}-k),0,D\theta\}.
\]

即使没有新的输入活动，历史项仍可能非零。因而“后续深层响应仍然很强”不能直接解释为“获得了新的独立确认”。这不证明深层融合一定不好；它给出一个可比较的设计问题：**能否在保留状态记忆的同时，让用于修正的观测来源明确独立于状态递推？**

采用状态估计中“历史估计与新测量分开”的组织方式。这里借鉴组织原则，不声称实现了卡尔曼滤波或精确贝叶斯更新，也不估计物理运动状态、协方差或似然比。

两篇范文的启发是设计步骤：先分析矛盾，再以原理约束信息通路，最后用消融验证。没有移植红外论文的频域分解、低频引导高频、螺旋采样，也没有移植拓扑损失。

## 2. 公式与信息来源

### 保留主干状态，提取无时间状态的观测

\[
(F_t,S_t)=\operatorname{V5}(X_t,S_{t-1}),\qquad
I_t=G_1\operatorname{Conv}_1(X_t).
\]

- X_t 是原 V5 的 12 通道事件计数表示，窗内 5 个时间 bin 是输入通道，不是额外 SNN 时间步。
- F_t 是最后一个解码层的连续膜电位特征，尺寸 12×264×352，包含此前信息。
- I_t 是**第一层**膜电位递推前的驱动电流。来自这次前向已经计算的卷积，不重新跑网络。V15 配置禁止时间归一化、噪声不变性分支、双记忆等额外机制，因此 I_t 只依赖 X_t 与共享参数。更深层的“电流”已经受上游记忆影响，不能替代这里的 I_t。

紧凑观测编码：

\[
E_t=\phi(I_t)=\operatorname{SiLU}(W_e\operatorname{SpaceToDepth}_4(I_t)+b_e).
\]

4×4 像素先搬到通道，随后 1×1 投影为 12 通道，得到 12×66×88。搬运本身不丢值，投影是有损压缩；不能把 E_t 称为原始事件的无损表示。没有跨时间 BatchNorm、GRU 或额外状态。

### 以旧窗为查询，读取下一窗的局部新观测

\[
q_t(u)=W_q[\operatorname{AvgPool}_4(F_t)(u),E_t(u)],
\quad k_{t+1}(v)=W_k E_{t+1}(v),
\quad v_{t+1}(v)=W_v E_{t+1}(v)+b_v.
\]

查询包含旧窗的语义和局部细节；键和值来自新的观测。每个查询只读取粗网格上 5×5 的局部邻域，3 个头，每头 4 维。学习的相对位置偏置允许不同位移偏好。该范围是计算预算选择，不是由某个种子的误差挑出的速度阈值，也不是任意运动保证。

增加一个值为零的“无合适对应”选项：

\[
\alpha_{uv}^{h}=\operatorname{softmax}_{v\in\mathcal N(u)\cup\{\varnothing\}}
\left(\frac{q_t^h(u)^\top k_{t+1}^h(v)}{\sqrt{d_h}}+b_{v-u}^h\right),
\qquad m_t^h(u)=\sum_{v\in\mathcal N(u)}\alpha_{uv}^h v_{t+1}^h(v).
\]

物理传感器之外（含补齐画布中的纯 padding patch）的采样被屏蔽。有效尺寸为 260×346，画布为 264×352；跨边界的部分 patch 保留有效子像素，池化与插值按有效支撑归一。补零区域不作为观测，最终不修正传感器外特征。空匹配概率是网络中的关联权重，**不是校准后的目标概率或拒判风险上界**。

### 修正旧特征，再沿用 V5 读出

\[
\Delta_t=\operatorname{Up}(W_o m_t),\quad
g_t=\sigma\big(W_g[F_t,\Delta_t,\operatorname{Up}(\alpha_{\varnothing})]+b_g\big),
\]
\[
F_t^{+}=F_t+a_t\,g_t\odot\Delta_t,
\quad z_i=\operatorname{MLP}_{V5}[F_t^{+}(x_i,y_i),p_i,\tau_i],\quad i\in t.
\]

a_t 表示是否真的取得下一窗。录像结束时 a_t=0，严格回退 F_t；有下一窗但其中没有事件时 a_t=1，允许网络学习“观测到静默”的作用。不能把静默和缺失混为一谈。

W_o 零初始化，使初始主输出精确等于 V5；门控不零初始化，第一步 W_o 可以获得梯度。修正是有符号的，可以提高或降低目标响应。修正结果**不写回 S_t**，不改变主干的状态时间轴。

## 3. 架构与重复信息的边界

```text
当前 50 ms 输入 X_t ──→ V5 BIR U-Net ──→ 历史状态 S_t ──→ 下一窗骨干
                        │         │
                  第一层电流 I_t  末层特征 F_t
                        │         │
                 无状态编码 E_t   ├── 暂存一窗
                        └── Q_t ──┤
                                  │
下一窗新输入 X_{t+1} ─→ 同一次 V5 前向，取得 I_{t+1}
                                  │
                       无状态编码 E_{t+1} → K,V
                                  │
                         有空匹配项的局部读取
                                  │
                         有符号残差 × 细粒度门控
                                  │
                            旧特征 F_t^+
                                  │
                    原 V5 事件 MLP，一次给旧窗事件出分
```

没有从混合深层 F_{t+1} 中“剥离 B”的逆问题；没有假设分到不同输入通道之后普通卷积仍会保持时间来源独立。来源隔离发生在明确的第一层电流接口。

消除的是两类**实现上的重复**：原始事件不重播到同一状态链，修正值不回灌为主干历史。没有消除场景本身的时间相关性，也没有保证共享参数下的特征统计独立。E_t 和 F_t 同时用于构造查询，不被当成两份独立概率相乘。

最终目标是条件判别 P(Y_t | X_{≤t+1}) 的学习近似。它不是 P(Y|A,B)P(Y|B,C) 的乘法，更没有把普通 attention 等同于贝叶斯序贯检验。核心假设是“明确的新观测来源 + 有范围限制的对应读取”能提供更可靠的修正，必须由对照支持。

## 4. 损失与训练

\[
\mathcal L=\tfrac12\mathcal L_{\rm det}(z_t^{+},Y_t)
+\tfrac12\mathcal L_{\rm det}(z_t,Y_t)+\mathcal L_{\rm comm,V5}.
\]

检测损失沿用 V5 加权 BCE 和训练集统计的正类权重上限 30。每个事件的两个监督权重合计为一；尾窗直接回退时不重复加权。辅助因果监督用于保持原读出的可用性，不要求前后输出强制一致。通信损失沿用 V5 的消息峰值约束、预算 157700、对偶更新及 α=0.05，不另造预算。这个约束不覆盖新增实值模块的 MAC。

r2 中所有统计缓存均核对训练集来源，续训同时核对训练集和验证集的文件清单、配置与源码；短探针权重不会标记为正式完整结果。

主实验从头训练 seed37、50 epochs、4 条流、K=16、原学习率和增益校准。主干在每个片段内按层并行运行；局部读取批量处理窗口对，禁止逐事件建档、邻域图或循环状态更新。

因果损失在当前窗立即计算，最终损失在取得未来观测时计算；每次更新按本次监督质量（0.5×当前事件数 + 0.5×定稿事件数）归一，完整一轮总质量等于原始事件数。这样 K=1 也不会失去骨干的当前窗梯度。融合损失在片段内部可以反传至旧窗 F_t、旧观测编码、新观测编码、共享骨干与原读出。跨 TBPTT 边界只保留上一窗的数值缓存并 detach；只有延后的旧特征梯度被截断，不能称为完整跨片段反传。录像边界清空对应流，不能用下一条录像的第一窗修正上一条录像。

每轮验证集按在线 step、FP32、关闭 TF32 评估并选最佳 val IoU。最终只用这个权重做完整 val/test。训练的层并行与在线逐窗在数学上等价，但 BIR 量化可能放大 GPU 核函数的舍入差异，因此不承诺 GPU 两种执行路径逐位一致，选模与最终报告使用同一路径。

## 5. 计算量与时延

设每窗事件数 N、全分辨率像素数 HW、粗网格 P=HW/16、宽度 d=12、邻域 K=25。新增局部读取复杂度 O(PKd)，而不是 O(P²) 或 O(N²)。投影和全分辨率门控分别是 O(Pd²) 和 O(HWC²)。V5 最后的事件特征索引及小 MLP 仍为 O(N)，主推理只运行一次事件 MLP，不把 O(N) 说成零成本。

默认尺寸下模块有 3,474 个参数，每次新观测编码加一对修正为 48,996,288 稠密 MAC，由 `ObservationRevision.dense_macs()` 按实际结构计算；包括观测编码、Q/K/V、空匹配点积、局部 QK/AV、输出投影和门控，不包括 softmax、激活、插值、访存等。因此 MAC 比例不能代替实际速度或能耗。

缓存为一个旧窗的 F_t、E_t、原始事件索引及 p/时间。F_t 在 FP32 下约 4.25 MiB/流，E_t 约 0.266 MiB/流；事件元数据随 N 增长，没有 N×隐藏维度×多轮状态。训练激活和梯度内存明显大于推理缓存。`pair_batch` 只限制局部展开的工作区，不能把整段 autograd 内存也解释为只保留四对。

内窗额外等待固定 50 ms，加上切片采集和计算；多数事件采集等待约 50–100 ms，尾窗回退。离线吞吐、单步耗时、采集等待和模拟实时积压分别报告。NVIDIA 板卡能耗采样包含空闲、输入处理等开销，不是纯模型能耗或类脑硬件能耗。

## 6. 实验组织与重大风险

默认只排主实验 observation_s37。独立重训对照：

| 组别 | 修改 | 检验问题 |
|---|---|---|
| observation | 第一层膜前电流编码为新观测 | 主方法 |
| deep | 相同局部读取模块，但来源改为深层 F | 来源隔离是否有益，而不只是多一个模块 |
| causal | 原 V5、同状态/通信/训练协议，没有延迟修正 | 相对骨干收益和代价 |

同一权重关闭未来修正只作为路径诊断，不能替代 causal 的独立重训。阈值扫描只展示取舍，不能据 test 改阈值或选模型。固定主阈值沿用 V5。四项指标保持原 EV-UAV 口径，其中 ACC 在本项目是目标事件召回率，Pd/Fa 保留历史实现的边界约定。

风险必须正面回答：

1. 第一层观测可能缺少语义，深层融合可能更有效。deep 对照是关键否证实验。
2. 静态背景也具有连续性，局部相关不等于目标。门控不能提供误报保证。
3. 极小目标可能在紧凑投影中丢失；快速运动可能超出局部范围；插值修正可能扩散背景。
4. 额外固定等待可能不适合严格低时延任务，需要同时报告精度和实际释放时延。
5. 跨片段 pending 特征被 detach，最后一对的旧分支梯度有截断；不能声称每对都完整端到端。
6. 加权 BCE 输出不是校准概率。没有精确贝叶斯、独立信息分解、未来收益下界或 CVPR 新颖性保证。

若只在单种子主指标涨一点、deep 同样涨，不能把来源分离当作已验证贡献。若几乎不使用未来，或因果对照更好，应保留 V5/V14 的已完成结果并如实收缩论文主张。

## 7. 原理背景资料

- [Recurrent Kalman Networks, ICML 2019](https://proceedings.mlr.press/v97/becker19a.html)：学习观测与递归状态估计的结构组织。
- [KalmanNet](https://arxiv.org/abs/2107.10043)：将已知递推结构与可学习更新结合；本实现不采用其滤波器。
- [TF-Blender](https://arxiv.org/abs/2108.05821)：时序特征融合已有先例，因此 attention 或延迟融合本身不作为“首次”。
- [TDNet](https://arxiv.org/abs/2004.01800)：视频语义分割中的时间分布式计算，提醒评估准确率与计算复用两方面。
