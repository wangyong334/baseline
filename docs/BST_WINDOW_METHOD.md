# 最终窗口分组模型：原理、结构与可检验性质

> 本页描述保留的 R2 模型。R3 的零值竞争、出生参考公式与限制见 [R3 方法合同](BST_FINAL_R3_METHOD.md)，其改变不是旧权重的无损替换。

2026-11-11。当前新模型配置为 `configs/bst_window.json`，旧 `bst_shared.json` 保留为平坦均值基线。新模型需要重新训练 SDU 和拟合 VoW；不能把旧权重、旧等待策略换一个名称作为新结果。本文是实际实现的方法合同，配套图与论文组织见 [BST_PAPER_BLUEPRINT.md](BST_PAPER_BLUEPRINT.md)。

## 1. 先明确问题，而非先选择网络层

目标事件稀疏、局部证据含混，需要后续观测纠正初始判断。难点不只是保留更多历史，而是：同一时间段的重复响应与后续时间段持续到来的支持具有不同含义；新证据又可能否定先前对旧事件的解释。

原代码已对每个窗口最多保留 16 个来源，不能把它描绘成不加限制地遍历所有原始事件。剩余问题是各窗有效邻居数仍可能不同，而对所有条目做一个总均值，会把跨窗持续支持也放进归一分母。旧网络的 mass 上下文可能学习数量作用，但直接聚合没有显式区分这两个轴。

本次改动据此确定两个不同的运算：**同窗内归一、不同窗间累积**。窗口表示观测的采集单位，不代表条件独立性。一个窗口的势再用学习折扣和有界值控制；不是规定后验只能越来越自信。

## 2. 三个模块的原理分工

| 模块 | 原理如何进入结构 | 对应实现 | 验证对象 |
|---|---|---|---|
| BIR 初始估计 | 有界泄漏状态、量化汇报、多尺度窗口共享读出 | 现有 BIR U-Net 与神经元，保持不变 | 弱目标初始估计、状态与消息；不把稀疏消息等同 GPU 跳算 |
| SDU 重审 | 显式保留旧来源；当前上下文重新决定旧势；窗内归一、跨窗可加；初始信念加当前总势 | SharedSequentialModel + WindowEvidence | 重复鲁棒性、持续支持、反证重审、来源缓存等价 |
| VoW 等待 | 有限时域条件代价比较；外部当前成本与网络预测的未来回报分开 | 非负代价 MLP、停止风险公式、比较器、截止与退出队列 | 纠错/误伤、同预算等待收益、真实工作量 |

SDU 与 VoW 是 ANN 决策头，BIR 是流式 SNN。该模型不能称为全脉冲架构。来源输入保持 `[初始分数, 极性]`，便于挂接具有相同因果输出契约的骨干；这同时保留了上游压缩信息丢失的局限，不宣称获得了多尺度语义特征。

## 3. 公式与图中的算子逐一对应

### 3.1 共享来源与窗平衡查询

每个事件在其 50 ms 窗口结束时可获得初始分数 z_i，初始概率估计记为 p_i^init = sigmoid(z_i)。来源编码只运行一次：Linear → LayerNorm → SiLU → Linear → SiLU，宽度 32，产生两头键/值投影及 16 维上下文。相对位置、时间与窗口偏移单独编码，缓存不含随查询状态变化的动态量。初始上下文锚点记为 c_i^init，令 c_i^(-1)=c_i^init，使 d=0 的查询也有明确定义。

令 N_ig 是查询 i 在来源窗口 g 中保留的邻居；u_j 是共享来源上下文。进入当前查询的可见摘要为：

\[
\bar u_{ig}=\frac1{|N_{ig}|}\sum_{j\in N_{ig}}u_j,\qquad
\bar u_i=\frac1{|G_i|}\sum_{g\in G_i}\bar u_{ig},\qquad
q_i^d=\mathrm{LN}\left(c_i^{d-1}+W_e\bar u_i+W_a d/D\right).\tag{W1}
\]

G_i 仅含已经到达的非空来源窗，空窗贡献零。归一化不跨查询、录像或未来时间。当前新证据在产生查询 q 之前进入摘要，因此本次就能改变旧证据解释。来源分组使用缓存的窗口索引，以 scatter reduction 实现，不构造全事件两两注意力。

### 3.2 每条旧证据仍可重权和重值

\[
\begin{aligned}
a_{ijh}^{d}&=\sigma\left(\langle K_{ijh},Q_h(q_i^d)\rangle/\sqrt r+b_{ijh}\right),\\
v_{ijh}^{d}&=s_h\tanh\left(w_h^\top\mathrm{SiLU}(U_{ijh}+V_h(q_i^d))+b_h\right),\\
s_h&=\mathrm{softplus}(\xi_h)>0.
\end{aligned}\tag{W2}
\]

K、U 包含固定来源与相对关系投影；Q、V 是轻量查询投影。默认两头、每头 8 维。a 是非负亲和权重，v 是可正可负的学习势，不将二者解释成已校准的同源概率和真实似然比。尺度 s 每头一个参数，初始化为 1，由前缀分类损失训练。

### 3.3 窗内归一与跨窗折扣

\[
\alpha_{ijh}^{d}=\frac{a_{ijh}^{d}}{\sum_{k\in N_{ig}}a_{ikh}^{d}},\qquad
m_{igh}^{d}=\sum_{j\in N_{ig}}\alpha_{ijh}^{d}v_{ijh}^{d}.\tag{W3}
\]

数值实现对有效 a 逐条施加 `max(a, 1e-12)` 后再求组内分母；填充条目仍严格为零，空组分母置 1。这个固定数值保护保留整组复制性质，也避免极小分母在反向中溢出。极端下溢时窗内亲和退化为均匀，并非把小分母截断后改变一组的总质量；常数不从实验精度挑选。低精度类型另用其最小正规数作为下限。

每个窗口的上下文用 alpha 在头间平均后的系数汇总来源，记作 t_ig。窗口折扣网络为 Linear(33,16) → SiLU → Linear(16,2) → Sigmoid：

\[
\rho_{igh}^{d}=\sigma\left(\mathrm{MLP}([q_i^d,t_{ig}^{d},\Delta w_{ig}/D])\right)_h,
\qquad R_i^d=\sum_{g\in G_i,h}\rho_{igh}^{d}m_{igh}^{d}.\tag{W4}
\]

这里不在窗口轴做 softmax。rho 是学习折扣，不是可靠性概率；rho 与 v 的分解也不唯一，应同时报告两者及其乘积。无窗口门消融将 rho 设为 1；无界值消融去掉 W2 的 tanh/尺度约束。空窗口始终 rho=0。

上下文用窗口折扣加权后归一汇总，输入各头总修正与 log(1+窗口折扣质量)，经 MLP → tanh，残差锚定初始上下文 c_i^init。原始事件计数仅用于检测是否有新增来源和记录工作量；VoW 接收非空窗数、窗口折扣质量及窗口层级的有效权重数量，避免计数旁路破坏复制性质。

### 3.4 从总势到信念的闭式读出

对每个固定前缀，定义 Bernoulli 分布的 KL 正则化目标：

\[
p_i^d=\arg\min_{p\in(0,1)}\mathrm{KL}(\mathrm{Ber}(p)\Vert\mathrm{Ber}(p_i^{\mathrm{init}}))-pR_i^d,
\qquad \ell_i^d=z_i+R_i^d.\tag{W5}
\]

这是对给定势 R 的精确闭式解，代码直接执行残差加法和 sigmoid。p_i^0 表示年龄 0 读取历史后的精化输出，可以不同于 p_i^init；这一步尚未获得事件出生之后的后续时间窗。年龄 1 及以后才引入后来到达的观测。无须额外 KL 训练惩罚。前缀 BCE 仍是学习目标，按已有抽样概率校正分布。

KL 公式本身不是创新：任意 logit 残差都能反写这种目标。真正限制网络行为的是 W1–W4 的分组、归一、有界与重审路径。R 由新上下文重算，因此若写递推必须使用 R_d−R_(d−1)，不能将整批旧势再次相加。也不能从广义 Bayes 的固定可加损失定理继承本网络的顺序一致性或校准保证。

### 3.5 VoW 的公式直接控制执行

\[
R_{stop}(p)=\min\{c_{FN}p,c_{FP}(1-p)\},\quad
Q_{wait}(S_d)=c_{step}+\mathrm{softplus}(\mathrm{MLP}(S_d)),\quad
\mathrm{wait}\iff Q_{wait}<R_{stop}.\tag{W6}
\]

误报/漏报代价由官方阈值对应的内部阈值统一确定。继续网络的 26 维输入是 16 维上下文及 10 项因果统计。它学习冻结后续策略的条件回报：

\[
f_\theta(S_d)\approx\mathbb E[J_{d+1}^{\pi}\mid S_d],\qquad
J_D^{\pi}=\mathcal C(a_D,Y),\qquad
J_d^{\pi}=\begin{cases}c_{step}+J_{d+1}^{\pi},&\pi\text{继续},\\\mathcal C(a_d,Y),&\pi\text{停止}.\end{cases}\tag{W7}
\]

离线未来标签只构成监督，不输入推理网络；不逐样本挑未来最小错误作为“等待收益真值”。既有策略迭代与可选出生头保留。W7 中 D 是该查询的有效截止，即 min(配置最大等待窗数, 录像结束前剩余窗数)，并非每个事件均能再等 10 窗。截止必须提交，提交事件退出查询计算。当前配置的 wait_cost 是固定步骤代价，不伪称测量得到的 GPU 焦耳成本。

## 4. 能证明什么，不能证明什么

1. **整组复制性质**：固定骨干输出、相对几何和选中邻域，从同一初始状态开始，将某窗的全部条目完整复制相同倍数；W1、W3、W4、上下文和后 SDU 的 VoW 特征保持不变，浮点容差除外。并不保证任意单事件复制、重新邻域选择、原始事件流经过 BIR，或使用原始网格计数的可选出生头不变。
2. **受控累积性质**：固定旧上下文、势和折扣，新增同向窗口使 R 按 W4 增加。完整网络允许新反证下调旧势，故不主张概率全程单调。
3. **势的界**：固定训练好的有限尺度，每窗绝对贡献不超过 sum_h s_h，总修正不超过非空窗数乘 sum_h s_h。新观测能改全部旧窗，所以不能说一次新观测的总改变量只有一个窗口的界。此性质不是误报率或改判风险上界。
4. **时间因果与不重复记账**：未来来源被掩码，无新增证据时信念冻结，仅推进策略年龄；重审替换总势，不重复累积旧势。

最重要的负控制是持续同形背景：不同窗口可能仍强相关，该背景也可能积累。必须实际检查反证是否降低旧势、长时背景是否误报增加、VoW 是否仍全等或只重参数化置信度。两种子正式精度与跨骨干实证未完成之前，不宣称这些困难已被解决。

出生筛选也是能力边界：直接提交的高置信错误不会被后续 SDU 挽回。默认固定出生区间与可选学习出生需要单列比较，不能只在已进入 SDU 的事件上证明收益后推广到所有漏检。当前来源只含初始分数和极性，几何由相对关系补充；上游已经丢失的语义无法保证恢复。

## 5. 消融、迁移与部署

可重训消融包括 full、no_reweight、no_revalue、no_reaudit、legacy_flat_mean、no_window_gate、unbounded_values。关闭 reweight 同时将 token affinity 与窗口折扣的查询输入固定到初始锚点；关闭 revalue 固定旧值分支。旧 mean 参考的参数数量略不同，不能当作严格参数匹配单因素对照。

每个骨干各自比较原始输出、年龄 0 历史精化后立即停止、固定截止 SDU、学习停止、学习出生。年龄 0 对照用于区分历史重新解释与等待后来时间窗的收益。按骨干和种子独立导出来源、训练 SDU、拟合 VoW，不能复用 BIR 的分数尺度或策略。代码接口兼容不代表跨架构性能已经验证；同一 U-Net 的 LIF/TIF/BIR 只是骨干变体。真实跨架构实验需要另一种因果骨干适配器和权重，见 [迁移协议](BST_TRANSFER_PROTOCOL.md)。

新模型主实验使用新的 release 标签与 `--config configs/bst_window.json`，旧任务快照不改。已有完整精度/耗时/能耗评估脚本复用；新结构与旧结构输出允许不同。缓存等价检查比较的是新模型自身的缓存/重算路径，而不是要求新架构模仿旧模型输出。
