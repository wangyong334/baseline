## 0. 一句话

流式脉冲骨干每 50 ms 给每个事件一个先验。先验已经够确定的事件当场定案；其余事件各生成一个**双房室判决神经元**：
- **树突（模块一）**：每来一窗，在共享证据图上读周围 33 个方框，算出"目标假设"和"背景假设"各自这一窗的**存在证据**。原理是整合概率数据关联（IPDA）的存在性似然比；"该来的没来"本身就是反证。
- **胞体（模块二）**：从先验出发，目标证据兴奋、背景证据抑制，逐窗积分。一旦膜电位越过在留出数据上校准、随年龄收拢的界，就发放一次并定案。

判决单元分两层：第一层冻结；它的判决脉冲写进证据图，第二层把脉冲数当作额外的方框统计量读入。

## 1. 数据：从原始事件到每个模块的输入

### 1.1 数据集与划分

- EV-UAV：147 条录像，官方划分 训练 / 验证 / 测试 = 99 / 24 / 24；传感器 346 × 260 像素；每条约 8 s（160 个 50 ms 窗）。
- 每条录像一个 `.npz`（`<数据根>/<split>/<name>.npz`）：
  - `ev_loc`：x、y、t（毫秒）；
  - `evs_norm`：第 3 列极性、第 4 列逐事件标签（目标 / 背景）、第 5 列目标编号。
- 选择（轮次、配置、规则、超参数）只看验证集，测试集只报告。

### 1.2 切窗

每个事件属于第 s = ⌊t / 50 ms⌋ 窗。骨干和判决单元都按窗运行，事件只能在自己那一窗结束时或之后定案。

### 1.3 骨干的输入（每窗一张 12 通道图）

- 正 / 负极性的整窗计数（2 通道），加上把 50 ms 分成 5 个时间箱、每箱每种极性的计数（10 通道），共 12 通道。
- 编码 X = clip(log1p(C) / q99, 0, 3)；q99 是在训练集上统计的 99% 分位数归一化常数（细节见 `configs/evisseg_stream_tif_comm_peak.yaml` 与数据读取代码 `dataset/ev_uav_stream.py`）。
- 每个事件另带自己的极性 p 和窗内时刻 t_local，供逐事件读出使用。

### 1.4 先验文件（骨干训练好、冻结后一次导出）

- `tools/deco/dump_z0.py` 对每个划分的每条录像逐窗运行冻结骨干，存每个事件的先验 `z0_<split>/<name>.npz`：轨迹第 0 列、`log_w`、`window_ms`。
- 先验在"校准尺度"上：z0 = 骨干 logit − log w，w = 骨干训练时的正样本权重（30）。
- 官方阈值 0.9 换到同一尺度：τ = logit(0.9) − log w = 2.197 − 3.401 = −1.204。Z ≥ τ 就是官方判为目标。
- 读入时把 z0 截到 [−20, 20]，NaN 记为 −20；先验个数与事件数不符直接报错。
- 三个骨干种子 v5s37 / v5s38 / v5s39 各一套先验（服务器 `EV-UAV-v8-rcl41/run/deco/<骨干>/z0_*`，其他目录用链接）。

### 1.5 判决层的输入

| 输入 | 从哪来 | 说明 |
|---|---|---|
| 事件 (x, y, 窗, 极性, 标签) | 1.1 / 1.2 | 极性按"与本事件相同 / 相反"使用，整体翻转极性时结果不变 |
| 先验 z0 | 1.4 | 胞体起点、入口判断、证据图里的目标分数 |
| 截止步 F | F = min(10, 录像最后一窗 − 事件窗) | 判决单元最多走 11 步（第 0 步 = 事件自己那一窗）；录像末尾的事件步数更少 |
| 证据图 | 每窗由事件与先验建（第 5 节） | 所有单元共用 |
| 第一层判决脉冲（只给第二层） | 冻结第一层的定案结果（第 7 节） | 位置、窗、类型 |

### 1.6 方框统计量的标准化

训练开始前，从训练集按抽样概率每条录像抽至多 400 个事件，在它们所有有效步、所有方框上统计每个统计量的均值和标准差（只统计证据统计量，不含脉冲数）。另统计 z0 的均值和标准差，用于状态初值。之后训练和推理都用这组固定的数（存在模型里）。

## 2. 总体结构（每来一窗）

```
事件流 ─► 每 50 ms 一窗（12 通道计数图）
   │
   ├─► 骨干：BIR 流式脉冲 U-Net（冻结，105,777 参数）─► 每个事件的先验 z0
   │                                                       │
   │        ┌──────────────────────────────────────────────┤
   │        ▼                                              ▼
   └─► 共享证据图（每窗建一次）                   入口：|z0 − τ| ≥ b0 ？── 是 ─► 当场定案（用先验）
         每像素、每极性：事件数 n、目标分数和 q             │ 否
         （第二层另有：第一层的目标 / 背景判决脉冲数）       ▼
                   │                              生成判决单元（每个不确定事件一个）
                   └──── 读 33 个视网膜式方框 ───► 树突（模块一）：每个假设本窗的存在证据
                                                   胞体（模块二）：U ← U + 目标证据 − 背景证据
                                                   |U − τ| ≥ b_k → 发放一次 = 定案 + 判决脉冲
```

每个事件最终只有一个标签：要么入口定案（第 0 列），要么判决单元在第 k 步发放（第 1 + k 列）；截止或录像结束时强制定案。

## 3. 骨干：BIR 流式脉冲 U-Net（V5，冻结）

| 部件 | 内容 |
|---|---|
| 结构 | 7 层脉冲 U-Net：编码 enc1–4、解码 dec3–1，通道 12 / 24 / 48 / 48；3×3 卷积 + 逐通道增益（训练前用训练集校准一次）；转置卷积上采样 + 跳连。状态跨窗保持（流式） |
| 神经元 BIR（有界积分上报，代码名 tif） | M_t = min(ReLU(λ M_{t−1} + (1 − λ)(I_t − κ)), Qθ)，q_t = round(M_t / θ)；不复位，只发送变化量 m_t = q_t − q_{t−1}；λ、κ、θ 按通道学习，Q = 7。重建误差 ≤ θ/2，输入沉默时状态在有限步内归零 |
| 逐事件读出 | 小 MLP，输入 = 事件所在像素的 dec1 状态、极性、窗内时刻 → logit |
| 损失 | 加权二值交叉熵（正样本权重上限 30）+ 每窗消息数的峰值机会约束：一窗的非零消息数超过预算 B 的比例 ≤ 5%。B = 同结构 LIF 网络在验证集上的每窗平均消息数（EV-UAV 157,700）；用对偶上升自动调乘子；消息数的梯度用 \|Δx\| 的无偏代理 |
| 训练 | 有状态截断时间反传（TBPTT）：4 条并行流，每段 16 窗（0.8 s），50 轮；按验证集 IoU 选权重 |
| 代码 / 权重 | `model/lif2d_stream.py`（`StreamingTIF2d`）、`model/evspsegnet_stream.py`、`utils/comm_budget.py`、`train_stream_v1.py`、`configs/evisseg_stream_tif_comm_peak.yaml`；Git 标签 `v5-frozen`；服务器权重在 `EV-UAV-v8-rcl41/log/` 下（种子 37：`stream_tif_commpeak_msg_seed37/best_val_iou_seed37.pt`） |

- 骨干训练好后冻结，判决层的训练与推理都不改它。
- 骨干到达即判 test IoU（3 骨干 × 3 判决种子的平均口径）为 0.8660。
- 跨平台：消息量化使少数事件的先验在不同 GPU 上略有不同，论文数字一律用服务器结果。

## 4. 入口与停止规则（"下方窗口"校准；不训练，第一层、第二层都用）

把一个事件的判决轨迹排成列：Z_0 = z0（第 0 列，还没有单元），Z_{1+k} = U(k)（第 k 步的膜电位），ℓ = 最后一列（截止或录像结束）。事件在第一个满足 |Z_c − τ| ≥ b_c 的列定案，否则在 ℓ 强制定案。

- **风险**：在第 c 列以余量 m 定案、但截止时结论不同的概率（"之后还会改判"）。只比较"现在的结论"和"截止时的结论"，不需要标签。
- **校准**（`tools/v18/stopping.py`，`rule="window"`）：
  1. 逐列，在仍未定案的验证事件上，从最大余量往下按固定顺序检验候选界。
  2. 对每个候选界，取它**下方紧邻**的 n_w 个事件，计算它们改判率的 Clopper–Pearson 上界；上界 < α 则通过，继续往下。
  3. 第一次不通过就停，b_c 取最后通过的界。
  - 依据：改判概率随余量不增，所以下方的事件不比界上的事件少改判。
- **常数**：α = 0.01（声明的改判风险）；δ = 0.1（置信度，11 列平分）；n_w = 4 × 468 = 1872。
  - 468 是零改判时以置信度 δ/11 证明 α = 1% 所需的最少事件数；一个窗口最多容许 8 次改判（0.43%）。
  - 倍数 4 是唯一手定的常数。2 / 4 / 8 精度完全不变，只改开销：进单元 26.9% / 9.2% / 5.2%。
- **收拢包络**：b_c ≤ b_{c−1}。越接近截止，剩下能改变结论的证据越少，界自然变窄。
- **入口**：第 0 列就是入口。先验已满足 |z0 − τ| ≥ b0 的事件当场定案，不生成单元。所以"谁进判决层"是校准的结果，没有手设区间。V18 定型约 9% 的事件进单元，但各骨干差异大（v5s39 约 18%）。
- **验证集的诚实数字**：验证集分两半，各用另一半校准的界评估。测试集用全部验证集校准的界。
- 这条规则取代了 V17 的"保序块逐块检验"：旧规则下，一处晚改判就让某列的界变成无穷大，等待与能耗随种子跳变。

## 5. 共享证据图与方框读取

### 5.1 证据图（每窗、每种极性建一次，所有单元共用，不搜索邻居）

- 事件数图 n(x, y) 和目标分数和图 q(x, y) = Σ σ(z0)。
- 以整数定点积分图存储：任意方框的和只要 4 次查表，与求和顺序无关，所以流式与离线逐位一致。
- 第二层另有两张图：第一层判决脉冲的目标数 s_T、背景数 s_B（第 7 节）。
- 长录像（EV-Flying）按窗分段建图，每段 ≤ 1.5 GB（`EVUAV_MAP_GB`），每段多带单元往后要读的 10 窗；特征与整段建图相同。

### 5.2 视网膜式方框

- 以事件为中心，共 4 级：第 0 级是 3×3 个 3 px 的方框；往外每一级是上一级外面一圈 8 个、边长 3 倍的方框（9、27、81 px）。
- 共 33 个方框，不重叠地铺满 243 px 的正方形：近处细、远处粗。

### 5.3 每个方框、每窗的统计量

| 统计量 | 含义 |
|---|---|
| log(1 + n_同极性)、log(1 + n_异极性) | 方框里的事件数 |
| log(1 + q_同极性)、log(1 + q_异极性) | 方框里的目标分数和（骨干认为"像目标"的程度） |
| 画面内比例 | 方框落在画面内的面积比例（画面外不等于"没有事件"） |
| 第二层另加：log(1 + s_T)、log(1 + s_B) | 方框里第一层的目标 / 背景判决脉冲数（本事件自己的脉冲扣除） |

- 第 0 步把事件自己从中心方框扣掉。
- 第 k 步读事件之后第 k 窗。窗不存在（超过截止或录像结束）时该步无效，不计损失。
- 没有事件的方框对证据没有贡献，直接跳过（平均每窗约 21 个非空框），计算量随事件活动而变。

## 6. 判决单元（双房室脉冲神经元）

配置（V19 最终版）：`--dendrite existence --content box --clutter on`（关联环 `--ring off` 是默认），其余为 V18 默认：`--tokens glm --gate distance --audit ledger --context on --context-ff off --dim 32 --heads 4 --value ei --pool window --evidence events --levels 4`，11 步。参数：第一层 11,696，第二层 15,120（多两项方框统计量）。

四个读者（头）：目标假设一近一远（h = 1, 2），背景假设一近一远（h = 3, 4）。

### 6.1 状态（上下文）：按已经看到的证据读新窗

- **初值**：c0 = 线性层([标准化的 z0, 极性])，宽度 32。
- **累计和**：单元只保存三个，关联量 M = Σ β、按关联加权的统计量和 X = Σ β x̃、各假设累计证据 L = Σ λ（β、λ 见 6.2）。
- **更新**：每读一窗后 c = c0 + W_o (X / M) + W_m [log(1 + M), L]。
- **作用**：平移内容系数（6.2 的 Δθ、Δβ），并决定漏检概率。去掉状态在 V18 上 val −0.0088（3 骨干）。
- **存储**：每个单元约 60 个数（膜电位、状态、三个累计和），不缓存历史窗，每步计算量恒定。

### 6.2 树突（模块一）：每个假设本窗的存在证据

第 k 步、方框 b（事件数 n_b > 0）的计算分三步：

**1. 得分** score_hb = 关联先验 + 内容 − 杂波项

| 项 | 公式 | 含义 |
|---|---|---|
| 关联先验 | b_h − r_b² / (2σ_h²) | r_b 是方框中心到事件的距离；σ_h 是读者 h 学到的半径；b_h 是读者在所属假设里的混合权重（对数） |
| 内容 | θ[k, b, h] · x̃_b + β[k, b, h] + Δθ_h(c) · x̃_b + Δβ_h(c) | x̃_b 是标准化的方框统计量。系数按"窗偏移、方框、读者"各一套，状态整体平移（FiLM）。系数可以直接画成图看每个读者在哪里、读什么 |
| 杂波项 | κ_h · log(1 + E_b) | E_b = ρ̂ · 面积_b 是方框里预期的杂波事件数；ρ̂ = 单元本窗所有方框里"像背景的事件"（计数 − 目标分数和，截到 ≥ 0）÷ 画面内像素数。等于把事件数除以 (1 + 预期杂波)^κ，看"超出杂波预期多少" |

**2. 存在性汇合**（每个假设 g 一个）

同一假设的两个读者是关联先验的两个混合成分，共用一次检出、一个漏检项，所以每个假设每窗只算一次观测。
- 检出项 D_g = Σ_{h∈g} Σ_b n_b · exp(score_hb)：框里的每个事件都可能是这个源的检出。
- 漏检项 miss_g(c) = σ(m_g + u_g · c)：这一窗该源没被检出的概率，随状态变化。
- 本窗证据 λ_g = log(miss_g + D_g) = log miss_g + softplus(log D_g − log miss_g)：
  - 检出很多时近似 log D_g；
  - 什么都没看到时 λ_g = log miss_g < 0，就是"该来的没来"的反证。

**3. 两路电流**：I_E(k) = λ_目标（兴奋），I_I(k) = λ_背景（抑制）。

**副产品（可解释量，也用于状态更新）**：
- 后验关联 β_hb = n_b exp(score_hb) / (miss_g + D_g)，即 PDA 里的 β；
- "本窗检出了源"的概率 1 − β_0 = D_g / (miss_g + D_g)；
- 关联量 = 读者的 β 之和；按 β 加权的平均统计量。

**V18 定型的树突（回退方案）只在这一节不同**：
- 一窗证据 = 归属加权平均 Σ_b g_b v_b / Σ_b g_b，再加一个伪观测（漏电导）；
- g_b = 距离归属 σ(b_h − r²/(2σ_h²)) × 事件数，v_b = softplus(内容)；
- 即电导型平衡电位。V18 学到的近读者半径为 5–13 px。

### 6.3 胞体（模块二）：积分到界、发放一次

- **起点**：U(−1) = z0。
- **积分**：U(k) = U(k − 1) + I_E(k) − I_I(k)。每窗只读新的一窗，读完即累加，旧窗不重读（积分形式，代码名 ledger）。
- **发放**：第 k 步若 |U(k) − τ| ≥ b_{1+k}（第 4 节的校准界）就发放一次：标签 = [U(k) ≥ τ]，同时在事件像素、当前窗发出类型为"目标 / 背景"的判决脉冲，单元随即释放。截止时强制定案。

### 6.4 初始化

- **输出层零初始化**：新单元一开始严格等于先验（测试 `test_starts_at_prior`），判决层从"不改骨干"出发。
- σ 初值取方框距离均方根 51.8 px 的 1/√2 倍和 √2 倍（近 36.6、远 73.3）。
- b_h = 0（读者权重各 0.5），κ = 1，漏检 0.5，内容系数和状态平移为 0。

## 7. 两层协同：判决脉冲作为证据

- **第一层**：第 6 节的单元单独训练（`v19f_s<种子>`），训练后冻结，按自己的校准界定案。
  - 只有进了单元的事件在定案时发脉冲；入口定案的事件不发。
  - 脉冲位置 = 事件像素，时刻 = 事件窗 + 定案步数，类型 = 目标 / 背景。
  - 这些脉冲按窗、按类型建成两张图 s_T、s_B。
- **第二层**：同结构的单元（`v19fc_s<种子>`），把 log(1 + s_T)、log(1 + s_B) 当作两项额外的方框统计量读入；用同一停止规则校准。第二层的定案就是最终标签。
- **落选的接法**：
  - 侧向突触直接接胞体（`--spikes synapse`）：V18 上 test 9/9 更低，淘汰；
  - 鞅一致性损失：val 8/9 更低、等待更长，降为分析材料。
- **部署**：两层每窗依次运行，能耗报告两层合计。

## 8. 损失函数

| 阶段 | 损失 |
|---|---|
| 骨干（已完成、冻结） | 加权二值交叉熵（正样本权重上限 30）+ 每窗消息数峰值机会约束（超预算比例 ≤ 5%，对偶上升）（第 3 节） |
| 判决层（第一层、第二层相同） | 每一步膜电位的逐事件二值交叉熵，按重要性权重归一：L = Σ_i ω_i Σ_{k ≤ F_i} BCE(U_i(k), Y_i) / Σ_i ω_i (F_i + 1)。ω_i = 1 / 抽中概率（第 9.2 节）；无效步不计 |
| 停止规则 | 无损失，只在验证集上校准（第 4 节） |

- 每一步都算交叉熵：它是严格合适的评分规则，所以每一步的 U(k) 都朝"到第 k 步为止的证据下的后验"训练。之后的停止规则只需要判断这个后验什么时候已经不会再变。
- 不加鞅损失、不加稀疏 / 能耗项。判决层的能耗由入口（多数事件不生成单元）和事件驱动的方框读取控制。

## 9. 训练方法

### 9.1 两段式

1. **第一段：骨干**。在 EV-UAV 训练集上训练（第 3 节），冻结，导出三个划分的先验（1.4）。
2. **第二段：判决层**（骨干冻结），内部按两层的依赖顺序进行：
   - 先训第一层判决单元，在验证集上校准它的停止规则（第 4 节），然后冻结；
   - 再训第二层：它读冻结第一层的判决脉冲，这些脉冲按第一层校准后的界生成，与部署时完全一致；最后校准第二层的停止规则。

### 9.2 抽样

训练用全部事件（不只入口外的），按"离阈值多远"分层抽样：
- 按 z0 − τ 每 1 个对数几率单位分段；目标事件全收；每段的背景事件每轮最多 5 万个，抽中概率 = min(1, 50000 / 该段背景数)。
- 按抽中概率的倒数加权：期望上等于在全部事件上训练，上限只决定算力。

### 9.3 每轮的流程

1. 按随机顺序遍历训练录像，抽事件。
2. 对每条录像建证据图，算出被抽中事件 11 步 × 33 方框的统计量，以半精度存入一个"池子"。
3. 池子攒满约 26 万个事件后整体打乱，按批 512 训练；然后清空池子，继续下一批录像。

### 9.4 优化与选择

- AdamW，学习率 2e-3，权重衰减 1e-4，余弦退火，梯度裁剪 1.0，8 轮，判决种子 0 / 1 / 2。
- **选轮次**：按验证集"全部事件都等到截止"的 IoU，与停止规则无关，避免选择与校准互相影响。
- **校准与报告**：选定轮次后在验证集上校准停止规则；验证集报两半交叉校准的诚实数字，测试集只报告。

### 9.5 每个作业的步骤（`tools/v18/run_sdu.sh`）

1. 训练（`train_sdu.py`）：存模型、验证 / 测试集的全部轨迹；
2. 评估（`eval_sdu.py`）：校准停止规则，算四个指标、等待、进单元比例、能耗；
3. 分析（`analyze_sdu.py`）：学到的常数、按事件类型的等待等；
4. 误差分解（`reducible.py`）：骨干错误中入口外 / 改对 / 仍错；
5. 流式回放（`stream_sdu.py`）：逐窗运行部署形式，与离线轨迹逐事件比对。

已完成的步骤会跳过，失败的作业重跑即可续上。服务器 4090 与另外两个作业共卡时，单层约 25–27 分钟（训练约 22 分钟），协同约 30 分钟。

## 10. 推理与部署（`StreamingDecisionLayer`，逐窗）

每来一窗：
1. 骨干处理本窗，得到本窗事件的先验。
2. 建本窗证据图（第二层另建本窗脉冲图）。
3. 在等的单元读本窗、算电流、积分；越界的发放并释放。
4. 本窗新事件过入口：安全的当场定案，其余生成单元并立刻做第 0 步。

- 同一出生窗的单元同步，每窗一次批量计算。
- 流式结果与离线训练、评估逐事件一致：单元测试覆盖，实际录像上也逐事件核对过。V19 共 600 条录像记录中只有 1 处不一致，是界上压线，膜电位差 2.6e-6。

## 14. 局限

- **改不了骨干看不见的目标。** 判决层救不了骨干持续看不见的目标：val 入口外的存在型漏检中，86.5% 前后 3 窗都没被找到。后续增益要靠骨干。
- **学到的常数不可解释。** V19 的新参数大多停在初值附近，可解释性靠公式本身。
- **能耗更高。** 比 V18 高约 18%（单层）。
- **混合形式。** 积分与发放是脉冲式的，输入电流由分级运算给出。
- **EV-Flying 上没有提升。**（第二个数据集；V18 第一层，V5-EVF 种子 37 先验，2 轮）
  - 种子 0 test 0.7355，骨干 0.7353；种子 1 第 2 轮发散，0.7134。
  - 原因：标签由框导出且有漏标（不补标）；目标快而短命（每窗位移 p95 25 px、寿命中位 5 窗），等待能积累的证据很少。
  - 暂不再做，论文作补充 / 局限。
