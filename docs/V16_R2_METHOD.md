# V16 r2：相关观察共识与有界条件修正

2026-11-13。实现入口为 `tools/v16/train.py`，正式配置为 `configs/v16/r2/`。r1 的配置与 `model/context_revision.py` 保留用于旧权重复现；r2 不调用它的全图注意力或特征修正。

## 问题与设计取舍

稀疏目标的判别信息可能跨越切片边界。100 ms 观察窗以 50 ms 步长推进，使同一内部事件获得两次上下文观察，在第二次覆盖结束时统一提交。V5 BIR、跨窗膜电位、原通信峰值约束、分流并行 TBPTT 均保留，阈值固定 0.9。

r1 的问题不是未对齐事件：原始 ID 已对齐。主要结构风险是两次相关特征经过无界残差后可以过度增信，训练目标又没有专门惩罚相对于第二次观察新增的背景错误。全图注意力 unfold 和第三次读出增加了开销。已有实验不能证明所有误报都由这三点造成，因此本次同时加入可验证的结构约束与真实数据探针。

r2 选择已有 V5 读出隐藏向量，而非新增大空间网络。每次正常读出得到 logit z_j 与 32 维 ReLU 隐藏向量 h_j；其中包含共享像素特征、事件极性和窗内时间。融合损失可以反传到读出层和骨干。两次观察的原始事件 ID 相同，无邻居搜索、逐事件循环状态或重复 SDU 审查。

## 方法一：相关观察的凸共识

问题：两次分数包含重复输入，直接相加会把共同信息当成重复支持。原理：以加权 KL 中心组织相关预测，不假设它们是独立似然。

对给定观察计算共享可靠性网络：

    s_j = Linear_8→1(SiLU(Linear_33→8([h_j, z_j])))
    [α1, α2] = softmax([s1, s2])
    z_bar = α1 z1 + α2 z2

当 α 固定时，q_bar = argmin_q Σ_j α_j KL(q || Bernoulli(sigmoid(z_j)))，其 logit 即 z_bar。α 是学习权重，不声称是校准的不确定度。

可检验性质：权重非负且和为 1；共识位于两分数之间；两分数相同时不会因重复出现而增强；交换两观察不改变共识。它不从高维表示中精确分离或扣除共同 B，不能称作精确贝叶斯后验。

## 方法二：有界条件修正

问题：凸共识只能在已有分数之间选择，不能表达两个隐藏观察的互补信息；普通残差又可以任意增信。原理：在共识附近学习受限修正，要求观察无差异时残差严格为零。

    c = [z1, z2, α1]
    b = W_b [h1, c] + b_b
    d = W_d (h2 - h1)                  # W_d 无偏置
    r = SiLU(b + d) - SiLU(b)
    δ = κ tanh(w_out^T r)              # 输出无偏置，κ = 1
    z_final = z_bar + δ

同一个 b 出现在两项中，因此 h1=h2 时 δ=0；任意输入均有 |δ|≤κ。最后一个投影零初始化，初始模型退化为方法一；差分投影保持非零初始化，避免整个分支无法学习。

概率空间中可将最后一步理解为 KL 邻近更新：q_final = argmin_q {KL(q || q_bar) - δ E_q[y]}。这等价于 logit 加 δ。Bernoulli 的 log-partition 二阶导数不超过 1/4，因此 KL(q_final || q_bar)≤δ²/8。这只限制预测分布的改变量，不是误报率上界。

h 包含时间相位，因此 h2-h1 既包含上下文变化，也可能包含同一事件在窗口中位置的变化。零差分约束不能被写成“只吸收新增未来证据”。膜电位中的历史相关性仍存在；不使用独立似然相乘，也不把普通差分描述为严格的信息去重。

## 网络数据流

    100 ms 重叠观察（每 50 ms 推进）
      → 同一 V5 BIR U-Net，膜电位按时间持续传递
      → 原 V5 读出：共享空间特征 + p + t_local → Linear → ReLU(h32) → Linear(z)
      → 按原始事件 ID 配对两次 h/z，第一份只缓存到下一窗
      → 方法一：共享可靠性 → 二项 Softmax → 凸共识 z_bar
      → 方法二：条件差分 → 有界残差 δ
      → sigmoid(z_bar + δ)，固定 0.9 提交标签

每个内部事件两次普通读出、一次融合；首尾仅覆盖一次的事件沿用普通读出。已提交标签不回流膜电位。读出图在一个 TBPTT chunk 内贯通；跨 chunk 缓存 detach+clone，保留数值而截断梯度。每段录像结束时检查缓存为空，每个原始事件恰好提交一次。

## 损失与训练

令 ℓ_w 为原 weighted BCE，正样本权重仍由训练集估计并截断到 30。对配对事件：

    L_pair = 0.25 ℓ_w(z1,y) + 0.25 ℓ_w(z2,y)
             + 0.5 ℓ_w(z_final,y) + 0.5 λ R(z_final, stopgrad(z2), y)
    R = w*y*[softplus(-z_final)-softplus(-stopgrad(z2))]_+
        + (1-y)*[softplus(z_final)-softplus(stopgrad(z2))]_+

λ=1。R 同时惩罚目标置信度相对第二次观察降低、背景置信度相对第二次观察提高；有标签且方向正确的修正不支付这项附加代价。只惩罚背景在探针中损失较多召回，因此使用双向约束。R 是训练风险正则，不在推理时读取标签，也不保证测试召回不下降。

单次覆盖事件权重为 1，配对事件基础监督总权重为 1；每个 chunk 以监督质量归一化，再加原 V5 通信预算项。没有修改判决阈值、拟合测试集温度或用测试集选模型。

正式设置：streams=4、TBPTT K=16、每 chunk 一次 Adam 更新；最多40轮，至少15轮，验证 IoU 连续8轮未严格提高则早停。每轮在线 step 验证，按验证 IoU 选权重；训练子集诊断每10轮执行，减少非必要评估。默认从头训练，头归一化为恒等，不搬入冻结骨干的近零通道统计。

默认六项任务：full/no_revision/no_context × seed37/38；训练数据、损失、初始化规则、停止规则相同。共同骨干和模块参数使用同一初值。no_revision 完全移除方法二，仅保留共识；no_context 完全移除方法一，以 z2 为基底再做有界修正。另提供 second.yaml 作为双模块均关闭的手工对照，不自动增加到六项队列。同权重 first/second/main 仅是读出诊断，不能替代独立重训消融。

## 计算量与限制

完整头833个参数，每对事件1088个线性 MAC；两个单模块各544个。该数不含 V5 普通读出、激活函数、Softmax、内存读写和骨干。总开销为 O(N)，用张量批量执行；没有逐事件 Python 神经网络调用。百万事件仍须付出线性成本，不能说与事件数无关。

推理缓存约为每个待判事件33个浮点数加索引，保留一个重叠半窗，内存仍与该半窗事件密度成正比。默认评测器会预载整条录像，这部分应单独计入峰值内存。训练在 CPU 缓存不可变录像索引，减少每轮排序和加载，以额外主存换时间。

空间关系来自原 U-Net；新头没有显式跨窗运动对齐。如果原读出隐藏向量已丢失必要信息，833参数的小头不能恢复。两个高置信错误观察也可能被共同保留。早停可能错过晚期改善，完整增益需正式多种子验证，不能由结构性质或单次探针保证。
