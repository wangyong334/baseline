## 本轮修复

1. **物理传感器掩码**：260×346 的有效区域之外不能充当未来观测；66×88 粗网格中 153 个纯 padding token 被排除。部分边缘 patch 保留有效子像素，池化/插值按有效支撑归一，最终不修改传感器外特征。不增加参数。
2. **数据与结果来源**：复用统计量核对训练集来源、几何和数值；续训同时核对训练集与验证集清单。NaN 预测立即失败并恢复模型模式。缺少训练范围来源或短探针权重不能标为完整正式实验。
3. **性能评估**：核对权重设计与全部公开配置，记录 sensor/pad；延迟样本保留 NumPy 数组，避免为大量事件创建 Python float。推理吞吐与整段功率测量流程吞吐分别报告，新增 ANN 读出/修正 MAC 单独列出，整卡焦耳不当作纯模型能耗。
4. **发布隔离**：固定 22 个必需源文件/配置的依赖清单；服务器上残留的旧 SFTP 文件不会进入冻结源码。只复用 GPU 1 已有池子。
5. **代码清理**：删除 331 个跟踪历史文件和 250 个明确生成缓存；恢复并精简 6 份 V5 关键数值测试；旧 trainer 由约 1,670 行收敛到 278 行共享辅助。具体审计见 [清理记录](V15_CLEANUP.md)。

## 同录像、同权重的计算开销

三份 val 录像按事件密度选低/中/高，每份两次、每条路径共 960 窗；重复预测最大绝对差 0。这里比较的是计算开销，不能代替各方法独立重训的精度比较。

| 路径 | 平均在线步耗时 | P95 | 推理峰值分配 | 事件吞吐 |
|---|---:|---:|---:|---:|
| 同权重骨干 V5 原始读出 | 5.10 ms | 6.30 ms | 0.183 GiB | 177,737 events/s |
| V15 r2 主输出 | 8.51 ms | 9.87 ms | 0.202 GiB | 106,895 events/s |

| 录像 | 事件数 | V15 整段回放均时 |
|---|---:|---:|
| val_022.npz | 8,165 | 1.367 s |
| val_012.npz | 39,595 | 1.374 s |
| val_023.npz | 391,344 | 1.368 s |

这些都是 8 秒录像；输入事件数组预载，不是相机采集端到端测试。平均计算步耗时增加约 67%，不能以小参数量宣称零开销。新增模块仍为 3,474 参数、48,996,288 dense MAC/观测编码及修正对，另有 softmax、插值和访存开销。主要新增计算由固定特征图决定；事件表示和末端 MLP 的 O(N) 成本仍存在，未验证任意百万级事件率。

V15 平均采集等待 75.17 ms / P95 98 ms，V5 是 25.48 / 48 ms；额外 50 ms 不能与纯计算时间混淆。功率采样发现同卡其他进程，不能把数值归因于模型，也没有测 CPU/整机能耗。

完整原始结果：`Res/v15_r2_profile/profile.json`。局部背景误匹配、浅层观测语义不足、紧凑投影丢失弱目标等是仍需正式实验验证的方法风险；没有以这次短探针宣布其已解决。
