## 模块与主张

- **BIR**：复用当前窗口共享流式 SNN。事件初始估计在其 50 ms 窗结束后可用，不能写成事件到达即零延迟输出。
- **SDU**：新增 `model/bst_window.py`。每个来源窗内部归一化，跨窗累积学习折扣后的有符号有界势。保留每条已选来源、窗口 ID 和相对关系；新上下文同时改变旧来源的亲和度和值，以及旧窗的折扣。来源编码和固定关系投影缓存，动态权重与值仍重算。
- **VoW**：复用有限时域条件代价网络；使用窗口层级统计，比较解析停止风险与预测继续代价。停止后退出查询计算。固定步骤成本不冒称物理焦耳；学习出生为单独实验路径。

最终候选的 SDU 为 5,486 参数，比平坦均值的 4,906 多 580；继续策略 897 参数，可选出生策略 385 参数。本地 BIR 权重为 105,777 参数。参数少不保证推理快，实际结果见下。

完整公式、复制性质的条件、重新解释旧证据与不重复记账的区别见 [方法合同](BST_WINDOW_METHOD.md)。论文问题陈述、图表布局与消融组织见 [论文蓝图](BST_PAPER_BLUEPRINT.md)。

## 验证及负面结果

工程测试覆盖因果输出与梯度、空前缀、同前缀不漂移、旧权重/旧值可分别冻结、完整复制已选窗口的性质、受控跨窗累积、贡献重建、极小亲和度的有限梯度、缓存路径与旧模型兼容。测试数量、日志和源码 hash 见 `Res/bst_window_20261111/VALIDATION.json`。

GPU 小样本训练、VoW 拟合、真实录像重审诊断和原始流评估均已运行，但仅 2 段训练、4 段验证、1 个训练 epoch，不是正式结果。探针使用的历史先验来源未满足新发布的完整身份验证要求，所有产物标记 probe，正式服务器管线会重新完整导出。

**探针有负面精度结果，不能隐藏：** `test_000`（44,751 事件）中 BIR 的 IoU 为 96.2370%，新 SDU 固定截止为 93.3981%；漏检由 1 变为 0，但假阳性由 93 增为 170。学习停止在这个探针上没有改善最终标签，减少的是证据等待；完整计算反而约 3.97 s，高于固定截止的 3.50 s，因此也不能据此宣称节省真实运行时间。该观察不能用来挑测试集超参数，也不能推广为完整训练后的排名；它明确说明“结构可解释”尚未等于“已经解决误报”。详见 `Res/bst_window_20261111/metrics_smoke/metrics.json`。

后来补跑的年龄 0 对照为 IoU 95.7404%、假阳性 107、漏检 0，全部 1,274 个入选查询仅更新一次，额外证据等待为零。等待后续窗相对这一对照又增加了 63 个假阳性，说明“有未来信息”也不保证利用正确；VoW 探针没有避免这些误伤。该对照在同一权重、同一录像上运行，单轮时间只验证测量管线，不用来比较微小速度差。文件为 `metrics_arrival_smoke/metrics.json`。

## 同录像最终运行时间

设备 RTX 5060 Laptop，`test_023.npz`，620,440 事件、8 秒录像。固定相同 BIR、出生规则、邻域预算、截止与 batch=1024；预热后交替顺序运行三轮，计时包含表示、骨干、检索/缓存、SDU 与 CPU 输出，不含磁盘读取、模型加载和输出文件写入。不同架构使用不同探针权重，比较的是执行成本，不是等输出优化或精度优劣。

| 实现 | 整段时间中位 | 三轮整段时间 | 窗口 P95 中位 |
|---|---:|---|---:|
| 旧平坦均值参考 | 5.536 s | 5.094 / 5.536 / 5.981 s | 41.91 ms |
| 新分组模型，缓存 | 6.486 s | 5.590 / 6.504 / 6.486 s | 50.04 ms |
| 新分组模型，重算 oracle | 7.476 s | 见原始 JSON | 57.88 ms |

新结构比旧均值观测上慢 17.2%；缓存比新结构自身重算少用时 13.2%。本机波动明显，不把两次测量的差异归因于某一行代码。整体 RTF 约 0.811 不代表每个 50 ms 窗均满足截止，也不包括最长 500 ms 的自适应证据等待。

新结构缓存与重算比较的最大 logit 差为 9.54e-7，类别零差异，先验、等待步数和提交原因精确一致。三轮重复也全部通过容差检查（其中一次重算重复最大差 1.91e-6）。重算 oracle 保留缓存并额外重建固定关系，仅用于正确性和重复计算诊断，不能当成最省显存的无缓存实现。

该录像共发起 13,699 个待判查询，实际重审 148,982 次；累计有效证据访问约 3,639 万，首次准备约 442 万，峰值活跃查询 1,683。复杂度是共享骨干 + 选中查询的有界邻域重审，仍有真实计算开销，不是所有事件都免计算。每个来源窗最多 16 条、最多 21 个来源窗，默认上界为每次查询 336 条，不建立全部事件两两注意力。

最终数据：`Res/bst_window_20261111/runtime_comparison_final.json`；原始分轮输出：`architecture_profile_final/`。早一轮 `runtime_comparison.json` 是最终数值稳定化前的探针，不引用其 4.35% 开销。

## 正式验证必须回答的问题

1. 两个真实骨干种子 37、38 独立导出先验、训练 SDU、拟合 VoW；同时评估 BIR、age0 历史精化、固定截止、学习停止、学习出生。age0 对照分离历史精化与等待未来证据的收益。
2. 对 full、no_reweight、no_revalue、no_reaudit、legacy_flat_mean、no_window_gate、unbounded_values 分别重新训练；同权重关开关只能做机制诊断。
3. 长时背景、同形持续干扰、后来反证是关键负控制。窗口之间可能相关，窗口折扣不是可靠性概率，不能证明误报风险上界。
4. VoW 必须在相同等待/计算预算下比较固定规则与仅置信度策略。不是只证明网络能输出停止动作。
5. 同一 U-Net 的 LIF/TIF/graded/ReLU 只构成骨干变体。真正独立架构迁移仍需另一架构的因果适配器及权重。不要将接口测试写成迁移性能。

默认出生区间直接提交的错误不再被 SDU 重审；学习出生另列为第五条评估路径。该筛选可能遗漏需要纠错的高置信事件，是需要报告的边界。来源只含分数和极性、相对几何单独处理，不能保证恢复骨干已经丢掉的语义。

[实验矩阵工具](../tools/bst/experiment_matrix.py) 会按骨干和种子检查身份、隔离缓存并生成命令；缺权重明确 blocked，不生成可执行伪结果。协议见 [BST_TRANSFER_PROTOCOL.md](BST_TRANSFER_PROTOCOL.md)。
