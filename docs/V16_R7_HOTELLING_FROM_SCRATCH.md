# V16 r7：直接 Hotelling 读出与 seed37 从头训练

2026-11-13。用户要求直接优化 V16 Hotelling、seed37 从随机初始化训练，并进入现有物理 GPU1 池子。本方案取代尚未运行的 r6 冻结骨干实验；r4/r5/r6 配置与结果保留。

## 1. 放在什么位置

Hotelling 是事件最终判决的线性观察器，不是 SNN 状态更新、注意力门或任意非线性残差。骨干保留 V5 BIR、跨窗膜电位、single_rolling、100 ms 观察窗／50 ms 步长及通信预算。

同一原始事件 ID 在两个重叠窗口各有一次观测。分别在该事件坐标读取 dec1 的复位前膜电位 `u_pre`（12维）和原事件分类器 logit（1维）。每次观测 `v_j=[h_j,z_j]` 为13维，联合向量按 `[v_2,v_1]` 排列，共26维。所有 `coverage_count==1` 的事件（录像首尾50 ms）使用各自唯一观测的原事件 logit。配对依原始事件 ID 与 first/last_window 完成，不凭邻近位置匹配目标，也不假设两次观测相互独立。

两次特征均包含流式状态和对应窗口信息；这里不声称把窗口中的某一物理目标分量精确分离出来，也不声称运动补偿。

## 2. 数学定义和可检验性质

只用训练集配对观测估计两类均值和类内协方差。每条录像每类最多固定抽样512个配对事件，全部99条训练录像按完整时间顺序回放。该估计对应此抽样分布，而非全部事件均匀加权的分布。

令原始类均值为 `m_0,m_1`，类内协方差为 `C_0,C_1`，采用各类样本中心化后的最大似然估计（除以各类样本数），`C=(C_0+C_1)/2`。没有把类间均值差混入协方差，也没有用类别频率去淹没正类协方差。

按 `D=diag(sqrt(max(diag(C),1e-8)))` 标准化，`x=D^-1(v-(m_0+m_1)/2)`，`delta=D^-1(m_1-m_0)`。在该坐标下：

```
K0 = D^-1 C D^-1
K  = 0.95 K0 + 0.05 diag(K0) + epsilon I
epsilon = 1e-5 * max(mean(diag(K0)), 1e-8)
w = solve(K, delta)
d2 = delta^T w
s = w^T x / max(sqrt(d2), 1e-6)
logit_final = softplus(a) * s + b
```

当 `d2<=1e-12` 时判别模板置零，不从无分离的统计制造方向。正尺度另有 `1e-6` 数值下限。均值、协方差和求解都在 CPU float64 中完成，再检查部署 dtype 有限性并保存缓冲区。

`w` 最大化的是估计且正则化度量下的线性 Rayleigh 商 `(w^T delta)^2/(w^T K w)`；当 `d2>1e-12` 时，未校准得分 `s` 在该度量下方差为1。零分离时得分为0，真实协方差 `K0` 下或乘以学习尺度后的方差不保证为1。不能把它说成对真实总体分布或真实协方差的最优保证。正尺度与偏置是仅有的两个可训练观察器参数，由加权BCE学习，决策阈值仍固定0.9；这不保证该工作点最优或输出为校准概率。Hotelling 得分本身不是概率，非高斯分布下也不自动等于似然比。

原来的通道压缩、自由 MLP 修正和 `±2` 残差上限都不参与该新读出。推理可折叠成26维点积、标量尺度和偏置；不在线计算协方差或逆矩阵。

以观测时间编号定义 `x=[x2;x1]`、`K=[[K22,K21],[K12,K11]]`，设置 `B=K12 K22^-1`、`S=K11-B K21`。联合得分精确分解为第二次观测项加第一次观测的线性回归残差项，两个项统一除以联合分离度：

```
s = [delta2^T K22^-1 x2
     + (delta1-B delta2)^T S^-1 (x1-B x2)] / sqrt(d_joint2)
d_joint2 = delta2^T K22^-1 delta2
           + (delta1-B delta2)^T S^-1 (delta1-B delta2)
```

该式用于非退化情况；这里的边际项属于联合正则化矩阵，不直接等同于独立拟合的 no_context 模型。审计记录 `d_joint²=d_second²+d_conditional²`。非高斯情形下，不把这个线性残差的协方差声称为完整条件分布的协方差。相关性在联合协方差及该分解中处理；这不是把两次分数当独立概率相乘。有限样本与收缩正则可使重复观测也出现表观 Fisher 增量，因此增量不能独自证明获得了新信息。

理论依据：[He & Park, Model Observers in Medical Imaging Research (2013)](https://www.thno.org/v03p0774.htm)。本文将该线性观察器定义应用于任务学习后的事件描述子，应用位置和训练方法需由本实验验证。

## 3. 从头训练和统计刷新

`configs/v16/r7_hotelling/full.yaml` 明确指定随机初始化、50轮、无早停、无预训练 checkpoint、无骨干冻结和无旧 r5 适配阶段。

1. seed37 随机初始化骨干和原事件头；仅用训练集计算输入归一化和神经元增益校准。
2. 用当前随机骨干完整回放训练集，拟合初始观察器。
3. 用固定观察器统计执行一整轮原4流 TBPTT16训练。骨干、原事件分类器和观察器的两个标量共同更新；保留原事件分类器每次观测 BCE、配对最终 BCE 和通信预算损失。
4. 用更新后的骨干再次完整回放训练集、刷新观察器统计；保留已学习标量。
5. 验证集按固定0.9阈值评估 IoU／ACC／Pd／Fa，按 Val IoU 选模型，保存对应骨干、校准标量和同一版本的统计。重复到50轮。

这是统计估计与可微特征学习交替执行。梯度经过固定线性模板回传到两次观测和骨干，不穿过协方差估计／矩阵求解。刷新统计后，尺度与偏置保留自本轮优化，可能相对新统计存在适配滞后；不声称每轮验证前标量都已在新模板上收敛。TBPTT片段边界仍按原协议保留数值状态、截断历史梯度。每轮额外的训练集统计回放是真实开销，不能把这次描述为几分钟的冻结头训练。

验证和测试只能读取 checkpoint 的统计，不能拟合统计或调阈值；Test 在正式训练选模结束后由原流水线执行。旧 r5 的 Test 排名不作为此次超参数搜索目标。

## 4. 实现和消融语义

- `model/hotelling_readout.py`：显式模板求解、条件分解、常量缓冲区与两标量校准。
- `tools/v16/train_hotelling.py`：训练集刷新、权重／统计 SHA256、恢复一致性及随机初始化审计。
- `tools/v16/train.py`：接入完整骨干训练、推理和原事件身份配对。
- `full`：26维联合完整协方差观察器，本次唯一提交任务。
- `no_context`：独立拟合第二次观测的13维边际观察器，第一次观测系数严格为0。
- `no_revision`：26维联合对角协方差观察器，去掉相关性建模；这个历史名称在r7表示对角观察器对照，不能称为“完全不使用Hotelling”。
- `second`：原第二次 logit 直通的同权重诊断；不等于独立训练的基线。

三份正式配置除 variant 与输出路径外一致。现在只启动 full seed37；尚无 r7 精度结果，也尚不能声称优于 r4/r5 或证明上下文的独立收益。
