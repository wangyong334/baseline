## 总架构图

读图顺序是从上方事件流到 BIR，再到初始事件信念。出生规则在付出 SDU 成本之前决定是否打开该事件的判决单元；默认使用固定区间，学习到的廉价头作为可选对照。具体区间的 `sym` 或 `martingale` 类型以保存的配置为准，不把两个历史版本混为同一种规则。一个事件提交后从待判队列移除，但该事件作为观测仍保留在允许的历史范围内，供其他事件读取。

打开 SDU 后，年龄 0 读取已经到达的过去窗口与当前完整窗口，不需要额外等待；这个初次精化后的分数可以不同于 BIR 初始分数。年龄 1 到 D 才表示等待后续窗口。图中“initial belief”和“age 0 history refinement”不是同一个输出。

下方共享历史与待判事件是两种不同对象：前者保存源证据，后者保存每个事件自己的状态。多事件共享编码，不共享标签、后验估计或提交时刻。等待回路只继续处理仍在队列中的事件。

图中“encode each source once”指冻结推理时，在一个源条目的缓存生命周期内仅编码一次；训练时每次参数更新后必须失效旧编码。不能解释成训练全过程只计算一次编码器。

## BIR 图

对应 `model/evspsegnet_stream.py`、`model/lif2d_stream.py` 的现有骨干。输入为整窗正负计数 2 通道，加 5 个时间 bin × 2 极性，共 12 通道。bin 是输入通道，不是额外循环时间步。

编码器通道为 12、24、48、48，解码器为 48、24、12，共七组跨窗状态。浅层与对应解码层之间有跳连。事件读出使用事件位置的特征、极性和窗内时间。

右侧神经元图展示不带背景自适应分支的 BIR：当前驱动减去学习偏置，经泄漏有界状态积分，再量化得到电平。图中 `q_k` 是量化电平，网络实际汇报幅度为 `theta * q_k`；`delta_q` 用于消息计数。现有卷积仍按稠密 PyTorch 路径执行，电平变化消息减少不自动等于 GPU 运算减少。

## 共享证据图

对应 `SharedSequentialModel.encode_sources` 与 `tools/bst/data.py`。默认源特征只有初始分数和极性；第一维分数在编码前做可逆的 `asinh` 变换。源编码器为 `Linear → LayerNorm → SiLU → Linear → SiLU`，默认宽度 32。键、值各投影为 2 头 × 8 维；上下文投影为 16 维。

源自身特征不包含“相对某个查询的位置”。坐标、时间与源 ID 保留为索引，只有读取时才形成 Δx、Δy、Δt 和窗口偏移。相对位置归一化尺度、时间窗口和特征维度在配置中显式声明。全部 LayerNorm 仅作用于单条特征的通道，不跨事件、录像或未来时间窗聚合统计量。

缓存保留条目而非仅保留不可恢复的 (A,b) 总和。它不等价于保留所有原始信息；可学习编码本身仍存在表达瓶颈，需要通过实验检查。

## SDU 图

对应 `SharedSequentialModel.reaudit`。当前查询上下文由自己的旧状态、当前已可见源证据摘要和年龄组成。新证据摘要在重新赋权和重新赋值之前进入查询，因此新到邻居的内容可以在本次调用中改变旧邻居的解释，不必等到下一次再有新事件。

两个分支分别给出非负权重和有符号值。默认每头求加权均值，再将各头修正相加。输出始终为“同一个初始分数 + 本次整个证据集合的总修正”，不是“上一步分数 + 整批旧证据”。状态更新为初始上下文加上 `tanh` 有界残差；本轮代码没有使用 GRU。初始上下文以独立 `anchor` 字段缓存，保留梯度，后续年龄复用同一个锚点而不重复运行固定的先验 MLP。

相同可见证据前缀再次调用时，信念与上下文保持不变，只推进策略年龄。在线执行器会在调用重审前跳过没有新增可见邻居的事件。这个设计没有把空时间窗建模成新的观测似然；它是本轮明确的建模边界。

门权重不是经过监督校准的同源概率，有符号值不是已经证明的单邻居对数似然比。`neff` 为权重的 Kish 有效数量，不应解释成独立证据数量。对应的最小机制检查包括：固定年龄、掩码、旧邻居和旧状态，仅改变新邻居内容，旧邻居的权重与值会改变；关闭重新赋值开关后，旧值保持不变。

## VoW 图

对应 `BirthValueHead`、`ContinuationValueHead`、`tools/bst/policy.py` 中的 `BirthContext`，以及训练和流式执行入口。生产配置中的可选出生头使用 10 维输入：事件自身的 `asinh(initial_logit)`、极性和窗内时间 3 维，加共享空间邻域当前与历史统计 7 维。统计包含分数均值、标准差、数量、最大值、极性均值，以及历史分数均值与数量；默认网格大小 4、历史跨度 10 窗，参数写入配置。它不读取先运行 SDU 才能得到的状态，也不执行逐事件 SDU 邻居编码。核心 `BirthValueHead` 是通用可配置输入维度的小网络，类的最小输入默认值为 2，实际训练入口显式传入 10。后 SDU 头读取当前上下文、分数、修正、当前变化、证据权重统计和年龄等因果信息。

两个值网络均预测非负的下游策略代价。这个代价可以包含后续分类错误及后续等待成本；本次打开或再等一步的显式成本由外部加上，避免重复计费。图中相应框合并展示“预测值 + 当前行动成本”，不表示成本常数由 MLP 学出来。

训练时可在一个 minibatch 内预计算 `prepare_pairs`，缓存与查询当前状态无关的源读取和相对关系投影；每个年龄仍重新计算上下文相关的权重与值，并重新施加因果掩码。缓存保留梯度，仅在本次优化图内有效。它的显存随查询—邻居对数增长，不作为在线无限持久缓存使用。这个实现优化与在线端到端加速应分别计时报告。

内部后验估计为 σ(ℓ)，为保持官方工作点，报告分数为 σ(ℓ + log w)，判决阈值为 logit(0.9) − log w。停止风险中的误报和漏报代价必须与这个阈值一致。学习到的继续代价在条件期望层面与停止风险比较；训练目标不能逐事件查看未来真值后挑出最好的时刻。

图没有宣称“提交后真实判断永不改变”，也没有宣称对任意自适应停止时刻存在已证明的统计风险上界。相关性质需要单独的概率假设、校准或序贯统计论证。

## 再生成

在项目根目录运行已有包含 matplotlib 的 Python：

```powershell
python tools/bst/draw_architecture.py --out docs/figures/bst --dpi 240
```

可选 `--pdf` 同时导出矢量 PDF；默认交付 SVG 与 PNG。生成脚本为 `tools/bst/draw_architecture.py`。已逐张检查五张 PNG，确认公式、箭头和文字可读，正文无覆盖或裁切。最终论文排版时应根据双栏版面调整字号，SVG 为主要编辑源。
