# V18：协作的脉冲判决单元（方法说明）

## V18 改动（2026-11-13 夜，分支 V18，工作树 `ref-v18`，从 V17 `190bf26` 分出）

在 V17 主模型 l_glm 上做四处升级，代码在 `model/sdu.py`、`tools/v18/`、`tests/test_sdu_v18.py`（22 项测试）：

1. **E1 + B1 判决脉冲作为消息（同源事件一起判）**：第一层是训练好、校准好的 V17 判决单元（冻结），每个单元定案时在事件所在像素发一个脉冲（目标 / 背景）。第二层判决单元（V18 训练的部分）读本窗证据的同时，读方框里别人的判决脉冲（两个新统计量：目标脉冲数、背景脉冲数，取 log(1+n)；自己那一层单元发的脉冲扣掉）。两层各自校准入口和停止界。部署：`CooperativeStreamingLayer`，每窗先跑第一层，把它这一窗的定案作为脉冲写进证据图，再跑第二层；与离线逐事件一致（单元测试 + 本地冒烟 0 处不符）。训练：`train_sdu.py --stage1 <V17 运行目录>`，第一层在训练 / 验证 / 测试集上先跑一遍得到脉冲（缓存为 `messages_<split>.npz`）。
2. **D1 双房室判决神经元（讲法，计算不变）**：树突在每窗内达到电导型平衡电位（电导 = 归属 × 事件数，伪观测 = 漏电导），胞体完美积分，阈值随单元年龄收窄（校准界），发放一次即定案。
3. **A1 误差的时间可约分解**：`tools/v18/reducible.py`，自动在评估后运行。骨干到达即判的错误分成：入口外（自信错误，无单元）、进单元后改对、进单元仍错；另报单元新引入的错误、可达错误随等待窗数被改对的比例，以及只看标签的"后续窗附近是否还有同一目标"。
4. **G1 鞅一致性（可选）**：`--martingale w`，惩罚"给定当前后验时下一步后验的平均漂移"（后验序列是鞅；出处：Martingale-Consistent SSL，arXiv 2605.11846，2026）。作为变体跑。

另：逐窗累加下 `--pool mean` 改为"膜电位 = 先验 + 已读各窗电流的平均"（V17 的同名消融在逐窗累加下等于主模型，已修）；默认训练 8 轮（V17 dev_ep8 与 12 轮持平）。

## 1. 问题

流式脉冲骨干按固定时钟（50 ms 一窗）处理事件，每个事件在它所在的窗口结束时就被定案。多数事件这时证据已经足够；但目标刚出现、目标边界附近的少数事件，判别它们的证据要在之后几窗才到。固定时刻定案对这些事件太早，对大多数事件又没有必要再等。

记号：事件 i 落在窗 s_i，像素 (x_i, y_i)，极性 p_i，标签 Y_i ∈ {0, 1}。冻结骨干给出校准尺度上的先验对数几率 z0_i（骨干 logit 减去 log 正样本权重）。官方阈值 0.9 换到这个尺度上是 τ = logit(0.9) − log w（V5 s37：τ = −1.20）。截止 D = 10 窗（500 ms，延迟需求）。

## 2. 原理：序贯分析

每个不确定的事件看成一次"目标 / 背景"二选一的检验：从先验出发，随后续观测逐步更新，证据够了就停。神经科学里的对应物是漂移扩散模型：决策神经元把证据累积到界即定案。

| 序贯检验 / 漂移扩散 | 本文 |
|---|---|
| 起点偏置（先验） | 骨干给的 z0 |
| 决策变量 | 判决单元的膜电位 U |
| 每一步的证据 | 归属到本事件的新证据 |
| 决策界 | 第 k 步的界 b_k |
| 有截止时界收拢 | 界随剩余步数变窄（校准自然得到） |
| 决策时刻 | 发放时刻 |

经典检验有三个前提在事件流上不成立，每一处做一次改造：

| 经典前提 | 事件流上的情况 | 改造 |
|---|---|---|
| 观测直接属于这个检验 | 新事件混着本目标、别的目标和噪声 | 归属门（式 3） |
| 观测相互独立 | 同一个源连续产生事件，高度相关 | 归属平均，不求和（式 4）；每步由全部证据重新核账（式 5） |
| 没有截止，界是常数，后验已校准 | 必须 500 ms 内定案；学出来的膜电位在留出数据上过度自信 | 停止规则在留出录像上按 α 校准，入口也由它决定（式 7） |

另外一处是新增的：证据的含义取决于已经看到了什么，所以单元的状态（上下文）随核账更新，决定下一步怎么读（式 6）。

## 3. 方法

### 3.1 共享证据图（式 1、2）

每来一窗，把这一窗的事件落到网格上，按极性各建两张图：事件数 n 和"像目标的事件数" q = Σ σ(z0)。用积分图存储（整数定点，求和精确、与顺序无关），任何方框的和只要四次查表。图每窗只建一次，所有单元共用，**不搜索邻居**。

单元以自己的事件为中心，按"视网膜式"的固定方框读图（式 1）：第 0 级是 3×3 个 3 像素的方框，之后每一级是上一级外面一圈 8 个、边长 3 倍的方框。L = 4 级共 33 个方框，不重叠地铺满以事件为中心、边长 243 像素的正方形：近处细、远处粗。

每个方框、每个窗给 5 个数（式 2）：同极性 / 异极性的 log(1 + n)、log(1 + q)，以及方框落在画面内的面积比例（画面外不是"没有事件"）。极性按"与本事件相同 / 相反"编码，整体翻转极性时结果不变。本事件在自己那一窗的中心方框里被扣除。

### 3.2 判决单元（式 3–6）

每个方框、每个窗是一个记号：内容（线性）加位置（窗偏移 × 方框）后归一化，再投影成键和值，只算一次。

第 k 步（本窗及其后 k 窗已到），每个头 h 对目前所有记号做一次核账：

- 式 3，归属门：a_hj = σ( q_h(c, k) · key_j / √d_h + b_h − r_j² / (2σ_h²) )。查询来自单元的状态，r_j 是方框中心到事件的距离，σ_h 是这个头学到的感受野。用 sigmoid 不用 softmax，因为多条证据可以同时属于我；全都不属于时归属量很小。
- 式 4，窗内一次观测：e_hw = Σ_{j∈w} a_hj m_j v_hj / Σ_{j∈w} a_hj m_j，其中 v_hj = W_out(GELU(value_j + W_c c))_h，即这条证据在当前状态下说"像目标"还是"像背景"。同一窗里同一个源的事件高度相关，所以一窗的归属证据取平均，算一次观测。m_j = 1（以方框为观测单位）；或 m_j = 方框里的事件数（以事件为观测单位），此时每窗再加一个学出来的"这一窗没有属于我的事件"伪观测（贝叶斯伪计数平滑）。
- 式 5，窗间累加（重新核账，兴奋 / 抑制两通道）：U(k) = z0 + Σ_{h∈目标} Σ_{w≤k} e_hw − Σ_{h∈背景} Σ_{w≤k} e_hw。每来一窗就是一次新观测，证据逐窗累加，这就是序贯检验的形式。每一步用当前状态把已到的每一窗重新解读一遍，每窗只计一次。两通道的值都是 softplus(·) ≥ 0：目标通道兴奋、背景通道抑制。
- 式 6，状态更新：c ← c0 + Δ(归属平均的值, log(1 + 归属量), λ)，c0 由本事件的先验和极性得到。已经看到的东西决定下一步怎么读。

初始时输出层为零，所以 U(k) = z0，判决层从"不改骨干"出发。

### 3.3 停止规则与入口（式 7）

把一个事件的轨迹排成列：第 0 列是先验 z0（还没有单元），第 1 + k 列是第 k 步的膜电位。事件在第一个满足 |Z_c − τ| ≥ b_c 的列定案，否则在最后一列（截止或录像结束）强制定案。

- **风险**：定案时的结论与截止时的结论不同的概率（11-10 用户对"证据够了"的定义）。
- **校准**：每一列，在仍未定案的留出事件上，用保序回归（不分箱，单调不增）估计"改判概率 ~ 离阈值的距离"，b_c 取"从这里往上每一段改判率的 Clopper–Pearson 上界都低于 α"的最小距离（置信度 δ 按列数平分）。
- **入口**：第 0 列就是入口。先验已经安全的事件当场定案，不生成单元。所以"谁进判决层"是停止规则的结果，没有手设区间，宽度随骨干的刻度由校准决定。
- **界收拢**：越接近截止，剩下能改变结论的证据越少，同样距离下改判更少，界自然变窄。
- **常数**：α（声明的风险，1%）、δ（校准置信度，0.1）、截止 500 ms（延迟需求）。

### 3.4 训练

1. 骨干：已有 V5（BIR + 每窗消息峰值预算），冻结。
2. 判决单元：每轮按"离阈值的距离"分段抽样，目标事件全收，每段背景最多抽 cap 个，按被抽中概率的倒数加权。期望上等于用全部事件训练，cap 只决定算力（默认 5 万）。每一步的膜电位都用 BCE，这是严格合适的评分规则，所以每一步都朝"已到证据下的后验"训练。按验证集"全部事件等到截止"的 IoU 选轮次（与停止规则无关）。
3. 停止规则：不训练，只在验证集上校准；测试集只报最终结果。验证集的"诚实"数字用两半交叉校准。

### 3.5 部署形式与开销

`StreamingDecisionLayer` 逐窗执行：建本窗证据图 → 在等的单元读新窗、核账、越界即发放 → 新事件过入口 → 不安全的生成单元并立刻做第 0 步。同一出生窗的单元同步，每步一次批量计算。流式结果与离线训练、评估逐事件一致（单元测试 + 实际录像核对）。

每个单元每步的计算：新窗 33 个记号的嵌入 + 对 (k+1)×33 个记号的核账 + 状态更新（`SpikingDecisionUnits.step_macs`）。只有入口判为不安全的事件才有单元，单元一发放就释放。

能耗口径（11-13 晚）：以事件为观测单位时，没有事件的方框权重为 0，对膜电位、归属量和状态都没有贡献，所以只算有事件的方框（事件驱动，严格等价，单元测试 `test_empty_boxes_cost_nothing`）。方框求和按事件驱动实现计：方框内每个事件做 2 次累加（计数 + 分数）；GPU 代码用积分图得到同样的整数和。能耗 = 4.6 pJ × MAC + 0.9 pJ × AC，按每 8 s 流报告（`eval_sdu.py`）。

## 6. 不主张的内容

- 不说膜电位是校准的后验（留出数据上过度自信），只说按后验训练；定案的安全性由校准的停止规则保证。
- 不说首次把序贯检验或漂移扩散用于 SNN（DDM + SNN、SPRT-TANDEM、CETUS、ANCAT、ADP-C 均是先例）；新意在三处改造用于逐事件流式分割的组合。
- 不说与事件数无关：单元数随"不确定事件"数增长，靠入口规则和发放即释放控制。

| 策略 | test IoU | ACC | Pd | Fa (×10⁻⁶) | 生成单元 | 生成者平均等待 |
|---|---:|---:|---:|---:|---:|---:|
| 骨干 | 0.8766 | 0.9672 | 0.9524 | 13.45 | 0 | — |
| 全部第 0 步 | 0.8964 | 0.9697 | 0.9489 | 10.09 | 100% | 0 |
| 全部等到截止 | 0.9071 | 0.9678 | 0.9484 | 8.12 | 100% | 9.66 窗 |
| 完整校准 | 0.9068 | 0.9671 | 0.9476 | 8.02 | 2.13% | 3.11 窗 |

V11 同骨干（逐事件最近邻）test 0.9202，ACC 0.9753、Pd 0.9572。val：0.8892 对 0.8932。停止规则达标：与截止结论不一致 0.00006，每窗平均 17.7 MMAC（骨干约 1260 MMAC）。

诊断：
- 增益几乎全是去误报，阈值附近的漏检目标救回率只有 V11 的一半左右（离阈值 −4～−2.5：21% 对 49%）；已检出的近阈值目标在等待中被压低（0.5～1.5：第 0 步 92% → 截止 85%）。
- 两通道证据在第 1 步就塌了（目标单元的目标通道 4.18 → 1.47，之后不再增长），归属量每窗线性增加约 60：所有窗一起平均，新窗把本窗证据冲淡，等待无法累积证据，与序贯检验的原理矛盾。
- 按目标速度分组，慢目标同样落后，所以不是"目标飞走"造成的。
- 工程：服务器 torch 1.9 默认 TF32，离线轨迹最大偏差 2.35（截止判决 1 / 60 万处不同）；流式层按出生窗分组逐组计算，每窗 32 ms。

### 7.2 第二轮改动（11-13）

式 4、式 5 改为"窗内平均、窗间累加"；变体：方框 / 事件为观测单位。关闭 TF32；流式层改为每窗一次批量计算（本地 RTX 5060 每窗约 10 ms，纯 FP32 下与离线 0 处不符）；训练每次混洗约 37 条录像的样本；停止界只收拢不放宽。

结果（v5s37，判决种子 0，test 完整校准）：事件版 0.9191 / ACC 0.9711 / Pd 0.9543 / Fa 7.37e-6，4.0% 的事件生成单元，平均等 1.71 窗；方框版 0.9177。同一入口下统一等 0 / 2 / 5 窗：0.9069 / 0.9163 / 0.9180。

### 7.3 判决层能耗（11-13 晚）

事件驱动口径下重算第二轮主模型（test 完整校准）：每窗 60 个单元，14.3 MMAC（稠密 21.2）+ 0.13 M AC，**约 10.6 mJ / 8 s**，是 BIR 骨干（约 2.6–3.3 mJ / 8 s）的 3–4 倍。每步约 24 万 MAC 中，新窗方框嵌入（2d² / 方框）占大头，核账的值头（dH / 方框）其次；方框求和的累加可以忽略（约 0.02 mJ）。

改法是换"读框方式"（`--tokens`），不动序贯检验的结构（归属、窗内平均窗间累加、两通道、重新核账、校准停止）：

| 读框方式 | 一个方框怎么读 | 每单元每步 MAC（实测框数） |
|---|---|---:|
| mlp（第 1–3 轮） | 内容 + 槽位 → LayerNorm → 64 维键、值；值头 GELU | 约 24 万 |
| linear | 去掉 LayerNorm，键值对特征线性（部署时折叠成 5×d 矩阵 + 槽位表），d = 32 | 约 1.7 万 |
| glm | 不嵌入：每个方框的证据 = 它的 5 个统计量的线性模型，系数按（窗偏移、方框、头）固定，再由状态整体平移 | 约 0.6 万（归属门读统计量时约 0.8 万） |

三者都去掉状态更新里的前馈块（`--context-ff off`）。linear / glm 中每个通道的两个头感受野初值分开（近 / 远），否则距离门下同通道两个头永远一样。第四轮在服务器上跑 e_glm / e_glm_attr / e_linear（v5s37，种子 0）。结果：val 0.8912 / 0.8914 / 0.8901，test 0.9183 / 0.9196 / 0.9187，判决层 0.205 / 0.220 / 0.790 mJ / 8 s。

### 7.4 候选：逐窗累加（积分到界，11-13 晚）

单元每来一窗只读这一窗：U(k) = U(k−1) + I_E(k) − I_I(k)，越过校准界即发放。状态由三个累计和算出：累计归属量、按归属量加权的特征和、各通道累计证据，算法与重新核账版"一次核账所有窗"完全相同（单元测试 `test_ledger_context_as_reaudit`：读法不依赖状态时两版逐步一致）。所以两版只差"旧窗要不要用新状态重读"。修正了旧逐窗累加的缺陷：旧版"状态 += 本窗变化量"有正反馈，状态随步数无界增长（第三轮 audit_ledger 用的是旧定义）。流式层支持逐窗累加，每单元只存膜电位、状态和三个累计和（glm 时约 60 个数，对比重新核账的约 3600 个记号缓存），每步计算恒定（glm 约 3.5k MAC，去状态约 2.6k）。第五轮 l_glm / l_glm_noctx（v5s37，种子 0）。判定：逐窗累加的 val（诚实）不低于 e_glm 超过 0.001 → 用逐窗累加；去状态版不低于有状态版超过 0.001 → 删状态。

结果：l_glm val 0.8921 / test 0.9192 / ACC 0.9668 / Pd 0.9447 / Fa 6.09e-6，0.144 mJ / 8 s；去状态 val 0.8882 / test 0.9163。按规则用逐窗累加、保留状态。用户 11-13 定为主模型（"四个指标差别不大时选最可解释、最有新意的"）。

## 8. 最终模型 l_glm（11-13 晚定）

`tools/v17/train_sdu.py` 的默认值即主模型：`--tokens glm --gate distance --audit ledger --context on --context-ff off --dim 32 --heads 4 --value ei --pool window --evidence events --levels 4`，11 步（500 ms），12 轮，11,760 个参数。

每个判决单元每窗一步：读本窗 33 个方框中有事件的（平均约 21 个）→ 归属 = 距离的固定表（学到的半径：目标头 5.5 / 85.6 px，背景头 11.7 / 48.8 px）× 事件数 → 每框证据 = softplus（5 个统计量的线性模型，系数按窗偏移、方框、头，状态整体平移）→ 本窗按事件加权平均 + 伪观测 → 兴奋电流 I_E、抑制电流 I_I → U(k) = U(k−1) + I_E − I_I（起点 z0）→ 更新三个累计和与状态 → |U − τ| ≥ b_k 即发放。停止界（v5s37 种子 0）：入口 5.04，之后 4.25 → 0.79 只收不放。

已知代价与局限：

- Pd 比原读法低约 0.8 个点（test 0.9447 对 0.9517），丢的是每帧只有 1–3 个事件的稀疏目标帧（test 5234 个目标帧中净丢 52 个）；IoU 不受影响，Fa 更低。
- "窗内平均"本身没有精度证据（第三轮"每个事件独立求和"不差），论文只主张"每窗一次有界的观测、窗间累加"；"所有窗一起平均"明显差。
- 判决单元目前是混合形式：积分与发放是脉冲式的，输入电流由分级运算给出；纯脉冲版放到最后（骨干 BIR 也是整数消息的混合形式）。
- 跨平台：骨干先验 z0 因消息量化在不同 GPU 上少数事件不同，论文数字统一用服务器结果；同一平台上流式与离线逐事件一致。

最终轮（`tools/v17/round_v17.sh` 的 f1–f7，19 个作业）：主模型 3 骨干 × 3 判决种子；消融（都在 l_glm 上改一处）：重新核账、去状态、所有窗一起平均、每个事件独立求和、方框为观测单位、内容归属、单通道；开发项（不改主模型定义，作为后续候选）：级联微调（`--cascade-from`：只用入口界以内的事件微调，按"入口 + 截止"的 val IoU 选轮次，微调前的模型也参与比较）、3 级方框、8 轮训练。结束后在空闲卡上用 `stream_sdu.py --backbone` 测端到端（骨干 + 判决层）每窗耗时。
