# V16 r4 本地验证记录

日期：2026-11-13。分支：V16。对应方法见 `V16_R4_METHOD.md`，部署命令见 `V16_R4_SERVER.md`。

## 结论与证据边界

本轮实现已能在固定阈值 0.9 下，以小幅增加的读出计算降低验证集误报，并保住相对第二次原读出的召回与 Pd。但目前只有 seed37、同一个验证集上的小幅收益，**协方差结构相对同容量普通双观察头的独立贡献仍弱**。不能据此宣称测试集四指标必然改善、达到 90% IoU，或已经满足论文贡献强度要求。

本轮冻结的初始化是已经完成的 r2 seed37 骨干，保留其 BIR、跨窗状态和通信约束训练结果。对照中的 second 是该骨干的第二次读出，不是历史原版 V5 的同名表格结果。当前阶段只拟合统计量、训练新头，没有重新端到端训练 U-net。

## 训练与选模协议

- 训练集 99 段录像，验证集 24 段录像；本轮开发、消融和诊断均未使用实际测试集。
- 三个头均重置 seed37、独立训练，沿用同一正式 `fit_cached_head`、CPU 四线程、相同样本顺序和损失。统计量只由训练集拟合；复用各自已经生成的固定缓存。
- 100 ms 窗长、50 ms 步长、阈值 0.9 不变。最多 20 轮，至少 8 轮，耐心值 5。
- 验证集候选要求 IoU、ACC、Pd 不低于固定 second，Fa 不高于 second；合格者按 IoU 选择。零修正作为可行回退。该选模约束不保证未知测试集表现。

## 计算与耗时

模块新增 144 个可训练参数、6169 字节固定统计缓冲区。每对事件线性部分约 1368 MAC，不包括骨干、事件 gather、激活及内存读写。没有逐事件近邻检索、多轮注意力或隐藏状态迭代。

正式 CPU full 对照：20 轮，小头纯优化及训练风险扫描累计 48.13 秒，含每轮验证 108.74 秒；统计及缓存已复用，**不包含预处理成本**。完整训练成本应另计训练统计提取、训练/验证缓存和在线一致性检查；已有骨干预训练也不包含在该数字中。

本次正式 GPU 全流程共 1228.79 秒（约 20 分 29 秒），其中统计提取及训练/验证缓存 1030.82 秒，小头纯优化与训练风险扫描 62.33 秒、含每轮验证 171.93 秒，其余为初始化、在线一致性等开销。共享 GPU 下预处理占主要时间，不能把 62 秒当作完整训练时长。这些数字不含已有骨干的预训练。

本次所选头的独立在线审查位于 `Res/v16_r4_final_online_audit/result.json`。上述三段录像各重复两次，second 累计推理 11.865 秒、main 14.152 秒；预热后每步均值 12.319→14.715 ms，main 的 p95/p99 为 17.167/18.602 ms。峰值已分配显存 243.37→243.99 MiB。采样记录检测到其他 GPU 进程，这组时间约增加 19.27%，但共享 GPU 干扰下不能将其作为独占开销定值或宣传功耗下降。

较早的同结构旧头审查 `Res/v16_r4_online_audit/result.json` 在不同负载时测得 second/main 累计 5.388/6.035 秒、每步均值 5.556/6.236 ms。它使用旧损失所选权重，保留作为历史测量，不与本次新头的正式结果混用。

上述对照是相同 100/50 ms 骨干下的第二次读出与修正读出，不代表相对原版 50 ms V5 的完整成本差。功率采样观察到其他 GPU 进程，不能作为单模型能耗结论。推理步耗时还须与采集等待分开：内部事件额外等待一个 50 ms 步长，事件发生至第二次覆盖输出的采集等待通常为 50–100 ms，再加计算时间。

## 更大窗口的诊断

`tools/probes/probe_v16_window_scale.py` 已比较 100/50、200/100、400/200 ms。训练集 99 段用于表示统计，验证集按密度选 3 段用于冻结权重迁移诊断。增加窗口后网络步数减少，但时间 bin 宽度、神经元 dt、事件密度、通信率和等待时间一起改变；直接使用 100/50 权重出现明显退化。这不是匹配重训实验，**不能据此断言大窗口方案无效**。

固定 8 秒输入，网络步数为 159/79/39；全训练集平均采集等待约 75.45/149.54/296.07 ms。单次待判缓存规模随窗口增加，原事件读出线性运算总数几乎未减少。若做公平的大窗重训，需要匹配新的归一化、增益标定、物理 TBPTT 时长、状态 dt 及每秒通信预算，不能只修改 window_ms。

因此本次服务器候选仍使用已经匹配的 100/50 ms，避免把窗口分布变化与新模块效果混在一次验证中。诊断来源：`Res/v16_window_scale_diagnostic_20261113/summary.json`。

## 论文表述约束

Fisher/Hotelling、Schur 补、白化、约束优化和滑动窗口均为既有原理。本实现的可解释设计是用训练类内相关结构组织两个上下文读出，再以有界修正和固定工作点的误报/漏检目标训练。它不实现精确贝叶斯去重，不声称残差独立，也不保证实际分布的误报上界。

白化在保留的通道中是可逆线性变换，普通 MLP 原则上可以学到等效变换。相对同容量对照的独立收益需要进一步验证，不能仅凭公式或架构图证明创新有效。当前候选适合按既定 seed37 流程上服务器核验，不应提前宣告模型已经“完美”。
