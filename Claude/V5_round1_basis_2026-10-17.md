# V5 第 1 轮设计依据（2026-10-17 定稿）：流式 SNN 底座的通信接口

来源：我的缺陷分析，经过两轮外部意见核对（采纳、部分采纳的理由见当天对话）。第 1 轮的神经元设计以本文件为准。

---

## 0. 四个量的框架

| 记号 | 含义 |
|---|---|
| h_k | 内部表征：当前时刻、包含所需历史的表征 |
| ĥ_k | 接收端对 h_k 的估计 |
| q_k | 脉冲消息：对 ĥ 的离散修正 |
| e_k = h_k − ĥ_k | 通信误差 |

研究目标：**跟踪"当前时刻、包含所需历史的内部表征"**。

要分别回答三个问题，它们不是互斥的选项：
- 想表达什么：目标是 h_k；
- 脉冲携带什么：对接收端已有估计的离散修正；
- 接收端如何恢复：按明确的递推规则更新 ĥ，误差定义为 h − ĥ。

这样做的好处是能区分两种原因：
- h 本身的历史响应：h 为什么仍然很大；
- 通信造成的跟踪滞后：ĥ 为什么还偏离 h。

它不会自动消除拖尾。负脉冲首先表示"减少当前估计"，不能直接赋予"目标离开"这类任务含义。

## 1. 用四个量重写 V1 的 LIF（由引理 1 精确推出）

V1 的方程：u_k = β·u_{k−1} + I_k − θ·s_k，s_k = H(β·u_{k−1} + I_k − θ)。

令：
- h_k := Σ_m β^m I_{k−m}，即 h_k = β·h_{k−1} + I_k；
- ĥ_k := θ·Σ_m β^m s_{k−m}，即 ĥ_k = β·ĥ_{k−1} + θ·s_k。

精确成立：
- **u_k = h_k − ĥ_k = e_k**；
- 发放条件等价于 **h_k − β·ĥ_{k−1} ≥ θ**。

所以 V1 的 LIF 就是一个**闭环、单极、1 bit 的 ΣΔ 跟踪器**：
- 目标 h 是输入的漏积分，**隐式**存在；
- 解码器 ĥ 也是**隐式**的，按同一个 β 衰减；
- 消息 q = θ·s ∈ {0, θ}，每 tick 最多 1 个；
- **唯一显式存在的状态是误差 e，也就是膜电位 u**。

一个 β 同时决定三件事：h 的记忆衰减、ĥ 的衰减、e 的动力学。

**编码器与解码器不一致**：真正的下游神经元，是用它自己的 β′ 和权重去积分脉冲的。β′ ≠ β 时，发送端算误差所参照的 ĥ，接收端实际上并不持有。

## 2. 缺陷 1：有限的脉冲通信接口（定稿措辞）

**1a　负状态积累导致的恢复滞后**
- 持续负驱动 −a 下，u_k = −a·(1−β^k)/(1−β)，趋于 −a/(1−β)，有界，但尺度放大约 1/(1−β) 倍。
- 设切换输入时负状态的幅值为 A（u_0 = −A），之后输入正的 b，首次发放前 u_n = b/(1−β) − (A + b/(1−β))·β^n。
- 发放输出的代理梯度随着离阈值越远而变小；但时间状态路径的导数仍是 β。
- 用四个量来说：h < 0 的负表征无法用单极消息传出去，于是 e = h − ĥ 停在负值。

**1b　发放容量有限导致的幅值混淆与延迟释放**
- 每 tick 最多 1 个脉冲：I > θ 时，不同强度都输出"每 tick 都发"。
- 在持续恒定输入、已经进入每步都发放的状态时，极限是 u∞ = (I − θ)/(1−β)。
- 停止输入后，残留状态可能继续发放，也可能被泄漏消耗。尾部发放是否有害，取决于编码和读出的语义。
- 用四个量来说：h − β·ĥ 远大于 θ，每 tick 只能修正 θ，跟不上。

**1c　缺少明确的表征撤销通道**
- 发放率下降和负权重都能表达"减少"，所以不能说"完全不能报减"。
- 真正的限制是：下游已经保存了一个持续的表征时，单极接口发不出带符号的修正去撤销它，下降只能靠沉默、泄漏或其他通道。
- 用四个量来说：h 下降得比 β 衰减更快时，ĥ > h，e < 0，没有撤销消息可用。
- 引入 −1 之前必须先说明：撤销的是哪个量、接收端如何解码、是否会误抵消仍需保留的历史、上下游时间常数不同或出现饱和时撤销是否仍然正确。

**1d　一次性或持续弱输入的不可传达区间**
- 从零状态出发：持续常数输入 I ≤ θ(1−β) 时永远不会首次发放；单次输入 0 < I_1 < θ、之后无输入时，也不会发放，状态只会衰减。
- 已有较高膜电位时，微小输入也可能触发脉冲。
- 阈下信息没有传出，是结构事实；它是否必须传出，是需要另行论证的设计目标。滤掉小信号有时正是需要的功能（例如压掉噪声事件）。

**1e　有限通信容量下的精度与延迟取舍**
- 在固定通道数、每步固定离散输出容量下，表征精度、响应时限与通信预算存在约束，具体关系由编码和解码方式决定。
- 多层组合后的精度与响应时限，必须根据具体的状态更新、通信和连接方式推导，不能由单层结论直接外推。V1 有跳连，层内又在同一 tick 依次更新。

**五项的关系**：1a、1d 是弱驱动或受抑制时的传递问题；1b 是过载；1c 是撤销语义；1e 是覆盖全部的容量约束。

**流式运行的加重因素**：通常的静态 SNN 在独立样本的边界会重置状态；持续流式运行缺少这种周期性重置，因此极端工作状态可能跨越更多输入持续存在。这不等于说静态 SNN 没有这些问题：它在一个样本的内部同样可能沉默、饱和或恢复缓慢。

## 3. 第 1 轮的 7 条要求（定稿）

1. **因果、单步**
   - 每个外部输入只触发一次各层状态更新，不依赖内部反复收敛；
   - 明确每步消息的字母表与数量。
2. **响应有条件可界定**
   - 对声明范围内的表征上升、下降与符号变化，规定允许误差与响应时限；不承诺任意变化都能在 1–2 步完成。
   - 容量下界：单接口每步最多发送一个幅值为 θ 的修正，初始重建准确，目标发生一次跳变 D 时，K ≥ ⌈max(0, |D| − ε)/θ⌉。改用多通道、多脉冲或可变幅值时，按相应的通信容量重写。
3. **状态尺度与静息行为可控**
   - 对有界输入，证明状态有界或处于规定的工作范围；
   - 零输入、零状态时保持静息（F(0,0) = 0，G(0,0) = 0）；历史状态允许产生有定义的后续响应。注意"突触映射满足 W0 = 0"与"整个神经元在当前无输入时不发放"不是一回事。
   - 归一化只约束性质：因果性、零状态行为、局部性、对稀疏执行的影响、计算成本。不预先写死方法名。
4. **通信目标与误差明确**
   - 先定义编码的是当前表征、变化量还是累计量，再定义误差；给出正常工作区间与过载后的行为，避免靠硬截断隐藏信息损失。
   - **编码器与解码器一致**：发送端与接收端对脉冲幅值、符号、时间演化和重置规则的解释一致。自适应阈值或幅值所需的信息必须能在接收端获得，并计入通信与计算成本。
5. **记忆与通信职责可区分**
   - 记忆按所需的时间规律演化；通信误差相对于当前的目标量更新。
   - 发送脉冲、遗忘历史、撤销表征，三者的作用必须能够分别解释。
   - "误差永不泄漏"不是目标：跟踪当前表征时，已经被后来的变化抵消的旧差异，不应该再补发。
6. **资源成本可量化**
   - 推理状态不随流的长度增长；
   - 同时给出每个神经元实际的状态数、字节数、计算与访存成本。固定 K 个桶也是关于流长度的 O(1)，不能只凭大 O 判断是否便宜。
7. **训练与执行一致**
   - 第一版兼容现有 TBPTT；明确代理梯度和截断规则；验证逐窗与分块执行一致；分别分析深度、时间两个方向的梯度。
   - **多层、长时间组合后的性质**：分析单层的误差、响应和状态性质在跨层、跨时间组合后是否保持，以及何时失效。单层状态有界 ≠ 网络对扰动不敏感；单层编码误差小 ≠ 经过大权重和非线性后误差小；每步误差小 ≠ 长时间后误差小；为限制误差而强制快速遗忘，可能损伤记忆。

## 4. 第 1 轮设计要回答的问题（下一步）

1. h_k 的更新规则：记忆动力学，它自己的时间常数，与 e 分开。
2. ĥ_k 的更新规则：接收端可以独立计算，满足编码器与解码器一致；是否衰减、按什么衰减。
3. q_k 的字母表与容量：单极还是双极，每步一个还是多个，幅值固定还是自适应；成本如何。
4. e_k 的动力学：由 h 和 ĥ 推出，不另设泄漏；它的有界性和过载行为。
5. 上述四项满足第 2–7 条的条件和边界，以及在 U-Net 中层层组合后的性质。

到这一步，才决定是否需要双状态、双极脉冲、自适应阈值或归一化。
