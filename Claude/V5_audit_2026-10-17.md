# V5 标准对照审计：流式 SNN V1 与教科书 / 标准实现逐层对照（2026-10-17）

**做法**：只读 V1 代码和文献，不用任何实测量（饱和比例、消融差值、κ 等一律不作依据），不跑实验，不写代码。每一项都列出四样东西：标准是什么（出处）、V1 怎么做（代码位置）、两者的差别、按理论推出的后果。

**标记**：

| 标记 | 含义 |
|---|---|
| ✔ | 与标准一致 |
| △ | 偏离标准，按理论应回到标准（低风险修正，本身不算创新） |
| ◆ | 教科书或标准理论里有、深度流式 SNN 普遍丢掉的机制 → **创新来源候选** |
| ○ | 流式工况下标准理论本身没给答案 → **开放问题，也是创新来源** |

V1 的事实（代码）：
- 神经元 `model/lif2d_stream.py:4-7`：U_pre = β·U_prev + I；S = H(U_pre − θ)；U = U_pre − θ·S（减阈值复位，复位支路 detach）；τ = τ_min + (τ_max − τ_min)·sigmoid(a)；β = exp(−Δ/τ)。
- 配置：Δ = 50 ms，τ ∈ [50, 2000] ms，所有通道初值 200 ms（β ≈ 0.779），θ = 1，代理梯度 1/(1+|v|)²。
- 网络 `model/evspsegnet_stream.py:3-12`：7 个"Conv3×3（bias=False）→ 逐通道增益 → LIF"单元，3 次 stride 2；没有 BN；神经元之间没有循环连接（膜电位只在原位置递推）。
- 读出 `:151, :541-554`：MLP([dec1 的 U_pre, p, t_local])。
- 增益 `:605-656`：训练前逐层校准一次（正电流的 99% 分位 × 增益 = θ），之后继续可学。
- 输入 `dataset/stream_windows.py:114-126, 190-203`：每窗 12 通道，即整窗正负计数加 5 个时间 bin × 2 个极性；X = clip(log1p(C)/q99, 0, 3)。5 个 bin 是输入通道，不是 SNN 时间步。
- 训练：标准有状态 TBPTT（k=16，B=4），逐事件 BCE（pos_weight），Adam，全局裁剪 1.0。

## L0 问题层：网络在算一个什么样的函数

**0.1 决策时刻 ○**
- 标准：信号处理里分滤波（只用过去）、固定滞后平滑（等 L 再判）、整段平滑；序贯检验（Wald SPRT）里，"何时判"本身是决策变量。
- V1：块因果。事件在所在窗的末尾才判，等于隐含一个 0–50 ms 的滞后，这个滞后由窗的时钟决定，不是设计出来的量。
- 后果：滞后和窗长绑在一起，改窗长就同时改了"能看到多少未来"。
- 创新来源：把"决策滞后 / 可修订输出"做成范式本身的一部分（V3 走过的方向，但当时是推理期补丁）。

**0.2 输出与损失 ✔**
- 逐事件 BCE + 类别权重是标准做法。
- 注意：pos_weight 改变了概率的校准，阈值 0.9 对应的不是真实后验 0.9。这只影响口径解释，不是偏离。

## L1 输入表示

**1.1 窗内时间当通道、窗间时间当递推 ○**
- 标准：
  - 神经形态的原生方式是每个事件就是一个输入脉冲，在它自己的时刻进入神经元；
  - 帧式表示中，体素网格用时间上的双线性插值避免量化（Zhu 2019）。
- V1：窗内时间用 5 个硬分箱的通道表达（静态卷积处理），窗间时间用膜电位递推。同一段时间被两种机制分别处理，窗边界处不连续。
- 后果（定义推出）：
  1. 对窗的相位不等变：同一串事件整体平移 20 ms，网络的响应会变；标准的时间平移等变只在 50 ms 网格上成立。
  2. 递推的时间分辨率就是 Δ。
  3. 硬分箱有量化误差，标准做法是插值。
- 创新来源：见 L4.5"时钟"。

**1.2 计数归一化 ✔**
- log1p 加训练集 q99 是固定的 Weber 型压缩，属于"按写明规则从训练集导出"的常数，符合 §0.2。
- clip 3 意味着计数到某个值后完全饱和，这是一个设计选择。

**1.3 第一层输入是实数 △（已知取舍）**
- 输入是归一化计数，不是脉冲，所以第一层是 MAC 运算。与"脉冲驱动"的标准有差别，但事件相机 SNN 的帧式输入很常见。

## L2 神经元

**2.1 时间常数同时改变了增益 △（最明确的偏离）**
- 标准：
  - **教科书 LIF**（Gerstner《Neuronal Dynamics》第 1 章）：τ du/dt = −(u − u_rest) + R·I。τ 只决定"多快"，稳态 = R·I，与 τ 无关。对脉冲（δ 电流）输入，每个脉冲让 u 跳 Rq/τ，PSP 面积恒为 Rq：τ 用"高度"换"宽度"，面积不变。
  - **精确离散化**（输入在一窗内恒定）：u_k = β·u_{k−1} + (1−β)·R·I_k。
  - **PLIF**（Fang 2021，SpikingJelly 默认 decay_input=True）：H = V + (X − (V − V_reset))/τ，输入按 1/τ 缩放，增益与 τ 无关。
  - **SSM**：Mamba / S4 的 ZOH 离散化下，稳态增益 B̄/(1−Ā) ≈ −B/A，与步长 Δ 无关，Δ 只改快慢；LRU（Orvieto 2023）专门加了归一化因子，防止 |λ|→1 时状态变大、训练不稳。
- V1：U = β·U + I（snnTorch 的写法；snnTorch 教程说明 (1−β) 被吸收进权重了，这只在 β 固定时成立）。V1 的 τ 是可学的。
- 后果：
  - 稳态增益 1/(1−β) 随 τ 变化。τ 可学范围是 50–2000 ms，对应增益 1.6–40.5，跨约 26 倍；初值 200 ms 时是 4.5。
  - 网络想要"记得久"，就必须同时接受"增益大、更容易远离阈值"。
  - 表达能力上，逐通道增益 g 可以抵消，所以不是能力问题，而是**参数化问题**，影响的是优化的几何和稳定性。这正是 LRU 的论点。
- 结论：应回到标准参数化（τ 只管快慢）。不是创新。

**2.2 复位方式 ✔ / ○**
- 标准：
  - 教科书神经元和 SpikingJelly 默认都是复位到 u_r（硬复位）；
  - 减阈值复位来自 ANN→SNN 转换，用来保住发放率的精度（Rueckauer 2017、RMP-SNN）；
  - snnTorch 默认减阈值；
  - 复位支路 detach 是标准训练技巧（Zenke & Vogels 2021）。
- V1：减阈值复位 + detach。两种标准里的一种。
- 后果（理论）：
  - 减阈值复位让神经元成为 ΣΔ 调制器（见 L5.1），残差不丢；
  - 硬复位丢掉残差，但状态有界；
  - 两种都管不住负的一侧。
- 开放问题：膜电位同时是记忆时，复位决定了"状态是什么意思"——是编码残差（减阈值），还是"距上次发放的时间"（硬复位）。标准理论没有针对流式记忆给出选择。

**2.3 电流型突触 vs 电导型突触 ◆（创新来源，重点）**
- 标准（教科书：Gerstner 第 3 章、Dayan & Abbott 第 5 章）：
  - 真实突触是电导型：C du/dt = −g_L(u − E_L) − g_e(t)(u − E_e) − g_i(t)(u − E_i)。
  - 电流型（I 与 u 无关）是在 u 远离反转电位时的近似。几乎所有深度 SNN（包括 V1）用的都是电流型。
- 电导型的三条性质（由定义直接推出，不靠实测）：
  1. **状态有界**：稳态 u* = (g_L·E_L + g_e·E_e + g_i·E_i)/(g_L + g_e + g_i)，是反转电位的凸组合，永远在 [E_i, E_e] 内，抑制不会无限累积。
  2. **除法式归一化**：输入电导整体放大 c 倍（事件率翻倍）时，在 g ≫ g_L 的区域 u* 与 c 无关，即对输入率的乘性变化不变（Weber 律）。这是 Carandini & Heeger（2012）"归一化是典型神经计算"的分流抑制实现。抑制的反转电位接近静息时，作用是除法（降增益）而不是减法。
  3. **输入决定的时间常数**：τ_eff = C/(g_L + g_e + g_i)，输入越强、积分越快、遗忘越快（高电导态，Destexhe 2003）。精确离散化是 u_k = u*_k + (u_{k−1} − u*_k)·exp(−Δ/τ_eff,k)，这在形式上就是**选择性 SSM**：Ā_k 由输入决定，对应 Mamba 的输入依赖 Δ。
- 与流式需求的关系（理论上的需要）：
  - 无限长的流要求状态有界（性质 1）；
  - 事件率随对比度、速度、光照成倍变化，要求对乘性变化不变（性质 2）；
  - 长程序列模型需要"按输入决定记还是忘"（性质 3；Tallec & Ollivier 2018 证明，时间扭曲不变性要求门控）。
  - 一个教科书机制同时给出三条。
- 与"脉冲驱动 / 零输入零电流"的兼容性：
  - 有符号的卷积核可以拆成正负两部分，W⁺*S 驱动 g_e，W⁻*S 驱动 g_i，突触仍然只做加法；
  - 没有输入时 u 留在 E_L（取 0），零输入仍然零输出；
  - 代价是神经元更新里有除法或指数（Loihi 2 的可编程神经元能做）。
- 文献：
  - 计算神经科学里是标准模型；
  - 深度 SNN 训练中没有查到用电导型突触做流式视觉的；
  - 最接近的是 NeuronSpark（arXiv 2603.16148，2026-03），它把电流型 LIF 写成选择性 SSM，衰减、增益、阈值另外加门控，做的是语言模型。
  - **需要更仔细地查重。**
- 可证伪预测（理论给出，待定是否做）：
  1. 输入事件率整体乘以 c（重复或稀疏抽取事件）时，电导型网络的输出比电流型稳定；
  2. 不需要额外的归一化层；
  3. 不同层的 τ_eff 随场景忙闲自动变化。

**2.4 发放非线性与代理梯度 ✔（但依赖 L3.1）**
- Heaviside + fast-sigmoid 代理梯度（SuperSpike，Zenke & Ganguli 2018）是标准。
- 注意：代理梯度的宽度以 θ 为单位固定。只有膜电位分布落在阈值附近时，代理梯度才起作用；标准做法靠归一化保证这一点（tdBN 的出发点，Zheng 2021）。V1 没有归一化（L3.1），所以没有任何机制保证这个前提。

**2.5 适应（第二状态变量）◆**
- 标准（教科书 Gerstner 第 6 章 AdEx / 发放频率适应；深度 SNN：LSNN / ALIF，Bellec 2018；Salaj 2021 eLife）：
  - 第二个慢变量 w 跟踪自身发放，抬高阈值或减去电流。
  - 功能有三个：对输入率做高通（只对变化响应，对持续输入习惯化）；提供比膜电位长得多的记忆（τ_w ≫ τ_m）；稳态调节（把发放率拉回）。
  - 突触层面对应的是短时程抑制（Tsodyks–Markram）。
- V1：没有。
- 与流式需求的关系（理论）：
  - 固定机位下，"原地反复出现的源"（静止闪烁、热像素、静止边缘）是持续输入，按定义会被习惯化；
  - 移动目标在每个像素上都是短暂的新输入，不会被习惯化；
  - 这就是 §6.1"复发 vs 暂态"判据的教科书实现，不需要手写背景模型。
- 理论预言的失效：悬停目标在原地持续出事件，也会被习惯化。
- 文献：ALIF 在深度 SNN 里已知；把适应当作事件相机流式检测的背景机制，没有查到直接先例，需要查重。

**2.6 不应期 = 窗长 ○**
- 标准：不应期约 1–2 ms。
- V1：每窗最多发 1 个脉冲，等于不应期 = Δ = 50 ms，发放率上限 20 Hz。
- 后果：一个神经元每窗只能传 1 bit；表达强度只能靠多个窗（延迟）或多个通道。属于 L4.5"时钟"的问题。

**2.7 突触动力学 ✔（可选扩展）**
- V1 是瞬时突触（δ 电流），单极点。
- 标准也有带 τ_syn 的二阶突触（snnTorch 的 Synaptic、Perez-Nieves 2021）。二阶神经元在 L5.1 的 ΣΔ 视角下有意义。

## L3 网络

**3.1 归一化 △ + ○**
- 标准：
  - 深度 SNN：tdBN（Zheng 2021）、BNTT、TEBN、MPBN。推理时用滑动统计量的 BN 是逐通道仿射，可以折进卷积权重和阈值，不破坏流式和脉冲驱动。
  - 流式 RNN：每步 LayerNorm（Ba 2016），RVT 等使用；循环网络的 BN 见 Cooijmans 2017。
- V1：不用归一化；训练前用分位数一次性校准逐通道增益，属于 LSUV（Mishkin 2016）类的数据依赖初始化，是标准初始化的一类。
- 差别：校准只在开始时把尺度放到阈值附近，训练中没有任何机制维持（这正是 BN 相对 LSUV 的作用）。
- 约束（理论）：事件驱动要求 f(0)=0（空白区域不产生电流），所以带平移的 BN 不能直接用，只能用只缩放不平移的归一化；而且必须因果；推理时最好能折叠，或者是神经元自身的机制。
- 开放问题：满足这四条约束的归一化，标准理论没有现成答案。电导型突触（2.3）的分流抑制正好是"神经元自身的、只缩放的、因果的局部归一化"。

**3.2 初始化 ✔**
- 卷积用 PyTorch 默认初始化，加数据依赖的增益校准（LSUV 类）。
- SNN 专门的标准还有"按膜电位波动初始化"（Rossbroich, Gygax & Zenke 2022），让膜电位均值和方差相对阈值落在目标区。V1 的分位数校准是同一类思路。

**3.3 状态转移的空间结构：对角 ◆ / ○**
- 标准：
  - 卷积循环网络（ConvLSTM，Shi 2015；ConvGRU）的状态转移是卷积：h_k = f(W_h * h_{k−1} + W_x * x_k)，状态可以在空间里移动；
  - TrajGRU（Shi 2017）进一步学"沿轨迹"的连接。
- V1：状态转移是对角的（每个像素、每个通道只乘 β）。神经元之间没有循环连接，记忆不能在空间里移动；跨窗的空间关系只能靠每窗的前馈卷积重新建立。
- 后果（教科书数值分析：CFL 条件）：
  - 显式格式每步只能把信息传到模板半径之内。
  - 循环核半径为 r、该层步幅为 s 时，状态的"搬运速度"上限是 r·s 像素 / 窗。V1 的 r = 0，所以状态不搬运。
  - 记忆只记"这个位置（大小约为感受野）过去发生过什么"。
- 创新来源：适合运动源的流的状态转移应该是什么（局部搬运、学到的流场、或者沿事件联系递推，即 §6.2 的谱系）。这次是从 ConvRNN 的定义和 CFL 条件推出来的，不是从实测推出来的。

**3.4 时空滤波可分离：同一层做不到跨窗的方向选择性 ◆**
- 标准（Adelson & Bergen 1985 运动能量模型；Hassenstein–Reichardt 检测器）：方向选择性要求时空**不可分离**（在 x-t 上倾斜）的滤波器，标准构造是把至少两种不同时间滤波（不同 τ 或延迟）的空间滤波组合起来。
- V1：单层跨窗响应的线性部分是 W(空间) × β^n(时间)，可分离（复位是非线性，但不产生 x-t 上的倾斜），所以单层没有跨窗的方向选择性。下一层把不同 τ 的通道组合起来才可能得到；而 V1 所有通道的 τ 初值都是 200 ms，初始化时就没有这种组合的条件，只能靠训练把 τ 拉开。
- 窗内的方向信息只来自 5 个时间 bin 通道，范围限于 50 ms。
- 创新来源：跨窗运动选择性的标准构造（多时间常数 / 延迟 + 空间偏移；可学习延迟见 DCLS，Hammouamri 2024）。这和 3.3、4.3 是同一件事的三个侧面。

**3.5 跳连传脉冲、解码器 ✔**
- 原版解码器有一半输入是实数（ConvT 输出），合并版可以严格改写成全部是脉冲（方案 C）。这属于工程取舍。

**3.6 读出 ✔**
- 读出用膜电位（不发放的积分器读出），是标准做法。
- 逐事件读 dec1 的 U_pre，加上 p 和 t_local。

**3.7 层间同步、没有延迟 ✔（可扩展）**
- 同一窗内 7 层依次更新、没有轴突延迟，是深度 SNN 的标准做法。可学习延迟是标准扩展，与 3.4 相关。

## L4 递推 / 状态理论（把 V1 当作流式序列模型）

**4.1 稳定性 / 有界性 △**
- 标准：SSM / RNN 要求特征值在单位圆内，并且状态幅度归一化（2.1）。
- V1：β < 1，线性部分稳定，但状态尺度 = 输入尺度 × 1/(1−β)，负的一侧只受输入幅度约束。
- 结论：修好 2.1 后，状态尺度与 τ 解耦；有界性还需要 2.3 或 3.1 来保证。

**4.2 衰退记忆 ✔**
- Boyd & Chua 1985：时不变、因果、具有衰退记忆的算子可以被一致逼近。无限长的流要求衰退记忆，V1 满足（β < 1）。
- τ_max = 2000 ms 是人定的上界，按 §0.2 应说明它属于哪一类常数。

**4.3 时间常数的初始化：单一时间尺度 △**
- 标准：
  - S4D / Mamba：Δ 在一个范围内对数均匀初始化；
  - LRU：特征值模长在一个环内均匀；
  - SNN：Perez-Nieves 2021（Nature Communications）表明 τ 的异质性能稳定、改善时间任务；
  - HiPPO 的动机是一组覆盖多个时间尺度的基。
- V1：所有通道 τ 初值都是 200 ms。
- 后果：
  1. 初始化时没有多时间尺度的基；
  2. 长 τ 只能靠训练拉开，而 TBPTT（k=16，即 0.8 s）给长时间常数的梯度有截断偏差；
  3. 与 3.4 相连：初始化时没有跨窗方向选择性的条件。
- 结论：应回到标准（对数均匀的异质初始化）。不是创新。

**4.4 选择性 / 门控 ◆**
- 标准：LSTM / GRU 的门；Mamba 的输入依赖 Δ；Tallec & Ollivier（ICLR 2018）证明，对时间扭曲（时间的单调重参数化）不变要求可学习的、由输入决定的时间常数，固定泄漏只对全局缩放成立。
- V1：β 固定，按墙钟衰减。
- 后果：同一个模式以不同速度出现时，V1 的动力学不同（不具备时间扭曲不变性）；源停止发事件时，记忆照样衰减。
- 创新来源：电导型神经元（2.3）天然给出由输入决定的 τ_eff，不需要额外加门。这是"教科书神经元本来就是选择性 SSM"的一条线。

**4.5 时钟：数据时钟 = 计算时钟 ○（创新来源）**
- 标准：
  - 计算神经科学的事件驱动仿真对 LIF 两次输入之间做精确积分（Rotter & Diesmann 1999；Brette 2007 综述），状态是连续时间的，在任意时刻都可以求值；
  - SSM 支持逐步不同的 Δ_k（S5）；
  - 事件流：EventSSM（Schöne 2024）逐事件更新、用全局状态做分类；Zubić（CVPR 2024）用可学 Δ 换窗频率不重训；EventProp（Wunderlich & Pehle 2021）给出连续时间 SNN 的精确梯度。
- V1：固定 Δ = 50 ms，数据时钟和计算时钟是同一个，带来三个后果：
  1. 不应期 = Δ（2.6）；
  2. 窗内时间改用通道表达，导致对相位不等变（1.1）；
  3. 输出频率和训练时的窗长绑定。
- 创新来源：用标准的连续时间公式（精确积分）把两个时钟解耦。状态是连续时间的，什么时候计算、什么时候输出，由事件或需求决定，同一个训练好的模型可以在任意输出频率下用。
- 注意：用户 10-12 放弃的 R 线（步长一致）与此有重叠；区别在于 R 线是"让离散网络对步长不变"，这里是"直接用标准的连续时间形式"。是否重开由用户定。

**4.6 训练视野与记忆尺度 ✔（已标准）**
- 有状态 TBPTT 是标准做法。
- 截断对长时间常数梯度的偏差是已知结论（Tallec & Ollivier 2017 ARTBP），只作解释，不改方法。

**4.7 初始状态 ✔**
- 录像开头零状态，训练中 batchify 的切点也清零，训练与推理一致。可学的初始状态是标准选项，不是必需。

## L5 编码 / 信息

**5.1 一个状态同时担两种角色：ΣΔ 编码 vs 衰退记忆 ○（创新来源）**
- 标准（信号处理 ΣΔ 理论；脉冲神经元 ≈ ΣΔ：Yoon 2017 IEEE TNNLS、Eckhorn 神经元的噪声整形文献）：
  - 积分器 + 1 bit 量化 + 反馈（减阈值复位）= 一阶 ΣΔ 调制器。
  - 量化误差留在积分器里，被推到高频（一阶噪声整形，20 dB/十倍频）。
  - 输入超过量化范围（每步输入 > θ）时过载，输出卡在每步 1 个脉冲。
  - 多 bit 量化器每多 1 bit 提高约 6 dB；高阶 ΣΔ 要多个积分器。
- V1：同一个膜电位既是 ΣΔ 积分器，又是带泄漏（β < 1）的记忆。
- 理论上的张力：
  - ΣΔ 要低频无误差，需要 β → 1（不泄漏），否则误差 ∝ (1−β)；
  - 无限长的流要求衰退记忆，需要 β < 1；
  - 单状态神经元必须在"编码精度"和"遗忘"之间折中。
- 创新来源：把两种角色拆到两个状态上（一个不泄漏的编码残差 + 一个泄漏的记忆）。这从理论上给"双仓"一个与原设计不同的、有原理的版本：不是"再加一份慢记忆"，而是"编码与记忆分开"。二阶 ΣΔ（两个积分器）在深度 SNN 中少见，需要查重；多 bit 脉冲已有（I-LIF、Loihi 2 graded）。

**5.2 稀疏与能耗的约束 ✔**
- 事件驱动要求 f(0)=0、没有 bias、脉冲稀疏，V1 满足。这条是 3.1、2.3 的硬约束。

## 汇总

### A. 应回到标准的偏离（修正，不算创新）

| 项 | 偏离 | 标准做法 |
|---|---|---|
| 2.1 | τ 可学时，"记多久"和"增益多大"绑在一起 | 精确离散化 / PLIF：输入乘 (1−β)，τ 只管快慢 |
| 4.3 | 所有通道 τ 同一个初值 | 对数均匀的异质初始化（S4D / LRU / Perez-Nieves） |
| 3.1 | 训练中没有维持工作点的机制 | 只缩放、因果、可折叠的归一化（具体形式见 ○） |
| 1.1 | 窗内时间硬分箱 | 时间上双线性插值（体素网格的标准做法） |

### B. 创新来源候选（教科书有、深度流式 SNN 丢掉的机制，或流式工况下的开放问题）

| 族 | 包含的项 | 一句话 | 文献状态 |
|---|---|---|---|
| **① 工作点与尺度** | 2.3 电导型突触、2.5 适应、3.1 归一化约束、2.4 代理梯度前提、4.4 选择性 | 教科书的电导型神经元本身就是"有界 + 除法归一化 + 输入决定时间常数"的选择性状态单元；深度 SNN 用电流型近似把这三条都丢了 | 深度 SNN 中没查到直接先例；NeuronSpark（2026-03）是电流型加门控的语言模型 → 需细查 |

### C. 各族之间的关系
- ① 的电导型神经元同时覆盖 2.3 / 3.1 / 4.4，并给出 2.4 的前提，是覆盖面最广的一条；它也是"SSM 替代品"最自然的出发点：选择性来自教科书神经元本身，而不是借 Mamba 的门。
- ② 是 SSM 理论里"连续时间 + 可变 Δ"在 SNN 上的对应。
- ③ 是视觉流特有的，也就是"源在移动"的问题。
- ④ 解释了单状态 LIF 的内在折中。
- A 类修正是做 B 类之前的前提：不先把 V1 变成标准的流式 SNN，B 类的任何效果都分不清来源。
