# V5 第一步：流式 SNN 的最小数学模型与三个问题（2026-10-17）

**范围**：只用定义和推导，不引用任何本项目的实测量。实测只在文末作旁证。

**三个问题**：
- Q1：流式 SNN 和"同一网络、每个输入算 T 步"的静态 SNN 相比，算得有多准？误差怎样随输入变化的快慢而变？
- Q2：一个深层、逐神经元各自递推的 LIF 网络，能存多少记忆、存多久？
- Q3：截断 k 步的 TBPTT 能学到什么？

---

## 0. 最小模型与记号

**单个神经元**（第 l 层，与 V1 完全一致）：
- 复位前膜电位：v[k] = β·u[k−1] + I[k]
- 发放：s[k] = 1 当 v[k] ≥ θ，否则为 0
- 复位后膜电位：u[k] = v[k] − θ·s[k]（减阈值复位）

**层与层的连接**：
- 第 1 层：I¹[k] = W¹·x[k]，x 是第 k 个 tick 的实数输入。
- 其余各层：I^l[k] = W^l·s^{l−1}[k]。
- 网络没有横向或循环连接：每个神经元只和自己的过去递推，对角形式。

**记号**：
- β = e^{−Δ/τ}。
- **记忆长度（以 tick 计）**：n = 1/(1−β)。τ ≫ Δ 时，n ≈ τ/Δ。
- **不复位膜电位**（漏积分）：F[k] = Σ_{m≥0} β^m I[k−m]。
- **指数滑动平均**：EWMA_n(I)[k] = (1−β)·F[k]，权重 (1−β)β^m 的和为 1。

---

## 1. 两个基本引理

**引理 1（电荷恒等式，精确成立）**

    θ · Σ_{m≥0} β^m s[k−m] = F[k] − u[k]

- 证明：把 u[k] = β·u[k−1] + I[k] − θ·s[k] 一路展开即得。
- 含义：用同一个 β 去看，脉冲序列等于不复位膜电位 F 减去残差 u。所以 LIF 是对**它自己的漏积分 F** 做 ΣΔ 编码，不是对瞬时输入 I 编码。

**引理 2（残差的界）**

- **不过载**：若每个 tick 都有 0 ≤ I ≤ θ，则 0 ≤ u < θ。
  - 证明：设 u_prev ∈ [0, θ)，则 v ∈ [0, βθ + θ)。不发放时 u = v < θ；发放时 u = v − θ < βθ。用归纳法即得。
- **正向过载**：I 持续大于 θ 时，每 tick 都发放，残差涨到 (I − θ)·n，此时输出卡在每 tick 1 个脉冲。
- **负向**：没有任何复位，持续的 −a 会让 u 趋于 −a·n，下面没有界。

## 2. Q1：计算角色——脉冲码能传多准、要等多久

### 命题 1（精度）

**结论**：用一个窗口为 n 的漏积分器读脉冲码，读到的是输入的指数滑动平均。在不过载时，误差不超过 θ/n（以输入为单位）。

- 定义读出：r̂[k] = (1−β)·Σ_m β^m s[k−m]。
- 由引理 1 和引理 2 得：r̂·θ = EWMA_n(I) − (1−β)·u，误差 |(1−β)·u| < θ/n。
- 这和"静态 SNN 跑 T = n 步"的量化误差同阶。也就是说，流式 SNN 把静态 SNN 的 T 次重复摊到了流上。
- 下游的 LIF 神经元本身就是这样一个读出器：β 相同时，它的膜电位 = W·(F − u)/θ。所以**每一层用自己的 τ 来确定读上一层脉冲码的窗口**。β 不同时，读到的是 F 再做一次平滑，误差仍是同阶。

### 命题 2（精度和滞后的权衡）

**结论**：用窗口 n 估计当前输入，总误差 ≤ θ/n + |b|·(n−1)，其中 b 是输入每 tick 的变化量。

- **滞后来源**：输入线性漂移 I[k] = a + b·k 时，EWMA_n(I)[k] = I[k] − b·(n−1)。也就是落后 n−1 个 tick，约等于 τ。
- **阶跃输入**：经过 j 个 tick，只追上 1 − β^j。
- **最优窗口**：n* ≈ √(θ/|b|)，此时误差约 2√(θ|b|)。
- **输入不变（b = 0）**：n 越大越准，相当于静态 SNN 的 T 越大越准。
- **输入快变**：误差按 √(θ·变化率) 增长。

### 命题 3（深度累积）

L 层串联时：
- **滞后**：总的平均滞后 = Σ_l (n_l − 1) 个 tick。级联几何核的均值相加。
- **量化误差**：每层贡献 θ/n_l，再被下游的增益放大。

要让每层精度都达到 ε，总滞后至少约 L·(θ/ε − 1)·Δ。

精度有三个来源：

| 来源 | 误差 | 代价 |
|---|---|---|
| 时间（n 个 tick） | θ/n | 滞后 |
| 群体（N 个神经元，残差错开时） | θ/(nN) | 宽度 |
| 每个脉冲的比特数 b | θ/(n·2^b) | 多比特 |

静态 SNN 用时间换精度，代价是计算步数；**流式 SNN 用时间换精度，代价是数据上的滞后**。这就是"静态 SNN 重复 T 次、流式 SNN 只输入一次"的精确说法。

### 命题 4（两端失控都会把幅值换成时间）

两种情况都由引理 2 推出：
- **正向过载**：持续输入 I > θ，停止输入后还会多发约 n·ln(I/θ) 个 tick 的"拖尾"。输入期间，I 超过 θ 的那部分信息不可见，要等到之后才发出来。
- **负向深抑制**：持续 −a 之后再来 +b，要过约 n·ln((a+b)/(b − θ/n)) ≈ n·ln(1 + a/b) 个 tick 才第一次发放。

两者都正比于 n，用的还是同一个 τ。

### 小结 Q1

- 流式 SNN 在每层上算的是"对平滑后的输入做 ANN 式映射，再加上 ΣΔ 量化误差"。
- 输入平稳时，它逐渐收敛，相当于静态 SNN 的 T 在增长。
- 遇到突变时，有 Σ n_l 个 tick 的滞后。
- 两端失控时，还会额外多出 n·log 量级的时间。

**已有工作**：
- ΣΔ / 过采样理论：教科书。
- 转换误差的分解（量化 / 截断 / 不均匀）：Bu et al. ICLR 2022、Deng & Gu ICLR 2021。
- 按变化量计算的 ΣΔ 网络：O'Connor et al. ICLR 2018。
- 视频中跨帧保留状态、按间隔清零可以加快收敛：ISCAS 2021。

**本节可能的新意**：把"τ 就是读码窗口"讲清楚，给出流式条件下精度与滞后的定律和深度累积，以及两端失控的对数时间代价。

## 3. Q2：记忆角色——能存多久、能存什么

### 命题 5（衰退记忆的上限）

**结论**：没有横向或循环连接时，网络的记忆在 Σ n_l 个 tick 量级内衰退；尾部按 e^{−mΔ/τ_max} 衰减，超出几个 τ_max 就不剩什么。这与训练无关。

- **线性部分**：第 k−m 个 tick 的输入对第 k 个 tick 的影响，等于各层几何核的卷积。
  - 均值 Σ β_l/(1−β_l)；
  - 方差 Σ β_l/(1−β_l)²；
  - 尾部约 m^{L*−1}·β_max^m，其中 L* 是 β 取最大值的层数。
- **非线性部分不制造持久性**：每个神经元每 tick 都收缩一次（因子 β）。一次发放的翻转只注入 ±θ，然后同样按 β 衰减。网络是有向无环的级联，没有任何中性稳定的模式。
- **要突破这个上限**，只有三条路：
  1. 把 τ 调大，但会和 Q1 的滞后、Q3 的可学性冲突；
  2. 引入有中性稳定模式的循环，即吸引子；
  3. 引入门控，让 β 依赖输入。

  V1 三者都没有。

### 命题 6（能存什么）

- 每个位置的状态，是各层特征在各自 τ 下的指数平均；过去只通过 {β_c^m} 这组基被投影进来。
- **所有 τ 相等时**：只有一个指数基，只能记住"指数加权的总量"，记不住"什么时候发生的"。
  - 依据：HiPPO / LMU 的论证，要以分辨率 δ 表示长度为 H 的历史，需要约 H/δ 个独立的基。
- **容量上限**：不超过每个位置的状态个数（V1 是 216），依据是 Jaeger 2001 关于线性储备池记忆容量的结论（MC ≤ N）。

### 命题 7（原地积分的增益有上限，只对空间流成立）

- **平稳噪声**（每 tick 方差 σ²）：膜电位噪声的方差是 σ²/(1−β²) ≈ σ²·n/2。
- **原地持续的信号 s**：幅值是 s·n，信噪比 ∝ √n，积分越久越好。
- **移动的源**：只在感受野里停留 D = R/(vΔ) 个 tick。信噪比约为 s·min(n, D)/(σ√(n/2))，在 n ≈ D 处最大；n > D 时按 D/√n 下降。

**结论**：对移动的源，τ 超过 R/v 只会多积噪声。

（这是视觉 / 空间流特有的。不涉及空间的流，比如音频，不受这条限制。）

### 小结 Q2

- 记忆长度由 τ_max 和 Σ τ 决定；时间分辨率由 τ 的多样性决定；空间流里还受 R/v 封顶。
- **最关键的一点**：记忆和计算是**串联**的。某一层为了记忆取了大 τ，这一层读输入就有大滞后（命题 2），这个滞后会被下游所有层继承（命题 3）。
- SSM 块用三样东西把两者部分解开，V1 一样都没有：
  - 直通项 D·u（当前输入不经过记忆）；
  - 多维、多时间尺度**并联**的状态；
  - 连续的实数输出。

**已有工作**：衰退记忆（Boyd & Chua 1985）、记忆容量（Jaeger 2001）、HiPPO（Gu 2020）/ LMU（Voelker 2019）、匹配滤波与检测前跟踪（TBD）的积分增益。

## 4. Q3：可学性——截断 k 步的 TBPTT 学得到什么

### 命题 8（对 τ 的梯度被截断压小）

**设定**：一个线性神经元，截断点在 k−p 处，状态 c = u[k−p] 被当作常数（detach）。

**完整梯度**：

    ∂u[k]/∂β = Σ_{m≥1} m·β^{m−1}·I[k−m]

**截断后的梯度**：

    Σ_{m=1}^{p−1} m·β^{m−1}·I[k−m] + p·β^{p−1}·c

**缺掉的部分**：

    Σ_{j≥1} j·β^{p+j−1}·I[k−p−j]

也就是说，片段之前的输入，它们的"额外年龄 j"对梯度的贡献整个丢失了。

**缺多少**：输入平稳、均值为 μ 时：
- 完整梯度 = μ·n²；
- 截断后约 μ·(p²/2 + p·n)，在 p ≪ n 时约占完整值的 p/n；
- p 在片段内均匀分布，平均下来约为 **k/(2n)**。

**结论**：τ 远大于 k·Δ 时，τ 的梯度被压小约 k/(2n)；而且超过 p 的那些时间相关性完全学不到。

### 命题 9（"会读"但"不会写"）

- 下游读取被 detach 的状态时，对读取权重的梯度是精确的（状态就是片段的输入）。
- 把信息写进状态、并保留超过 k 个 tick，所需的上游梯度缺失。

所以 TBPTT-k 能学会**利用**前向动力学顺带留下的长期信息，但学不会**存**超过 k 个 tick 的特定信息。

深度不会改变这一点：片段内的任何路径都跨不过 k 个 tick。

**已有工作**：
- 截断偏向短期依赖：Tallec & Ollivier 2017。
- 无偏的替代方法：ARTBP、UORO、RTRL / e-prop。
- SSM 靠并行扫描在整条序列上求梯度；但这要求递推是线性的，而复位会破坏线性。

## 5. 综合：一个 τ 被五种需求拉扯

| 需求 | 要求 n（= τ/Δ） | 依据 |
|---|---|---|
| 读码精度（计算） | 大 | 误差 θ/n（命题 1） |
| 低滞后、时间分辨率 | 小 | 每层滞后 n−1，沿深度相加（命题 2、3） |
| 记忆长度 | 大（≥ 需要的 H） | 记忆长度约 Σ n、尾部由 τ_max 决定（命题 5） |
| 移动源 / 噪声（空间流） | ≤ R/(vΔ) | 超过只多积噪声（命题 7） |
| 可学性 | ≤ k | 梯度被压到约 k/(2n)（命题 8） |
| 两端失控的代价 | 小 | 拖尾和恢复时间正比于 n·log（命题 4） |

### 缺陷陈述（候选）

在流式 SNN 里，每个神经元**唯一的**时间常数同时决定四件事：
- 它的编码精度；
- 它的时间滞后；
- 它的记忆长度；
- 它能不能被训练。

这些要求互相矛盾。而且层与层是串联的，任何一层为记忆付出的滞后，都会被下游全部继承。

**对照**：
- 静态 SNN：精度来自 T，与数据时间无关，也不需要记忆。
- RNN / SSM：实数输出，精度与 n 无关；靠直通项和多时间尺度并联的状态解开滞后与记忆；靠并行扫描解开可学性。
- **只有流式 SNN 把这四件事绑在同一个参数上。**

### 对机制设计的要求（不是设计）

1. **精度与滞后分开**：不靠时间平均拿精度，或者用一种短窗口也能准确解码的码。
2. **记忆与主计算路径分开**：并联而不是串联，长记忆不能拖慢当前证据。
3. **记忆长度与可学性分开**：从结构上解决（可扫描的线性记忆），或者从训练上解决（无偏 / 前向）。
4. **保持二值通信和事件驱动的稀疏性**，否则就不再是 SNN 的优势。

**已有工作各自覆盖了一部分**：
- 多比特脉冲（I-LIF）覆盖 1 的一部分；
- SSM 的直通项在 ANN 里覆盖了 2；
- 并行扫描 / PSN 覆盖 3 的一部分。

**同时满足 1–4 的脉冲机制，目前没有看到。** 这是第二步（查重 + 设计）的起点。

## 6. 旁证（只作一致性检查，不作依据）

以下现象与上面的推导一致：
- 冷启动和突变时的滞后（命题 2、3）；
- 深层两端的极端膜电位（命题 4）；
- TBPTT 的 k 呈倒 U 形：太短学不到依赖，太长方差大（命题 8）；
- 双仓的 M 与 soma 的记忆串联，几乎没被用上（命题 5 的小结）；
- 步长从 50 ms 改到 200 ms 时精度崩掉（命题 2、4：n 和每 tick 的输入量都变了）。
